# ADR-115: "내 자산"이 모의 포트폴리오를 탭으로 품고, 실전투자(주문)는 따로 둔다

## Status
Accepted

**Note (2026-10-22):** 처음엔 ADR-115으로 썼다. 같은 시기 main에 다른 ADR-115(실거래 주문 멱등성)이 먼저 들어가 115로 옮겼다.

[account-aggregation-plan.md](../account-aggregation-plan.md) §8의 "기존 `portfolio/`(모의)와 `brokerage/`(실계좌)를 하나의 내 자산으로 묶는다"를
어디까지 할지 정한다. [ADR-066](066-terminal-ui-shell.md)의 아이콘 레일 구성을 바꾼다(레일 원칙 — 한 번의 클릭, 가장 긴 경로 일치 — 은 그대로).

## Context

1단계에서 웹에 `/assets`("내 자산" — 손 입력·CSV 계좌 통합)를 만들었다. 그 결과 "내 돈이 어디에 얼마 있나"를 보는 화면이 셋이 됐다.

- `/portfolio` — 모의 포트폴리오(보유·거래 내역·빠른 매수·인사이트·리스크). 레일 "포트폴리오".
- `/brokerage` — 주문용 증권사 연동(BYOK) 대시보드: 실시간 잔고·주문·조건부 주문·리밸런싱. 레일 "실전투자".
- `/assets` — 통합 보유(읽기 전용). 모의 탭은 모의 보유 표만 따로 보여 줬다.

고려한 범위:

- (a) 셋을 한 화면으로 합친다. `/brokerage`의 실시간 잔고를 통합 합계에 넣고, 주문 기능도 내 자산 안으로 옮긴다.
  - 증권사 API로 보유를 모으는 것은 ADR-106의 2단계다. 법률 자문(legal-review-brief §2-12) 전에는 하지 않기로 했다.
  - 주문 화면은 실주문 안전 게이트(ADR-025·055·057)와 함께 설계됐다. 보기 화면에 섞으면 "보는 곳에서 실수로 주문하는" 경로가 생긴다.
- (b) 모의 포트폴리오만 내 자산의 탭으로 옮긴다 — 채택. 실전투자는 주문 화면으로 그대로 둔다. 내 자산에서 연동 계좌가
  있다는 것을 보여 주고 그쪽으로 가는 길만 둔다.
- (c) 그대로 둔다. 화면이 셋이라 같은 질문에 어디로 가야 할지 헷갈린다. 모의 탭이 모의 포트폴리오 화면과 겹친다.

## Decision

- **레일:** "포트폴리오" 항목을 없애고 "내 자산"(`/assets`)이 그 자리와 아이콘을 잇는다. 예전 포트폴리오에 묶였던 체결 엔진·자동 주문
  규칙(`/matching`·`/watch-rules`)도 내 자산 아래로 묶는다. "실전투자"는 그대로 둔다.
- **탭:** 통합 | 계좌별 | 모의투자. 탭은 주소(`/assets?view=ACCOUNTS|PAPER`, 통합은 `/assets`)에 남는다. 링크로 열 수 있고 새로 고침해도
  유지된다. 탭 이동은 방문 기록을 쌓지 않는다(replace).
- **모의투자 탭 = 예전 `/portfolio` 전체.** 같은 컴포넌트(`PaperPortfolioView`)를 그린다. 상단 바 지표도 모의 계좌 기준으로 바뀐다.
  `/portfolio`는 `/assets?view=PAPER`로 보낸다. 북마크와 예전 링크가 계속 동작한다.
- **실전투자 연동은 보이기만 한다.** 계좌별 목록 아래에 "주문용 증권사 연동" 카드(증권사·마스킹한 계좌번호·실전투자로 가는 링크)를 둔다.
  그 잔고는 통합 합계에 넣지 않는다는 것을 카드에 적는다.

## Reasons

- 모의 포트폴리오는 이미 "보기" 화면이라 내 자산과 성격이 같다. 옮겨도 안전 게이트와 얽히는 것이 없다.
- 주문 화면을 따로 두면 실주문 경로가 지금처럼 한 곳에 모여 있다. 보기와 주문의 경계가 레일에서도 드러난다.
- 연동 계좌 잔고를 합치지 않는 것은 ADR-106의 단계 구분을 지키는 것이다. 카드가 그 사실을 이용자에게 밝힌다.

## Consequences

- 모의 포트폴리오로 가는 길이 한 번 더 길어진다. 레일 → 내 자산 → 모의투자 탭이다. 모의만 쓰는 이용자는 탭을 한 번 더 누른다.
  `?view=PAPER` 링크로 줄일 수 있다.
- 실전투자 이용자는 보유를 두 곳(실전투자의 실시간 잔고, 내 자산의 파일 기반 보유)에서 본다. 같은 증권사 계좌를 파일로도 올리면
  두 화면의 숫자가 다를 수 있다(시점·원장 차이). 2단계에서 잔고 스냅샷과 대사를 넣을 때 하나로 모은다.
- 모의투자 탭은 모의 포트폴리오의 쿼리(5초 폴링)를 탭이 열려 있을 때만 쓴다. 상단 바 지표용 쿼리는 다른 탭에서도 남는다.

## Revisit When

- 법률 자문 뒤 2단계(증권사 API 읽기)를 시작하면 — 연동 계좌 잔고를 통합 합계에 넣고, 카드 문구를 바꾼다.
- 모의투자 이용자 비중이 커서 탭 한 번이 부담이라는 신호가 오면 — 레일에 모의 바로가기를 다시 둔다.
- 실전투자 화면의 보기 기능(잔고·정산)이 내 자산과 겹친다는 지적이 쌓이면 — 주문만 남기고 보기를 내 자산으로 옮기는 것을 검토한다.
