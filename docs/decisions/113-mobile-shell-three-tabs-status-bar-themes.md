# ADR-113: 모바일 앱 셸 — 탭 3개 + 떨어진 검색, 상태 바, 앱 전체 모의/실전 모드, 드라큘라 기본 테마

## Status
Accepted

## Context

모바일 앱(`apps/mobile`)은 스크리너 홈에서 시작해 관심종목·알림·내 계좌·로그아웃을 이모지 하단 줄로 오갔다. 색은 화면마다 하드코딩한
남색이고 라이트 모드가 없다. 2026-10 iOS 디자인 시안(디자인 캔버스 "monticker iOS 앱 시안")에서 메뉴 구성 6안(A~F)을 비교했고,
"B안 피드 중심 + 상태 바"를 추천안으로 정했다. 적용 순서는 [mobile-design-plan.md](../mobile-design-plan.md)다.

고려한 메뉴 구성:

1. **A안 4탭 + 검색 분리(마켓 탭).** 시장 둘러보기가 앞에 오지만, 이 제품의 핵심 고리(내 종목이 움직이면 이유를 먼저 본다, ADR-105)와 멀다.
2. **C안 알림 탭.** 알림이 피드와 겹친다.
3. **D안 관심종목 중심 3탭.** 퀀트 신호·리스크 경고가 들어갈 곳이 없다.
4. **E안 퀀트 전면 5탭.** 퀀트를 쓰지 않는 다수에게 탭 두 개가 비어 있다.
5. **F안 하단 계좌 바.** 늘 잔고를 띄우면 잔고를 자주 보게 만든다(행동 리포트의 방향과 반대).
6. **B안 피드 중심 3탭(홈·관심종목·내 계좌) + 검색 분리 + 진행 중인 것만 보이는 상태 바** — 채택.

## Decision

### 내비게이션

- 하단 떠 있는 탭 3개: **홈**(내 종목·전략·리스크 새 소식 피드) · **관심종목** · **내 계좌**. 검색은 탭이 아니라 오른쪽에 떨어진 원형 버튼이다.
  검색을 열면 탭 바 자리가 홈 버튼 + 검색 입력창으로 바뀐다.
- 설정은 홈·내 계좌 오른쪽 위 프로필 버튼으로 간다. 알림 목록은 홈 피드와 설정에서 들어간다(탭 아님).
- 종목 상세·주문 시트·설정 하위 화면은 스택/시트로 탭 위에 쌓는다.

### 상태 바

- 탭 바 위 알약 하나. 모드 배지(모의 노랑 / 실전 주황) + **지금 진행 중인 것**(실행 중 전략 수, 미체결 주문 수, 실전이면 증권사 연동 상태)만 보인다.
  잔고는 띄우지 않는다.
- 모의는 진행 중인 것이 있을 때만 보이고, 실전은 늘 보인다. 내 계좌·종목 상세·주문 화면에서는 숨긴다(같은 내용이 화면에 있다).
- 누르면 내 계좌로 간다.

### 모의/실전 모드

- 앱 전체에 모드가 하나 있다(`paper` 기본 / `live`). 내 계좌의 모의 \| 실전 분할 버튼만 바꾼다. 종목 상세의 주문 버튼은 지금 모드로만 주문한다 —
  **주문 시트 안에서 모드를 바꾸지 않는다**(웹 W2에서 주문 패널 모드 토글을 뺀 것과 같은 이유).
- 실전은 증권사 연동(`/api/brokerage/account`의 `tokenValid`)이 있을 때만 고를 수 있다. 앱을 다시 열 때 연동이 끊겼으면 모의로 돌린다.
- 실전 주문은 **길게 누르기**로만 제출한다. 실주문 판단은 서버 게이트(ADR-025 리스크, ADR-057 킬 스위치)가 최종이고, 앱은 모의 데이터로 실전 리스크를 판정하지 않는다.
  결과가 불명이면 다시 보내지 않고 상태 동기화로 확인한다.

### 색과 테마

- **기본은 드라큘라 다크.** 라이트와 "시스템 따라가기"는 설정 › 화면 모드에서 고른다.
- 상승·하락 색은 `화면 모드에 맞춤`(기본 — 다크 초록 상승/빨강 하락, 라이트 빨강 상승/파랑 하락) · `빨강 상승·파랑 하락` · `초록 상승·빨강 하락`.
  차트·등락률·매수·매도 버튼·급등·급락 배지에 함께 적용하고, 위험 경고·로그아웃의 빨강은 바꾸지 않는다.
- 색 역할은 웹([ADR-112](112-web-shell-v2-search-rail-status-themes.md))과 같다. **주황 = 실전(실제 돈) 전용**, 모의 노랑, 공시 청록, 강조 보라.
- 설정은 기기에만 저장한다(웹도 상승·하락 색은 브라우저 저장이다).

## Reasons

- 홈을 피드로 두면 "관심종목이 움직였다 → 왜인지 → (원하면) 모의로 연습" 고리가 첫 화면에서 시작한다. 시장 둘러보기는 검색의 "많이 찾는 종목"과 홈 시장 요약으로 충분하다.
- 검색을 탭에서 떼면 어느 탭에서든 한 번에 닿고, 탭 3개가 넓어진다(iOS 26 탭 바 + 검색 분리 관행).
- 상태 바는 "지금 돈이 걸린 일이 돌아가고 있나"만 알린다. 잔고를 늘 보이지 않는 것은 F안을 버린 이유와 같다.
- 모드를 앱 전체에 하나만 두고 주문 시트에서 못 바꾸게 하면 "모의인 줄 알고 실전 주문"이 생길 경로가 줄어든다. 주황·길게 누르기가 두 번째 방어선이다.
- 드라큘라 다크는 웹 기본 테마와 같아 두 앱이 같은 제품으로 보인다.

## Consequences

- 스크리너 홈과 하단 "알림" 진입이 사라진다. 스크리너 목록이 필요한 사용자는 검색의 "많이 찾는 종목"이나 웹을 쓴다.
- 홈 피드는 서버에 개인화 피드 API가 없어 여러 쿼리를 클라이언트에서 합친다. 쿼리 수가 늘고, "새 소식 N건"은 기기마다 다르다.
- 새 네이티브 의존성(`react-native-svg`, `expo-blur`, `expo-haptics`, `expo-local-authentication`, AsyncStorage)이 생긴다. 모두 Expo SDK 고정 버전이라
  `expo install --check`로 관리된다. 개발 빌드를 새로 만들어야 한다.
- 시안의 소셜 로그인·프로필·실전 잔고 대조·수수료 추정은 서버 API가 없어 이번에 넣지 않는다(계획 §4).
- 기기 저장 설정은 웹과 동기화되지 않는다. 웹에서 고른 테마·상승·하락 색은 앱에 오지 않는다.

## Revisit When

- 홈 피드 쿼리가 느리거나 기기마다 "새 소식" 수가 달라 혼란이 생기면 — 서버 개인화 피드와 읽음 상태 API를 만든다.
- 탭 3개로 부족하다는 사용 데이터(퀀트랩 진입이 많음)가 나오면 — 전략 탭 승격을 검토한다.
- 사용자 설정을 계정에 저장하게 되면 — 테마·상승·하락 색을 웹과 함께 서버로 옮긴다.
