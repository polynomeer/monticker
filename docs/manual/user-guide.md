# monticker 사용자 매뉴얼

monticker는 실시간 시세를 단순히 보여주는 앱이 아니라, **"지금 무슨 일이 일어나고 있는지"**를 보여주고, 모의투자로 안전하게 연습하며, 나만의 투자 전략을 직접 검증해볼 수 있는 종합 투자 학습 플랫폼입니다. 이 문서는 모든 화면과 기능을 처음부터 끝까지 설명합니다.

> 화면은 2026년 10월 트레이딩 터미널 디자인(다크 전용, 상단 바 + 왼쪽 아이콘 레일)을 기준으로 설명합니다. 예전 화면의 스크린샷은 지금 화면과 달라서 모두 뺐고, 새로 찍을 목록은 [매뉴얼 색인](README.md#스크린샷-다시-찍을-목록)에 있습니다.
>
> 화면 곳곳의 회색 **"준비 중"** 표식은 디자인만 먼저 들어가고 기능은 아직 동작하지 않는 요소입니다. 이 문서에서도 그런 요소는 "준비 중"으로 적었습니다.

> ⚠️ monticker의 분석·점수·신호·AI 요약·주문 제안은 모두 **교육 및 시뮬레이션 목적의 참고 정보**이며 투자 자문이 아닙니다. 과거 성과는 미래 수익을 보장하지 않습니다. 실제 투자 판단과 책임은 본인에게 있습니다.
>
> 기본 상태에서는 어떤 화면에서도 실제 돈이 오가지 않습니다. 단, **[19. 실전투자](#19-실전투자-증권사-계좌-연동)** 메뉴에서 본인 명의의 증권사 API 키를 직접 연동하면 그 계좌로 실제 주문이 나갑니다. 이 기능은 현재 실계좌 검증과 법률 검토가 완료되지 않은 상태이니, 연동 전에 해당 섹션의 주의사항을 반드시 읽어주세요.

## 1. 시작하기

### 1.1 회원가입과 동의

`/signup` — 이메일·비밀번호·닉네임으로 가입하거나 **Google · 카카오 · 네이버 계정으로 바로 시작**할 수 있습니다.

- 비밀번호는 **8자 이상, 영문과 숫자를 모두 포함**해야 합니다. 입력하는 동안 강도(약함~매우 강함)가 표시됩니다.
- 닉네임은 2자 이상이며 전략 마켓에 제작자 이름으로 표시됩니다.
- 약관 동의 항목은 네 가지입니다. 필수 세 항목에 모두 동의해야 가입할 수 있습니다.

```
[ ] 전체 동의
[ ] [필수] 이용약관
[ ] [필수] 개인정보 수집·이용
[ ] [필수] 만 19세 이상입니다
[ ] [선택] 이벤트·리포트 이메일 수신
```

동의 내역은 서버에 기록됩니다. 선택 항목(마케팅 수신)은 나중에 [21.2 알림 설정](#212-알림-설정-settingsnotifications)에서 철회할 수 있습니다.

### 1.2 동의 화면 (`/consent`)

다음 경우에는 앱 화면 대신 **"서비스 이용 동의"** 화면이 먼저 뜹니다.

- 소셜 계정으로 처음 가입해 필수 동의가 아직 없는 경우
- 이용약관·개인정보처리방침이 바뀌어 다시 동의해야 하는 경우 — "약관이 바뀌었습니다. 바뀐 내용을 확인하고 다시 동의해주세요."가 표시됩니다.

필수 항목에 동의하고 "동의하고 계속"을 누르면 원래 가려던 화면으로 돌아갑니다.

### 1.3 로그인 / 비밀번호 찾기

`/login`에서 이메일·비밀번호 또는 소셜 계정으로 로그인합니다. 비밀번호를 잊으면 "비밀번호 찾기"(`/forgot-password`)에서 재설정 링크를 받습니다. 링크는 **30분** 동안 유효합니다.

- "로그인 상태 유지" 체크박스는 **준비 중**입니다(지금은 동작하지 않습니다).

로그인하지 않아도 홈·스크리너·종목 상세·검색 같은 시세 조회 화면은 모두 볼 수 있습니다. 모의투자, 관심종목, 알림, Quant Lab, 지갑 등 **개인화된 기능**은 로그인이 필요합니다.

### 1.4 온보딩과 모의투자 시작 자금

처음 로그인하면 4단계 온보딩(`/onboarding`)이 열립니다.

1. **환영** — 주요 기능(관심 종목, 가격 알림, 퀀트랩, 조건부 주문, AI 주문 제안) 소개
2. **어떤 시장을 지켜볼까요?** — 관심 분야(반도체, 2차전지, 바이오 등), 사용 방식(관찰 위주 / 단기 이벤트 매매 / 규칙 기반 퀀트), **모의투자 시작 자금**을 고릅니다.
   - 시작 자금은 **1,000만원 · 3,000만원 · 1억원** 중 하나이며, **처음 모의 계좌를 만들 때 한 번만** 정할 수 있습니다. 가상의 돈입니다.
   - 고른 분야와 사용 방식은 계정에 저장되고 **설정 → 관심 분야**에서 언제든 바꿀 수 있습니다. 고른 관심 분야는 홈의 섹터 히트맵·이벤트 피드에서 **앞쪽에 "관심" 표시와 함께** 보이고(정보를 숨기지는 않음, "관심 분야 순" 칩으로 끄기), 알림 이력에서 "관심 분야" 필터로 골라 볼 수 있습니다. 업종 이름으로 판정하는 근사라 넓은 업종(화학·기계 등)은 관련 없는 종목도 함께 앞에 올 수 있습니다. 투자 추천이 아니라 보는 순서를 바꾸는 기능입니다.
3. **관심종목을 담아보세요** — 거래대금 상위 종목 12개 중 여러 개를 골라 한 번에 관심종목에 담습니다. 인기 순위 통계가 아직 없어 거래대금 순으로 보여 주는 것이며, 투자 추천이 아닙니다.
4. **준비 완료**

## 2. 화면 구성 — 상단 바와 아이콘 레일

로그인·회원가입·약관·온보딩을 뺀 모든 화면은 같은 골격을 씁니다. 화면은 **다크 테마 전용**입니다.

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [로고] 화면 제목 / 종목   시세 스트립(화면마다 다름)   [▣] [● 모의투자 계좌 ₩…] [⊞] [🔔] [👤] │
├────┬─────────────────────────────────────────────────────────────────────┤
│ 홈 │                                                                     │
│ 트레│   패널  ┌ 탭 ─ 탭 ─────────────── [+] [설정] [⤢] ┐                 │
│ 스크│        │                                          │                 │
│ …  │        └──────────────────────────────────────────┘                 │
└────┴─────────────────────────────────────────────────────────────────────┘
```

### 2.1 왼쪽 아이콘 레일

모든 영역이 한 번의 클릭 거리에 있습니다. 아이콘에 마우스를 올리면 이름이 보이고, 지금 있는 영역은 보라색으로 표시됩니다.

| 아이콘 | 이동하는 곳 | 함께 묶인 화면 |
|--------|-------------|----------------|
| 홈 | `/` 마켓 개요 | |
| 트레이딩 | `/stocks/search` 종목 검색 | 종목 상세, 종목 비교 |
| 스크리너 | `/screener` | |
| 관심종목 | `/watchlist` | |
| 포트폴리오 | `/portfolio` | 체결 엔진, 자동 주문 규칙 |
| 지갑 | `/wallet` | 리플레이, 정산 |
| 퀀트랩 | `/quant-lab` | 룰셋 빌더, 백테스팅, 포트폴리오 분석 |
| 전략 마켓 | `/quant-lab/market` | 제작자 수익 |
| 실전투자 | `/brokerage` | 연동·주문·조건부 주문·리밸런싱 |
| 리스크 | `/risk` | |
| 알림 | `/alerts` | |
| 설정 | `/settings/appearance` | 알림 설정, 구독 |

> 예전 버전에서는 `/` 주소가 스크리너였습니다. 지금 스크리너는 `/screener`이고 `/`는 마켓 개요 홈입니다.

### 2.2 상단 바

- **제목 또는 종목 선택**: 화면 이름이 표시됩니다. 종목 화면에서는 종목 선택 칸이 됩니다.
- **시세 스트립**: 화면마다 요약 숫자가 다릅니다(홈은 지수·장 상태, 종목 화면은 현재가·거래량 등). 데이터가 없으면 `—`로 표시하고 숫자를 지어내지 않습니다.
- **계좌 칩**: 지금 어느 계좌를 보고 있는지 알려 줍니다.
  - 모의투자 화면: 노란 점과 "모의투자 계좌", 모의 계좌 총자산. 누르면 지갑으로 갑니다.
  - 실전투자 화면: **주황색** 테두리와 "실전 계좌", 연동 계좌의 가용 현금. 누르면 실전투자 대시보드로 갑니다.
- **알림(🔔)**: 알림 화면으로 이동합니다.
- **내 계정(👤)**: 구독 · 설정 · 로그아웃 메뉴. 로그인 전에는 "로그인" 버튼이 보입니다.
- "레이아웃 편집"과 "전체 메뉴" 아이콘은 **준비 중**입니다.

**종목 검색 단축키**: 어느 화면에서나 **⌘K(macOS) / Ctrl+K(Windows)**를 누르면 종목 검색으로 이동합니다.

### 2.3 패널

화면 본문은 여러 개의 **패널**로 나뉩니다. 패널 머리에는 탭과 작은 아이콘이 있습니다.

- **확대(⤢)**: 패널을 화면 가운데에 크게 띄웁니다. Esc, 닫기 버튼, 바깥 배경 클릭으로 닫습니다. 확대해도 차트·입력 내용은 그대로 유지됩니다.
- **내보내기(⬇)**: 지금 보이는 표를 CSV 파일로 받습니다. 동작하는 곳은 스크리너 결과, 관심종목, 포트폴리오, 정산, 체결 엔진의 주문 목록, 실전투자 대시보드·주문 화면입니다. 내보낼 수 없는 패널(종목 비교, 종목 화면 하단 패널)에는 아이콘이 없습니다.
- **패널 설정(슬라이더 아이콘)**: 흐리게 표시된 아이콘은 **준비 중**입니다.
- **+**: 스크리너에서는 "조건 저장"으로 동작합니다.

## 3. 홈 (마켓 개요)

`/` — 접속하면 가장 먼저 보이는 화면으로, 시장 전체 흐름을 한눈에 봅니다. 로그인하지 않아도 볼 수 있습니다.

### 3.1 상단 시세 스트립

| 항목 | 내용 |
|------|------|
| KOSPI · KOSDAQ · USD/KRW | 지수와 환율. 실시세 공급자가 연결되지 않은 환경에서는 이름 뒤에 **"(모의)"**가 붙습니다 — 개발용 모의 값이니 참고하지 마세요. |
| 장 상태 | "정규장 · 시각", "장 시작 전", "장 마감", **"휴장 · 휴장일 이름"**(예: 추석) 중 하나. KRX 휴장일 캘린더를 따릅니다. 서버에 연결하지 못하면 평일 09:00–15:30 기준으로만 계산합니다. |
| 오늘 이벤트 | 오늘(한국 시간) 감지된 이벤트 수 |
| 급등·급락 종목 | 오늘 급등·급락 이벤트가 난 종목 수 |

### 3.2 패널

- **지수 카드**: KOSPI·KOSDAQ·USD/KRW의 값, 등락, 기준 시각, 작은 추이 그래프. 모의 값이면 주황색 "모의" 배지가 붙습니다. 수집 전이면 "시세 수집 전입니다"로 표시됩니다.
- **이벤트 피드**: 탭은 "지금 움직이는 종목 · 오늘의 공시 · 뉴스"입니다. 열은 시각, 종목, 이벤트, **이벤트 구간 변동**(이벤트 직전 1분봉 종가 → 이벤트 후 30분까지의 등락), **거래량 배수**(이벤트 직후 5분 평균 거래량 ÷ 직전 60분 평균), 중요도, "차트 보기"입니다.
- **관심종목**: 내 관심종목 상위 몇 개와 추이. 로그인이 필요합니다.
- **퀀트 시그널**: 내 전략(포워드 테스트 중)과 구독한 마켓 전략에서 나온 최근 매수·매도 신호를 모읍니다. 신호는 모의 신호이며 주문이 나가지 않습니다.
- **섹터 히트맵**: 섹터별 평균 등락률(종목 동일가중)로 색이 칠해집니다. 오늘 이벤트가 있으면 건수가 함께 표시됩니다. 같은 패널의 **"테마" 탭은 준비 중**입니다.

## 4. 스크리너

`/screener` — 조건에 맞는 종목을 실시간으로 걸러 봅니다.

### 4.1 필터 (왼쪽 패널)

| 필터 | 선택지 |
|------|--------|
| 마켓 | 전체 / 국내 / 해외. "국내"를 고르면 국내 전체 / 코스피 / 코스닥 하위 구분이 나옵니다. |
| 섹터 | 섹터 칩을 여러 개 고를 수 있습니다. |
| 등락률 | 하한·상한 두 손잡이 슬라이더(−30% ~ +30%, 양 끝은 제한 없음) |
| 거래량 배수 (20일 평균 대비) | 최소값만 — 전체, 1×, 1.5×, 2×, 3×, 5×, 10× |
| 시가총액 | 전체 / 대형주(1조 이상) / 중형주 / 소형주, 그리고 최소·최대 범위(억원). 범위를 걸면 시가총액 정보가 없는 종목은 빠집니다. 해외를 고르면 숨겨집니다. |
| 오늘 발생한 이벤트 (모두 만족) | 뉴스 동반, 공시 동반, 퀀트 시그널 발생(로그인 필요), 감성 급변 |
| 정렬 | 거래대금순 / 거래량순 / 거래량 배수순 / 급상승 / 급하락 |

**거래량 배수**는 "최신 일봉 거래량 ÷ 직전 20거래일 평균"입니다.

### 4.2 결과 탭과 저장한 조건

- **실시간 차트**: 고른 조건과 정렬 그대로의 결과
- **급등·급락**: 급상승(또는 급하락) 순으로 고정
- **외국인·기관 동향 (준비 중)**: 실제 외국인·기관 수급 데이터가 아직 연동되지 않아, 지금은 실시간 차트와 같은 목록을 안내 문구와 함께 보여 줍니다. "매수/매도 비율" 열도 값 없이 "—"로 표시됩니다. 국내 종목의 실제 투자자별 매매는 종목 상세의 "투자자 동향" 탭에서 보세요(증권사 API가 설정된 환경에서만 실데이터).
- **★ 저장한 조건**: 결과 패널의 **+** 또는 "저장"으로 지금 조건을 이름 붙여 저장합니다(로그인 필요, 이름 40자, **최대 20개**). 저장한 탭에서 조건을 바꾸면 "변경 사항 저장"이나 삭제를 할 수 있습니다.

결과 열은 "기본(거래량 배수·오늘 장중 추이·이벤트·시가총액·섹터) / 거래(거래대금·매수/매도 비율(준비 중, "—")·섹터) / 밸류에이션(시가총액·PER·PBR)" 세 묶음 중에서 고릅니다. 상단에는 조건 일치 종목 수, 평균 등락, 평균 거래량 배수, 이벤트 동반 종목 수, 마지막 갱신 시각이 표시됩니다.

### 4.3 실시간 갱신과 더 보기

화면 상단의 "● 실시간"은 실시간 연결 상태입니다. 보이는 종목의 가격은 별도 새로고침 없이 갱신되고, 목록 전체는 10초마다 다시 계산됩니다. 아래로 스크롤하면 다음 종목이 자동으로 이어서 로드됩니다. 행의 ☆로 관심종목에 담고, 종목명을 누르면 [종목 상세](#52-종목-상세-화면-구성)로 갑니다.

## 5. 종목 검색 · 종목 상세 (트레이딩)

### 5.1 종목 검색 (`/stocks/search`)

아이콘 레일의 "트레이딩" 또는 **⌘K / Ctrl+K**로 엽니다. 검색 범위 탭은 전체 / 종목 / 이벤트·뉴스 / 전략입니다.

- **종목**: 종목명이나 티커로 찾습니다. 최근에 연 종목과 최근 검색어가 표시됩니다.
- **이벤트·뉴스**: 이벤트와 뉴스 제목에서 찾습니다.
- **전략**: 전략 마켓에 공유된 전략을 이름·설명·작성자로 찾습니다.
- "많이 찾는 종목"은 검색 통계가 아직 없어 거래대금 상위 종목으로 대신 보여 줍니다(**준비 중** 표식).

### 5.2 종목 상세 화면 구성

`/stocks/{종목코드}` — 차트·호가·주문·이벤트를 한 화면에서 보는 트레이딩 화면입니다.

```
상단 스트립: 현재가(바뀌면 잠깐 깜빡임) · 전일 대비 · 거래량 · 거래대금 · 변동성 σ(20일) · 오늘 이벤트 · 시가총액

┌ 주문 | 조건부 | 가격 알림 ┐  ┌ 호가 | 체결 | 시장 요약 ┐  ┌ 차트 | 왜 움직였나 | 뉴스 | 투자자 동향 | 토론 | 관심종목 ┐
│                          │  │                         │  │                                                      │
└──────────────────────────┘  └─────────────────────────┘  └──────────────────────────────────────────────────────┘
┌ 이벤트 | 호가 깊이 ┐
└───────────────────┘
┌ 보유 종목 | 미체결 주문 | 조건부 주문 | 체결 내역 | 정산 대기 ┐   ← 모의 / 실전 전환
└──────────────────────────────────────────────────────────────┘
```

- **시장 요약**: 시가·고가·저가·전일 종가·거래량·거래대금·PER·섹터와 종목 스코어(국내 종목만). 펀더멘털이 모의 데이터인 환경에서는 시가총액·PER이 `—`입니다.
- **왜 움직였나**: 최근 이벤트·뉴스·가격 동향을 바탕으로 AI가 만든 한 문단 요약입니다. 인용된 뉴스·이벤트는 "뉴스 보기"·"이벤트 보기"로 원문을 확인할 수 있습니다. 시간적 연관을 요약할 뿐 인과관계를 단정하지 않습니다.
- **투자자 동향**: 국내 종목의 개인·외국인·기관 순매수(최근 10거래일). 증권사 API가 설정되지 않은 환경에서는 "모의 데이터"로 표시됩니다.
- **토론**: [5.6 종목 토론](#56-종목-토론-커뮤니티)
- **관심종목**: 내 관심종목으로 빠르게 다른 종목에 옮겨 갑니다.

### 5.3 차트

- **봉 간격**: 1분 · 3분 · 15분 · 1시간 · 일 · 주 · 월 · 1년 · 3년
- **차트 유형**: 캔들 · 라인 · 영역 · 하이킨아시. 하이킨아시는 평균을 낸 봉이며, 툴팁에는 실제 시세가 함께 나옵니다.
- **지표**: 차트 위에 MA5·MA20·MA60·볼린저밴드, 아래 보조 창에 거래량·RSI·MACD 중 하나
- **이벤트 레이어**: 공시·뉴스·거래량·급등락(기본 켜짐), **퀀트 시그널**(내 전략·구독 전략의 이 종목 신호, 로그인 필요), **감성**(뉴스 감성 점수 — 초록 긍정·빨강 부정). 마커를 누르면 내용을 볼 수 있습니다.
- **대기 주문 선**: 미체결 지정가 주문이 있으면 차트에 "모의 매수 대기" 같은 가격선이 그려지고, 그 자리에서 취소할 수 있습니다.
- "차트 레이아웃" 아이콘은 **준비 중**입니다.

> 💡 monticker의 핵심 가치는 "가격이 왜 움직였는가"를 보여주는 것입니다. 이벤트 레이어와 "왜 움직였나" 탭을 함께 보세요. 다만 차트는 시간적 연관만 보여 줄 뿐, 인과관계를 단정하지 않습니다.

### 5.4 그리기 도구

차트 왼쪽 툴바의 도구입니다. 키보드 화살표로 도구 사이를 옮기고, Esc로 지금 도구를 해제합니다.

| 도구 | 사용법 |
|------|--------|
| 십자선 | 기본 상태. 그린 것을 끌어서 옮기고, 클릭하면 지웁니다. |
| 추세선 | 두 점을 클릭 |
| 수평선 | 한 번 클릭 |
| 펜 | 끌어서 자유롭게 그리기 |
| 텍스트 | 클릭한 자리에 글 입력(Enter 추가, Esc 취소) |
| 측정 | 두 점을 클릭하면 가격 차이·%·봉 수 표시(저장하지 않음) |
| 구간 확대 | 두 점을 클릭한 구간으로 확대(한 번 쓰면 해제) |
| 자석 | 점을 가까운 시가·고가·저가·종가에 붙임 |
| 잠금 | 그린 것을 옮기거나 지우지 못하게 막음 |
| 숨기기 / 모두 지우기 | 그린 것을 숨기거나 한꺼번에 지움(잠금 중에는 지울 수 없음) |

그린 것은 **이 브라우저에** 사용자·종목별로 저장됩니다(다른 기기와 동기화되지 않음). 봉 간격을 바꿔도 같은 시각·가격 자리에 그대로 놓입니다. 종목당 최대 100개까지 저장됩니다. 차트 유형과 자석 설정도 이 브라우저에 기억됩니다.

### 5.5 호가 · 체결 · 호가 깊이

- **호가**: 매도·매수 호가 단계와 잔량, 스프레드. 데이터 출처에 따라 다릅니다.
  - **KIS 실시간**: 한국투자증권 API 키가 설정된 환경의 실시간 호가
  - **Yahoo Finance**: 15분 지연 시세 기반 추정 호가
  - **Mock**: 현재가 기준 시뮬레이션 호가(기본값)
- **체결**: 이 종목의 최근 체결 틱이 장중에 실시간으로 쌓입니다. 서버가 재시작되면 잠시 비었다가 다시 채워지고, 합성(모의) 시세가 섞이면 그렇게 표시됩니다.
- **호가 깊이**: 보이는 호가 단계를 누적한 깊이 차트입니다(매수 = 상승 색, 매도 = 하락 색).

### 5.6 종목 토론 (커뮤니티)

"토론" 탭에서 이 종목에 대한 의견을 남기고 다른 사용자의 의견을 읽습니다. 글을 쓰려면 로그인이 필요합니다.

- 최근 이벤트를 **태그**로 붙여 "어떤 급등·뉴스에 대한 의견인지"를 남길 수 있습니다.
- **매수·매도 권유는 게시할 수 없습니다.** "지금 사세요" 같은 표현은 자동으로 걸러지며, 판정이 불확실해도 게시가 거부됩니다.
- 부적절한 글은 신고 버튼으로 사유와 함께 신고합니다. 신고는 접수만 되며 자동으로 지워지지 않습니다.

> 토론 글은 다른 사용자의 개인 의견이며 monticker가 보증하거나 추천하는 내용이 아닙니다.

### 5.7 하단 포지션 패널

화면 아래 패널은 **모의 / 실전** 전환과 함께 보유 종목, 미체결 주문, 조건부 주문, 체결 내역, 정산 대기를 탭으로 보여 줍니다.

- 보유 종목의 **최근 이벤트** 열에는 그 종목의 가장 최근 이벤트가, **진입 경로** 열에는 가장 최근 매수 체결이 어디서 나왔는지(직접 / Watch Rule / 조건부 / 전략)가 표시됩니다. 출처를 판정할 수 없는 예전 거래는 `—`입니다.
- 실전 쪽은 계좌가 연동돼 있어야 내용이 보입니다.

## 6. 관심종목

`/watchlist` — 자주 보는 종목을 그룹으로 묶어 관리합니다.

- **그룹**: "새 그룹 이름"에 입력해 그룹을 만듭니다. "기술주", "배당주"처럼 원하는 기준으로 나누세요.
- **그룹 삭제**: 그룹 옆 삭제 버튼을 누르면 확인 창에 종목 수와 "켜진 자동 주문 규칙 N개가 꺼집니다"가 보입니다. 그룹과 그 안의 종목은 지워지고, 이 그룹을 대상으로 한 [자동 주문 규칙](#10-자동-주문-규칙-watch-rule)은 지워지지 않고 **꺼지기만** 합니다(발동 기록은 남음). 꺼진 규칙은 대상을 다른 그룹이나 종목으로 바꾸면 다시 켤 수 있습니다.
- **종목 추가**: 종목 상세의 "관심종목 추가", 스크리너·검색의 ☆로 담습니다.
- **열**: 현재가, 전일 대비, **오늘**(장중 추이 미니 차트), **거래량 배수**(최신 일봉 ÷ 직전 20거래일 평균), 오늘 이벤트, 알림
- **필터·정렬**: 마켓(전체 / 국내 / 해외), 정렬(내 순서 / 이름순 / 등락률순 / 현재가순)
- **순서 바꾸기**: 행 끝 ⋯ 메뉴의 "위로 이동 / 아래로 이동"(키보드로도 가능). 정렬이 **"내 순서"**일 때만 옮길 수 있습니다.
- **그룹 전체 알림**: 그룹의 모든 종목에 거래량 급증 알림을 한 번에 겁니다.
- **선택 종목 패널**: 종목을 고르면 차트, 52주 최고·최저(일봉이 52주를 다 덮지 못하면 실제 기간을 붙여 "최고/최저"로 표시), 최근 이벤트, 가격 알림 설정이 보입니다. **외국인 순매수**는 **준비 중**입니다.
- 시간외·NXT 같은 세션별 시세 구분은 아직 없습니다.

## 7. 알림

`/alerts` — 알림 이력과 알림 규칙, 전달 채널을 한 화면에서 봅니다.

### 7.1 알림 이력과 읽음 표시

- 상단: 오늘 받은 알림, **읽지 않음**, 활성 규칙, 전달 채널 요약
- 탭: 전체 / 읽지 않음 / 가격 / 이벤트 / **뉴스·공시** / **시그널** / 계좌
- 읽지 않은 알림에는 분홍 점이 있습니다. 누르면 읽음 처리되고, **"모두 읽음"**은 목록을 불러온 시점까지 받은 알림을 모두 읽음으로 바꿉니다(그 뒤에 온 알림은 그대로 남습니다).
- 각 줄에는 전달 상태가 표시됩니다: 발송됨 / 이메일로 발송 / 발송 실패 / 발송 대기 / **설정으로 보내지 않음** / **방해 금지 시간 — 푸시 안 함** / 알림 설정대로 전달 / **시간당 한도 초과 — 알림 없이 이력만**.

**시그널 탭**: 내 전략과 구독한 마켓 전략에서 포워드 테스트 신호가 나면 이력에 쌓입니다. 이력에는 항상 남고, 푸시·이메일로 받을지는 알림 설정의 "퀀트 시그널"을 따릅니다. 이 기능이 생기기 전의 신호는 이력에 없습니다.

**뉴스·공시 탭**: 관심종목에 넣은 종목의 새 뉴스와 중요 DART 공시가 쌓입니다. 자세한 규칙은 [21.2 알림 설정](#212-알림-설정-settingsnotifications)의 "뉴스·공시"를 보세요.

### 7.2 알림 규칙

"새 알림 규칙"을 누르면 이 화면에서 바로 규칙을 만들 수 있습니다(종목 상세의 "가격 알림" 탭에서도 같은 규칙을 만듭니다).

| 유형 | 조건 |
|------|------|
| 가격 이상 / 가격 이하 | 지정 가격을 넘거나 그 아래로 떨어지면 |
| 거래량 급증 | 최신 거래량이 평소(20거래일 평균)보다 크게 늘면. 기준값 입력 없음 |
| RSI 과매도 / 과매수 | RSI가 지정값 아래로 / 위로 가면(기본 30 / 70, 기간 기본 14일) |
| 이동평균 상향 돌파 / 하향 이탈 | 현재가가 지정 기간(2~250일, 기본 20일) 이동평균선을 위로 뚫거나 아래로 떨어지면 |
| 보유종목 하락 (모의투자) | 모의투자로 보유 중인 종목이 지정 비율 이상 떨어지면. 실전투자 보유종목은 대상이 아닙니다 |

- 규칙마다 **켜기/끄기** 토글이 있습니다. 끈 규칙은 흐리게 " · 꺼짐"으로 표시되고, 언제든 다시 켤 수 있습니다.
- 한 번 울린 규칙은 **10분간 다시 울리지 않습니다(쿨다운)**. 조건이 계속 충족되면 10분마다 다시 울릴 수 있습니다.
- 알림 설정에서 해당 종류를 꺼 두어도 발동 기록은 이력에 "설정으로 보내지 않음"으로 남습니다.

### 7.3 전달 채널

알림 종류마다 어떤 채널(푸시 / 이메일 / 푸시 실패 시 이메일 / 알림 이력)로 오는지, 방해 금지 시간이 켜져 있는지 보여 줍니다. **끌 수 없는 알림**(리스크 경고, '결과 확인 중' 주문, 조건부 주문 실패)은 "항상 받음 · 방해 금지 시간에도 즉시"로 표시됩니다. 바꾸려면 "채널·방해 금지 시간 설정 →"으로 [21.2 알림 설정](#212-알림-설정-settingsnotifications)에 갑니다. 카카오 알림톡은 연동 예정입니다.

## 8. 모의투자 주문

monticker의 모의투자는 실제 돈이 들지 않는 가상 계좌(시작 자금 1,000만원·3,000만원·1억원 중 온보딩에서 선택)로 매매를 연습하는 기능입니다. 주문은 주로 [종목 상세](#52-종목-상세-화면-구성)의 **주문** 패널에서 넣습니다. 포트폴리오의 "빠른 매수", [체결 엔진](#9-체결-엔진)도 같은 모의 계좌를 씁니다.

### 8.1 주문 패널

```
[모의투자] [실전 · 연동 필요]        ← 실전 버튼은 항상 비활성
[매수] [매도]
주문 유형: [시장가] [지정가]
지정가:   [71,000]                   ← 지정가일 때만
수량:     [10]  [25%][50%][100%]  ──●──   주문 가능 ₩… · 보유 N주
[ ] 익절/손절 등록  익절가 [____] 손절가 [____]   ← 매수만

주문 전 리스크 체크   ✓ 통과 / ✗ 한도 초과
지금 기분은? [확신] [계획대로] [FOMO] [불안]

[매수 ₩710,000]
```

- **이 패널은 실제 주문을 보내지 않습니다.** "실전" 버튼은 계좌가 없으면 "실전 · 연동 필요", 있으면 "실전 · 실전투자 화면"으로 표시되며 누를 수 없습니다. 실전 주문은 [19. 실전투자](#19-실전투자-증권사-계좌-연동) 화면에서만 합니다.
- **시장가**: 현재가에 바로 전량 체결됩니다. 시세가 5분 넘게 갱신되지 않았으면(장 마감 후 등) 거부됩니다.
- **지정가**: 원하는 가격을 넣습니다. 지금 가격으로 바로 체결될 수 있으면 "지정가 · 지금 가격이면 즉시 체결"로 표시되고 바로 체결됩니다. 아니면 **미체결 주문**으로 남습니다 — [8.2](#82-지정가-주문이-체결되는-방식).
- 매도는 보유 수량(미체결 매도 수량 제외)을 넘을 수 없습니다.

### 8.2 지정가 주문이 체결되는 방식

- 서버가 **약 3초마다** 미체결 지정가 주문을 훑어, 최신 1분봉 종가가 지정가에 닿은 주문(매수는 종가 ≤ 지정가, 매도는 종가 ≥ 지정가)을 **그 종가로 전량** 체결합니다.
- 처리 순서는 **접수 순**입니다. 실제 거래소의 "가격 우선 → 시간 우선"과 다릅니다. 모의 체결에는 유동성 제한이 없어서, 가격이 닿으면 순번과 관계없이 그 가격의 주문이 함께 체결됩니다.
- 1분봉 종가로 판정하므로, 1분 안에서 잠깐 스쳤다가 돌아간 가격에는 체결되지 않을 수 있습니다. 시세가 5분 넘게 멈춰 있으면(장 마감 후 등) 체결하지 않고 기다립니다.
- **매수 지정가**는 대기하는 동안 "지정가 × 수량"만큼 현금이 **예약금**으로 묶입니다. 체결되면 차액이 돌아오고, 취소하면 전액 돌아옵니다. **매도 지정가**는 그 수량만큼 매도 가능 수량이 줄어듭니다.
- 매수 지정가는 체결 직전에 리스크 한도를 한 번 더 확인합니다. 그 사이 한도를 넘게 됐으면 주문이 자동 취소되고 예약금이 돌아옵니다.
- 미체결 주문은 하단 "미체결 주문" 탭, 차트의 대기 주문 선, 체결 엔진 화면에서 취소할 수 있습니다. 만료일은 따로 없습니다.

### 8.3 익절/손절 자동 등록과 조건부 주문

- **익절/손절 등록**(매수에서만): 매수가 체결되는 순간 익절가·손절가 매도 주문 감시를 자동으로 시작합니다. 둘 중 한쪽이 체결되면 다른 쪽은 취소됩니다(OCO).
- **조건부 탭**(로그인 필요): 체결과 별개로 이 종목에 조건부 주문을 겁니다.
  - 단일 조건: "가격 이상" 또는 "가격 이하"가 되면 매수/매도
  - 익절 + 손절(OCO): 익절가(이상)와 손절가(이하)를 함께 걸고, 한쪽이 발동하면 다른 쪽 취소
- 조건이 맞으면 **모의투자 시장가**로 체결됩니다. 서버가 약 3초마다 확인하며, 발동할 때도 리스크 한도를 통과해야 합니다. 한도나 잔고 부족으로 거부되면 "실패"로 남습니다.
- 등록한 주문은 "이 종목 조건부 주문" 목록과 하단 "조건부 주문" 탭에서 보고 취소합니다.

### 8.4 주문 전 리스크 체크

수량과 가격을 입력하는 동안 [11. 리스크](#11-리스크)에서 정한 한도(1일 VaR 95%, 종목 집중도, 일간 손실 한도, 보유 종목 수, 시간당 주문 수)에 걸리는지 **자동으로** 미리 보여 줍니다. "미리보기 — 주문할 때 서버가 다시 판정합니다"라는 안내대로, 실제 주문 때 한 번 더 판정합니다.

### 8.5 투자 영수증과 감정 태그

체결되면 **투자 영수증**이 뜹니다.

```
삼성전자 10주 매수 · 체결
주문 진행 단계
  ✓ 주문 접수       09:12:03
  ✓ 예약금 잠금     09:12:03   710,000원     ← 지정가만
  ✓ 체결            09:14:21
  … 정산            T+2 영업일 예정
체결금 · 수수료 · 슬리피지 · 정산 예정 금액 · 체결 후 잔고

이 주문을 낼 때 기분은?  [감정 태그]  메모(선택)   [저장하기] [건너뛰기]
```

- **진행 단계**: 시장가는 "접수 → 체결 → 정산" 3단계, 지정가는 "접수 → **예약금 잠금**(매도는 **매도 수량 잠금**) → 체결 → 정산" 4단계입니다. 일부만 체결되면 "부분 체결", 남은 수량을 취소했으면 "부분 체결 · 잔량 취소"로 표시됩니다. 잠금 시각을 기록하기 전에 낸 옛 주문은 "시각 기록 없음"으로 나옵니다.
- **감정 태그**: 주문 패널에서는 확신 · 계획대로 · FOMO · 불안 네 가지를 빠르게 고르고, 영수증에서는 12가지 중에서 고르거나 바꿀 수 있습니다.

```
확신 · 계획대로 · 장기 투자 · 뉴스 보고 · 비중 조절 · 불안
FOMO · 조급함 · 따라삼 · 물타기 · 직감 · 기타
```

매번 기록할 필요는 없습니다. 기록이 쌓이면 [투자 지갑](#12-투자-지갑과-리플레이)의 점수와 리플레이에서 "어떤 마음으로 낸 주문이 어떤 결과를 냈는지" 본인 데이터로 돌아볼 수 있습니다. **"계획대로"** 태그는 [계획 준수율](#124-주문-리플레이-walletreplay) 계산에 쓰입니다.

### 8.6 진입 경로

모의 체결마다 그 주문이 어디서 나왔는지 기록됩니다.

| 경로 | 뜻 |
|------|-----|
| 직접 | 내가 주문 패널·빠른 매수·체결 엔진에서 직접 낸 주문 |
| Watch Rule #n | [자동 주문 규칙](#10-자동-주문-규칙-watch-rule)이 낸 주문 |
| 조건부 #n | 모의 조건부 주문(익절/손절 포함)이 발동해 낸 주문 |
| 전략 #n | 전략이 낸 주문 |

경로는 서버가 정하며 포트폴리오 거래 내역, 지갑 원장, 리플레이, 종목 화면 하단에 표시됩니다. 이 기록이 생기기 전의 거래는 `—`입니다.

## 9. 체결 엔진

`/matching` — 호가창과 주문 대기열을 보면서 모의 주문이 어떻게 처리되는지 확인하는 화면입니다(아이콘 레일 "포트폴리오" 아래). **종목 상세와 같은 모의투자 계좌**를 쓰며, 별도의 가상 계좌가 아닙니다.

### 9.1 상단 요약

- **엔진: 접수 순 처리** — 모의 지정가는 접수된 순서대로 처리됩니다([8.2](#82-지정가-주문이-체결되는-방식)).
- 미체결 N건, 오늘 체결 N건
- **평균 슬리피지**(bp): 주문 접수 시점의 최우선 호가 대비 체결가 차이. +는 불리한 쪽입니다. 최근 30일, 실시간 호가가 기록된 체결만 계산하며 없으면 `—`입니다.
- **지연**: 시장가 주문 접수부터 체결까지 걸린 시간의 중앙값

### 9.2 주문 입력

종목(삼성전자·SK하이닉스·현대차·NAVER·AAPL·NVDA 중 선택), 매수/매도, 시장가/지정가, 수량을 넣고 제출합니다. **"리스크 사전 확인"**을 누르면 체결하지 않고 한도 통과 여부만 미리 볼 수 있습니다. 시장가를 고르면 예상 슬리피지, 지정가 매수를 고르면 묶일 예약금이 표시됩니다.

> 주문 폼 아래 안내 문구도 같은 내용(접수 순, 1분봉 종가 도달 시 전량 체결)을 보여 줍니다.

**AI 주문 제안**: 폼 아래 "제안 받기"를 누르면 AI가 선택한 종목의 최근 이벤트·뉴스·지표를 읽고 **매수 / 매도 / 보류** 중 하나의 방향과 근거를 제안합니다.

- AI는 **수량과 가격을 정하지 않습니다.**
- **"승인"을 눌러도 주문이 나가지 않습니다.** 승인은 "참고하겠다"는 기록일 뿐이고, 주문은 직접 폼에서 넣어야 하며 똑같이 리스크 한도 검사를 거칩니다.
- 제안은 요청할 때만 생성됩니다. "이 제안은 투자자문이 아니며, 모의투자 참고용 시뮬레이션 정보입니다."

### 9.3 오더북과 내 대기 순번

**오더북 (CLOB)** 패널은 호가와 함께 **모의 지정가 대기열**을 가격별로 보여 줍니다.

- 내 주문은 보라색 조각으로 **"내 주문 · 대기 N번째"**라고 표시됩니다. 순번은 같은 가격 안에서의 접수 순서입니다.
- 다른 사용자의 주문은 개별로 보이지 않고 "다른 주문 N건 · N주"처럼 묶어서만 표시됩니다.
- 호가 범위 밖에 있는 내 주문은 따로 모아 보여 줍니다.
- 모의 체결에는 유동성 제한이 없어, 가격이 닿으면 **순번과 관계없이** 그 가격의 주문이 함께 체결됩니다.

### 9.4 체결 테이프와 주문 목록

- **체결 테이프**: "시장 체결"(이 종목의 실제 최근 체결 틱)과 "내 체결" 탭
- **주문 목록**: 미체결(취소 가능) / 체결 내역(수수료 포함) / 주문 상태 흐름(접수 → 예약 → 부분 체결 → 체결 → 정산). 내보내기(⬇)로 CSV를 받을 수 있습니다.

## 10. 자동 주문 규칙 (Watch Rule)

`/watch-rules` — "삼성전자에 거래량 급증이 감지되면 10주 자동 매수"처럼, **이벤트나 전략 신호가 오면 알아서 모의 주문을 넣는 규칙**을 걸어 둡니다. 화면을 보고 있지 않아도 동작합니다(아이콘 레일 "포트폴리오" 아래).

> ⚠️ **모의투자 계좌에만 적용됩니다.** 실전투자 계좌는 자동으로 주문하지 않습니다 — 실계좌 주문은 항상 본인이 직접 눌러야 합니다.

### 10.1 규칙 만들기

```
규칙 이름 (선택):   [거래량 터지면 10주]                     ← 100자 이하
무엇을 감지할까요:  (•) 거래량 급증 ( ) 가격 급등 ( ) 가격 급락 ( ) 퀀트랩 · 전략 신호
  복합 조건 (선택): [ ] 가격 급등  [ ] 가격 급락   시간 창 [30분 ▾]
어떤 종목에서:      (•) 종목 하나 [삼성전자]   ( ) 관심종목 그룹 [기술주 ▾]
어떻게 주문할까요:  [매수] [매도]
  주문 유형:        (•) 시장가  ( ) 지정가 (발동 가격 대비) [-50] bp
  수량 기준:        (•) 주 수 [10]  ( ) 계좌 평가자산 % [5]
안전장치:
  중요도 하한 [0] 점 이상    쿨다운 [10분 ▾]    하루 최대 발동 [제한 없음]
  [✓] 리스크 한도 체크를 통과한 경우에만 주문   ← 끌 수 없음
[규칙 저장]
```

| 항목 | 설명 |
|------|------|
| 감지할 이벤트 | 거래량 급증 / 가격 급등 / 가격 급락, 또는 **퀀트랩 전략 신호**(내 전략이나 구독한 전략 중 이 종목을 포워드 테스트 중인 것을 고르고, 매수 신호·매도 신호 중 언제 발동할지 정함) |
| 복합 조건 | 이벤트 규칙에만. 고른 다른 이벤트도 시간 창(5분 / 30분 / 1시간 / 하루) 안에 함께 감지됐을 때만 발동 |
| 대상 | **종목 하나** 또는 **관심종목 그룹**. 그룹이면 이벤트가 감지된 순간 그 그룹에 들어 있는 종목마다 판정합니다(나중에 그룹에 넣은 종목도 포함). 그룹을 지우면 규칙은 멈춥니다 — [10.2](#102-규칙-수정하기)처럼 새 종목이나 그룹으로 대상을 바꾸면 다시 켤 수 있습니다 |
| 지정가 | 발동 시점 가격에서 bp만큼 떨어진 값에 지정가를 겁니다(100bp = 1%, 최대 ±10%, 기본 −50bp). 바로 체결되지 않으면 "지정가 접수"로 남고 [8.2](#82-지정가-주문이-체결되는-방식)처럼 처리됩니다 |
| 계좌 % | 발동 시점 모의 계좌 평가자산(현금 + 미체결 예약금 + 보유 평가액)의 1~25%만큼을 주 단위로 내려 주문합니다. 1주도 안 되면 주문하지 않고 "건너뜀"으로 남깁니다 |
| 중요도 하한 | 이벤트마다 0~100의 강도가 매겨집니다. 이 값 미만이면 발동하지 않습니다(전략 신호에는 쓰지 않음) |
| 쿨다운 | 한 번 체결되면 이 시간(없음 / 5분 / 10분 / 1시간 / 하루) 동안 다시 발동하지 않습니다. 기본 10분 |
| 하루 최대 발동 | 하루(한국 시간) 최대 체결 횟수. 비우면 제한 없음, 1~1000회 |

그룹 대상 규칙의 쿨다운과 하루 최대 발동은 종목별이 아니라 **규칙 하나에 대해** 셉니다.

### 10.2 규칙 수정하기

규칙 카드의 연필 버튼(✎)을 누르면 오른쪽 "새 규칙" 자리에 **규칙 수정** 폼이 지금 값으로 채워져 열립니다(폰 화면에서는 목록 아래로 이동합니다). 만들 때와 같은 폼·같은 입력 범위를 씁니다.

| 바꿀 수 있는 것 | 바꿀 수 없는 것 (새 규칙을 만드세요) |
|------|------|
| 이름, 중요도 하한, 쿨다운, 하루 최대 발동(비우면 제한 없음) | 감지 조건(이벤트·복합 조건·전략·신호 방향) |
| 대상(종목 하나 ↔ 관심종목 그룹, 다른 종목·그룹) | 매수 / 매도 |
| 주문 유형(시장가 ↔ 지정가)과 bp, 수량 기준(주 수 ↔ 계좌 %)과 값 | |

- **바꾼 항목만** 서버로 보냅니다. 아무것도 바꾸지 않고 저장하면 "바뀐 내용이 없습니다"가 보입니다.
- 주문 유형이나 수량 기준을 바꾸면 새 기준의 값을 직접 넣어야 합니다(예: 주 수 → 계좌 %로 바꾸면 비율 칸이 비어 있습니다).
- 서버가 거부하면(범위를 벗어남, 종목·그룹을 찾을 수 없음 등) 그 이유가 폼 아래에 그대로 보이고 폼은 열린 채로 남습니다.
- 이름·쿨다운·한도·수량 같은 값은 저장을 누르자마자 카드에 먼저 반영되고, 실패하면 원래대로 돌아갑니다. **대상·주문 유형·수량 기준을 바꾸면** 서버가 확인을 마칠 때까지 카드는 그대로입니다.
- 규칙 번호가 그대로라 오늘 발동 수·쿨다운·발동 기록·규칙 경유 손익이 이어집니다(지우고 다시 만들어도 한도가 초기화되지 않게 하려는 것입니다).
- [취소] 또는 `Esc`로 닫으면 연필 버튼으로 포커스가 돌아갑니다.

**대상 그룹이 삭제되어 꺼진 규칙** — 카드에 "대상 그룹 삭제됨"이 붙고 켜기 스위치는 잠깁니다. 연필 버튼(대상 바꾸기)을 눌러 새 종목이나 관심종목 그룹을 고르면 "저장하면서 규칙 다시 켜기"가 나타납니다(기본 켬). 저장하면 새 대상으로 다시 켜집니다. 대상을 바꾸지 않고 이름 등만 고칠 수도 있지만, 그때는 꺼진 채로 남습니다.

### 10.3 내 규칙과 상단 요약

- 상단: 활성 규칙, 오늘 발동, 차단됨(오늘 거부된 건수), **규칙 경유 손익**
- **규칙 경유 손익**: 규칙이 낸 **매도 체결**의 실현 손익입니다((매도가 − 그 시점 평균 매수단가) × 수량, 수수료·세금 전). 규칙이 산 종목을 내가 직접 팔았다면 그 손익은 직접 주문 쪽에 잡힙니다.
- 규칙 카드마다 "오늘 발동 / 한도"가 표시되고, 한도에 닿으면 "오늘 한도 도달"이 붙습니다. 규칙은 언제든 중지·재개·수정([10.2](#102-규칙-수정하기))·삭제할 수 있습니다.

### 10.4 발동 기록

| 상태 | 뜻 |
|------|-----|
| **체결** | 주문이 실제로 체결됐습니다. 주문 내역·지갑·포트폴리오에 모두 반영됩니다. |
| **지정가 접수** | 지정가 주문이 접수됐지만 아직 체결되지 않았습니다. |
| **지정가 체결** | 접수됐던 지정가가 나중에 체결됐습니다. 체결 시각과 체결가가 함께 보입니다. |
| **지정가 취소** | 접수됐던 지정가가 체결되지 않고 취소됐습니다(직접 취소·리스크 차단·보유 부족 중 사유 표시). |
| **거부** | 리스크 한도를 넘었거나 잔고·보유 수량이 부족했습니다. 자동 주문도 [11. 리스크](#11-리스크) 한도를 **똑같이** 통과해야 합니다. |
| **건너뜀** | 쿨다운 중, 하루 한도 도달, 중요도 미달, 계좌 % 계산 결과 0주, 시세가 오래된 경우 등. 이유가 함께 남습니다. |

꼭 알아둘 점:

- 같은 이벤트로 **두 번 체결되지 않습니다.** 서버가 재시작되거나 이벤트가 중복 전달돼도 한 번만 주문됩니다.
- 이벤트는 장 시간과 시세 상황에 따라 발생하지 않을 수도 있습니다. 규칙을 만들었다고 반드시 주문이 나가는 것은 아닙니다.

## 11. 리스크

`/risk` — 내 계좌의 위험 노출도를 보고 한도를 직접 정하는 화면입니다. 여기서 정한 한도는 **모의투자 주문과 실전투자 주문 모두**에 적용됩니다.

### 11.1 현재 리스크

- 상단: 리스크 수준(안전 / 보통 / 주의 / 위험), VaR 사용률, 섹터 최대 비중, **이번 달 차단** 건수
- 게이지: 일일 손실, 단일 종목 집중도, **섹터 집중도**, 1일 VaR(95%), 1시간 주문 빈도. 한도에 가까워질수록 색이 바뀝니다.

### 11.2 한도 설정

| 한도 | 설명 |
|------|------|
| 1일 VaR 한도 (%) | 하루 예상 최대 손실(95%)의 상한 |
| 단일 종목 최대 비중 (%) | 한 종목이 자산에서 차지할 수 있는 최대 비중 |
| **섹터 최대 비중 (%)** | 한 섹터의 최대 비중. 비우면 "미설정"(0 초과 100 이하) |
| 일일 최대 손실 (%) | 오늘 실현+평가 손익 기준 |
| 최대 보유 종목 수 | |
| 1시간 최대 주문 수 | |
| 리스크 체크 활성화 | 끄면 **모의투자 주문만** 한도 점검을 건너뜁니다. 실거래는 항상 점검합니다 |

손실·집중도·섹터·VaR·보유 종목 수 한도는 **위험을 늘리는 매수 주문**에 적용됩니다. 한도를 넘은 뒤에도 보유 종목을 팔아 위험을 줄일 수 있습니다. 미체결 지정가 매수도 집중도·보유 종목 수 계산에 포함됩니다.

### 11.3 한도 완화는 24시간 뒤 적용 (쿨링오프)

- 한도를 **더 엄격하게** 바꾸면 바로 적용됩니다.
- 한도를 **완화**하거나(값을 올리거나 비움) **리스크 체크를 끄면** 24시간 뒤에 적용됩니다. 그동안 "적용 대기 중인 변경"에 표시되며, 적용 전에 취소할 수 있습니다.

흥분한 상태에서 한도를 풀고 바로 큰 주문을 넣는 일을 막기 위한 장치입니다.

### 11.4 한도 근접 경고

모의 계좌의 VaR·종목 집중도·일간 손실(섹터 한도를 정했다면 섹터 집중도도)이 **한도의 80%**에 이르면 알림이 옵니다.

- 서버가 약 5분마다 확인하며, **항목별로 하루 한 번**만 보냅니다.
- 이 알림은 끌 수 없고 방해 금지 시간에도 바로 전달됩니다. 주문을 막지는 않습니다.
- 지금은 모의 계좌만 대상입니다(실전 계좌 경고는 아직 없음). 리스크 체크를 꺼 두었으면 보내지 않습니다.

### 11.5 차단 기록

리스크 한도 때문에 막힌 주문(모의투자·실거래)을 시각·종목·사유와 함께 보여 줍니다. "한도 초과 시" 동작은 지금 **"주문 차단"만** 있고, "경고 후 진행" 모드는 **준비 중**입니다.

> 💡 초보자는 기본값을 그대로 두는 것을 권장합니다. 충분히 익숙해지면 본인의 위험 허용도에 맞게 조정하세요.

## 12. 투자 지갑과 리플레이

`/wallet` — 모의투자 계좌의 "내 돈이 지금 어디에 어떤 상태로 있는지"를 보여 줍니다.

### 12.1 돈의 이동 지도

```
총 자산 10,000,000원       주문 → 체결 → T+2 정산 순서로 돈이 이동합니다

현금 (주문 가능)          ■■■■■■░░░░
예약금 (미체결 주문에 묶인 돈) ░░░░░░░░░░
평가액 (보유 종목 현재가 기준)  ■■■░░░░░░░
정산 대기 (체결 후 T+2 정산 전) ░░░░░░░░░░
```

"왜 출금 가능한 금액이 총 자산보다 적은지"를 보여 줍니다. 지정가 매수를 걸어 두면 그 금액이 **예약금**으로 옮겨 갑니다. 상단에는 총 자산, 오늘 손익, 원장 대사 결과(**잔액 불일치** 건수)가 표시됩니다.

### 12.2 원장 타임라인

모든 돈의 움직임을 시간순으로 보여 줍니다. 탭은 "원장 타임라인 / 입출금"입니다.

- 행마다 유형(체결·부분체결·예약·예약해제·정산완료·수수료·입금 등)과 돈의 흐름(현금 → 예약금, 정산 대기 → 현금 등)이 표시됩니다.
- 체결 행에는 [진입 경로](#86-진입-경로)가 함께 나옵니다.

### 12.3 투자 영수증과 점수

- **투자 영수증**: 최근 체결의 영수증을 다시 열고 감정 태그와 메모를 고칠 수 있습니다([8.5](#85-투자-영수증과-감정-태그)).
- **점수**: 두 가지 점수와 세부 지표를 보여 줍니다.
  - **투자 행동 점수**: 충동매매(FOMO·불안·조급함 태그 등)·과다거래·추격매수가 없었는지
  - **투자 생존 점수**: 한 종목에 쏠려 있거나 현금이 너무 적지 않은지
  - **세부 지표**(이번 주, 한국 시간 월요일부터):
    - **계획 준수율** — 판정할 수 있는 주문 중 계획된 주문의 비율([12.4](#124-주문-리플레이-walletreplay)의 정의와 같음)
    - **손절 준수율** — 손절선을 정해 둔 손실 매도 가운데 처음 정한 손절선을 지킨 비율
    - **행동 점수 · 지난주 대비**
    - 판정할 주문이 없으면 `—`로 표시됩니다.

점수 아래에는 항상 "모의투자 전용 교육용 피드백입니다. 실제 투자 조언이 아닙니다."라는 안내가 붙습니다. 점수는 매매를 막지 않습니다.

### 12.4 주문 리플레이 (`/wallet/replay`)

날짜를 골라 그날의 매매를 다시 따라가 봅니다.

- **날짜 띠**: 이전 주 / 다음 주로 넘기며 날짜별 수익률을 봅니다. 수익률은 그날 손익 ÷ 그날 0시 평가자산이며, 입출금은 빼고 계산합니다.
- **캔들 리플레이**: 그날 거래한 종목의 분봉을 재생·일시정지·처음으로·다음 주문으로 넘기며 내 주문 위치를 확인합니다.
- **주문 복기**: 시각, 종목, 매수/매도, 수량, 가격, 수익률, 감정 칩, 메모, 진입 경로. 계획 외 주문에는 주황색 "계획 외" 표시가 붙습니다.
- **계획 준수율 / 계획 외 주문**:
  - **계획된 주문** = Watch Rule·조건부 주문·전략이 낸 주문, 또는 감정 태그를 **"계획대로"**로 남긴 주문
  - 직접 낸 주문에 "계획대로" 태그가 없으면 계획 외 주문으로 셉니다. 출처를 알 수 없는 과거 주문은 비율에서 뺍니다.
  - 기록을 돌아보기 위한 지표이며 투자 판단의 기준이 아닙니다.
- **감정 분포 · 이번 주**: 고른 날짜가 속한 주(월~일)에 체결된 거래의 감정 태그 분포

AI가 주문마다 코멘트를 달아 주는 기능은 아직 없습니다.

`/quant-lab` — 코딩 없이 나만의 투자 규칙(룰셋)을 만들고 검증하는 공간입니다.

- 카드: 최근 백테스트의 자산 곡선, CAGR, MDD, **포워드 일치율**(포워드 테스트가 없으면 `—`), 버전, 수정일

### 16.2 룰셋 빌더

`/quant-lab/builder` — "새 전략"으로 엽니다.

```
전략 이름 / 한 줄 설명

조건 블록                    매수 조건  [모두 충족 시 ▾]
 거래량 · 가격 변동            ⠿ 거래량 배수 > 2          ▲▼ ✕
 이동평균 · RSI · MACD         ⠿ RSI 사이 30 ~ 70         ▲▼ ✕
 볼린저밴드 · 뉴스 감성        매도 조건  [하나라도 충족 시 ▾]
 공시 유형 · 배당 공시         ⠿ …
 시가총액 (흐림)
                              손절 [-4]%  익절 [8]%  최대 보유 [20]거래일  트레일링 [7]%

포지션 사이징: (•) 고정 비중 [10]% / 계좌   ( ) 변동성 역가중 [준비 중]  ( ) 켈리 1/2 [준비 중]
최대 동시 보유: [준비 중]
유니버스: [전체|국내|해외] [시총 전체|대형주|중형주|소형주]   [+ 필터 — 준비 중]
```

- **블록 추가**: 블록을 누르면 매수 조건에 추가되고, **끌어다 놓으면** 매수·매도 조건의 원하는 자리에 넣을 수 있습니다. 조건 순서는 왼쪽 점을 끌거나 ▲▼ 버튼으로 바꿉니다.
- **사용 가능한 지표**: 거래량, 가격 변동, 이동평균, RSI, MACD, 볼린저밴드, **뉴스 감성**, **공시 유형**(예: 자사주), **배당 공시**. 뉴스·공시는 장 마감 뒤 나온 것을 다음 거래일부터 반영합니다.
- **시가총액** 블록은 일별 시가총액 이력이 없어 쓸 수 없습니다. 대신 유니버스의 시총 필터를 쓰세요.
- **청산**: 손절 %, 익절 %, **최대 보유**(1~500거래일), **트레일링**(최고가 대비 0% 초과 50% 이하 하락 시 청산), 그리고 매도 조건. 매도 조건이나 최대 보유·트레일링 중 하나 이상이 필요합니다.
- **사이징**: 지금은 고정 비중(1회 투입 = 계좌의 N%)만 동작합니다. 변동성 역가중, 켈리 1/2, 최대 동시 보유는 **준비 중**입니다.
- **빠른 백테스트**: 저장한 뒤 빌더 안에서 CAGR·MDD·샤프·거래 수와 수익 곡선을 바로 봅니다.
- **버전**: 저장할 때마다 새 버전으로 기록됩니다. 기존 룰셋을 수정할 때 "버전" 패널에서 이전 버전을 읽기 전용으로 보고 변경 내용을 비교할 수 있습니다. "불러오기"는 화면에만 채우며, "룰셋 업데이트"를 눌러야 새 버전으로 저장됩니다.
- 포워드 테스트 중에는 룰을 바꿀 수 없습니다. 먼저 중지하세요.

### 16.3 백테스트 실행

룰셋 상세(`/quant-lab/{id}`)에서 종목(또는 유니버스), 기간, 초기 자본을 정하고 실행합니다. **수수료 0.015% + 슬리피지 0.1%**가 반영됩니다.

결과: 누적 수익(같은 종목을 계속 들고 있었을 때와의 비교 포함), CAGR, MDD, **샤프**(연환산, 무위험 3%), 승률, 손익비, 운용 자산 곡선, 낙폭 곡선, 월별 수익률, 거래 분포, 거래 내역(청산 사유: 청산 신호·익절·손절·최대 보유·트레일링·기간 종료). 이전에 저장된 결과에는 샤프가 `—`로 보이며 다시 실행하면 계산됩니다.

### 16.4 신뢰도 등급

신뢰도는 단순 수익률이 아니라 "이 결과를 얼마나 믿을 수 있는가"를 알려 줍니다.

| 등급 | 기준 |
|------|------|
| A | 거래 50회 이상 + 검증 기간 2년 이상 |
| B | 거래 20회 이상 + 검증 기간 1년 이상 |
| C | 거래 10회 이상 |
| D | 거래 10회 미만 — 과최적화 위험 높음 경고 |

신뢰도가 낮을수록(C, D) 결과를 맹신하지 말고 더 긴 기간으로 다시 검증해 보세요.

### 16.5 포워드 테스트

백테스트는 과거 데이터입니다. 룰셋 상세에서 **"포워드 테스트 시작"**을 누르면 지금부터의 실제 시장 흐름으로 같은 규칙을 검증합니다. 백테스트를 마친 전략만 시작할 수 있습니다.

- 평가는 **평일 장 마감 후 하루 한 번(한국 시간 16:00)** 이루어집니다. 장중에는 신호가 바로 보이지 않을 수 있습니다.
- 시작하면 룰셋 수정이 잠깁니다.
- 신호 이력, 운용 자산 곡선, 포워드 기간, **포워드 일치율**(포워드 신호가 같은 기간 백테스트 신호와 얼마나 일치하는지)을 보여 줍니다. 일치율이 낮으면 과최적화를 의심하세요.
- 나온 신호는 홈의 "퀀트 시그널", 알림의 "시그널" 탭, 종목 차트의 퀀트 시그널 레이어에 나타나고, [자동 주문 규칙](#10-자동-주문-규칙-watch-rule)의 감지 조건으로도 쓸 수 있습니다. 신호 자체가 주문을 내지는 않습니다.
- 상세 화면의 "구독자" 수는 `—`이고, "포워드 테스트 12주 이상 — 검증 배지 신청"은 **준비 중**입니다.

## 17. 전략 마켓과 제작자 수익

### 17.1 전략 공유하기

룰셋 상세의 **"전략 마켓에 공유"**에서 소개 글과 월 구독료(0이면 무료, 최대 100만원)를 정하고 "과거 성과가 미래 수익을 보장하지 않음을 구독자에게 고지"에 체크합니다. 백테스트를 완료한 전략만 공유할 수 있으며, 구독자에게는 **신호와 성과 지표만** 공개됩니다.

### 17.2 전략 마켓 둘러보기 (`/quant-lab/market`)

- 상단: **공유 전략 총수**, 검증 배지(`—`), 구독 중, 이번 달 신호
- 필터: 인기 / 신규 / 무료 / 구독 중. **"검증 배지" 필터는 준비 중**입니다.
- 정렬: 구독자 많은 순 / 최근 등록 순 / 포워드 기간 긴 순(지금 보는 페이지 안에서 정렬). 한 페이지에 20개씩 이전/다음으로 넘깁니다.
- 카드: CAGR, MDD, 샤프, 포워드 기간과 일치율, 백테스트 곡선. "신호 보기"로 최근 신호를 펼칩니다.
- **구독 전략 신호** 패널: 구독한 전략의 신호 이력과 새 신호가 실시간으로 모입니다.
- 전략을 이름·설명·작성자로 찾으려면 [종목 검색](#51-종목-검색-stockssearch)의 "전략" 탭을 쓰세요.

**구독하기**: 무료 전략은 "구독"으로 바로 구독하고 해제할 수 있습니다. **유료 전략 구독은 결제가 열리지 않아 "준비 중"**입니다(가격은 표시되지만 구독할 수 없습니다).

꼭 알아둘 점:

- 구독자는 **신호만** 받습니다. 룰셋 내용(조건)은 제작자만 볼 수 있습니다.
- 전략은 "수익률 1위"가 아니라 **검증 기간과 신뢰도** 기준으로 보세요. 마켓의 어떤 전략도 수익을 보장하지 않으며, 신호를 따를지는 본인의 판단입니다.
- "검증 배지"(12주 이상 포워드 테스트 + 일정 수준 이상의 일치율)는 심사 정책이 정해지지 않아 **준비 중**입니다. 지금은 모든 카드가 "검증 전"입니다.

### 17.3 제작자 수익 (`/quant-lab/earnings`)

- 구독료의 **70%**가 제작자 몫입니다(플랫폼 수수료 차감 후).
- 상단: 누적 순수익, 이번 달 순수익, 활성 구독자, 출금 가능. **평균 별점·다음 정산은 `—`**입니다.
- 최근 12개월 월별 순수익 차트, 전략별 지표(이탈률은 기록이 없어 `—`), 수익 내역, 출금 내역
- **출금 신청**: 출금 가능 금액이 **10,000원 이상**일 때 은행·계좌번호·본인 명의 예금주를 입력해 신청합니다. 신청 후 운영 검토를 거쳐 지급되며, 지급 일정과 원천징수 여부는 정산 정책(확정 전)을 따릅니다.
- 유료 구독 결제가 열리기 전까지는 실제 수익이 생기지 않습니다.

## 18. 포트폴리오 분석 (Analytics)

`/analytics` — 한 화면에 분석 패널이 차례로 놓여 있습니다(아이콘 레일 "퀀트랩" 아래). 모든 결과는 **과거 데이터로 계산한 분석**이며, 매매 권유나 투자 자문이 아닙니다.

### 18.1 효율적 프론티어와 분석 결과 비중

```
종목 선택: [삼성전자] [SK하이닉스] [+ 종목 추가]   (2개 이상)
분석 기간: (3개월) (6개월) [1년] (2년) (직접 지정)        [분석 실행]

기대 수익률(연) · 예상 위험 · 샤프 최대 (과거 기준) · 동일가중 샤프 · 현재 보유 샤프

[위험-수익 분포 차트]
  · 회색 점      무작위 비중 포트폴리오 표본(공매도 없음, 합 100%)
  ─ 보라색 선    효율적 프론티어
  ◆ 초록 마름모  샤프 비율 최대 지점 (과거 데이터 기준)
  ○ 주황 원      동일가중
  ■ 하늘색 사각  현재 모의투자 보유 비중

분석 결과 비중: 종목별 % (현재 N% 또는 동일 N%와 비교)
```

- **분석 기간**: 3개월·6개월·1년(기본)·2년, 또는 직접 지정(한국 날짜 기준, 60일~3년, 오늘까지). 고른 종목이 **모두 함께 거래된 날**만 씁니다. 그런 날의 수익률이 30일보다 적으면 이유를 보여 주고 계산하지 않습니다.
- 표본은 고정된 방식으로 뽑아 같은 종목·기간이면 매번 같은 결과가 나옵니다.
- 고른 종목을 모의투자로 보유하고 있으면 현재 보유 비중과 비교하고, 없으면 동일가중과 비교합니다.
- 샤프 비율은 서버에 설정된 무위험 수익률로 계산합니다.
- "이 종목을 사라"가 아니라 "고른 종목들을 과거에 이런 비율로 나눴다면 위험 대비 수익이 어땠는가"를 보여 주는 도구입니다.

**분석 비중을 리밸런싱 초안으로**: 분석 결과 비중을 [실전투자 리밸런싱](#196-리밸런싱--목표-비중-맞추기) 화면에 **저장되지 않은 초안**으로 채웁니다. 목표 저장과 주문 실행은 그 화면에서 직접 확인해야 하며, 자동으로 주문하지 않습니다.

### 18.2 절세 시뮬레이션

올해 실현 이익, 손실 실현 후보(평가손실 중인 종목), 예상 절세 효과를 보여 줍니다. "손익통산" 개념을 모의투자 데이터로 시뮬레이션하는 교육용 도구이며, 세무 자문이 아니고 실제 세무 신고에 사용할 수 없습니다.

### 18.3 켈리 비중 계산

승률·평균 이익·평균 손실을 입력하면 풀 켈리와 **하프 켈리(권장)**를 계산합니다. Quant Lab 룰셋의 최신 백테스트 결과로 채울 수도 있습니다.

### 18.4 차트 패턴

고른 종목의 최근 차트에서 이중 바닥, 이중 천장, 헤드앤숄더, 상승/하락 삼각수렴 같은 전형적인 패턴을 찾아 완성도(%)와 함께 보여 줍니다.

### 18.5 시장 국면

상승장 / 하락장 / 횡보장 / 고변동성 중 어디에 해당하는지 ADX(추세강도), 연환산 변동성, 추세 기울기와 함께 보여 줍니다. 백테스트 결과를 볼 때 "이 전략이 어느 국면에서 검증됐는지"를 함께 확인하세요.

## 19. 실전투자 (증권사 계좌 연동)

`/brokerage` — 본인 명의의 **한국투자증권** 또는 **토스증권** 계좌를 API 키로 연동해 실제 주문을 넣는 화면입니다. 실전 화면은 상단 계좌 칩이 **주황색 "실전 계좌"**로 바뀌고 경고 배너가 붙어, 모의투자 화면과 구분됩니다.

> ⚠️ **이 메뉴에서 넣는 주문은 실제 증권사 계좌로 체결됩니다.** 실제 돈이 움직입니다.
>
> - monticker는 증권사가 아닙니다. 여러분이 증권사에서 직접 발급받은 API 키로 여러분을 대신해 주문을 전달하는 도구일 뿐이며, 자금을 보관하지 않습니다. monticker를 통해서는 출금·이체를 할 수 없습니다.
> - 이 기능은 현재 **실계좌 검증과 법률 검토가 완료되지 않은 상태**입니다. 실제 자금으로 쓰기 전에 소액으로 충분히 테스트하고, 한국투자증권은 **모의투자 계좌**로 먼저 연동해 보세요.
> - 화면의 어떤 정보도 투자 자문이 아닙니다. 최종 판단과 책임은 본인에게 있습니다.

### 19.1 계좌 연동하기 (`/brokerage/connect`)

```
연동 단계: 증권사 선택 → API 키 등록 → 권한 확인 → 완료

증권사:  ( ) 한국투자증권   ( ) 토스증권
App Key / App Secret (토스증권은 Client ID / Client Secret)
계좌번호: 숫자만 입력

[ ] 본인 명의 계좌의 API 키이며, 주문 권한을 monticker에 위임하는 것에 동의합니다
[ ] monticker는 자금을 보관하지 않고 증권사 API 호출만 대행함을 이해했습니다
[ ] 실제 주문의 체결 결과·손실은 본인에게 귀속됨을 이해했습니다

[연결 테스트 후 다음]
```

- 세 가지 동의에 모두 체크해야 연동할 수 있으며, 동의 내역은 서버에 기록됩니다.
- **키 발급처**: 한국투자증권은 Open API 포털([KIS Developers](https://apiportal.koreainvestment.com)), 토스증권은 Open API 개발자 센터. 실명 인증이 필요합니다.
- **한국투자증권은 모의투자 계좌를 지원**합니다. 토스증권은 모의투자 서버가 없어 실계좌로만 동작합니다.
- 키는 암호화되어 저장되고 화면·로그에 다시 표시되지 않습니다. 계좌 비밀번호나 공동인증서는 요구하지 않습니다.
- 한 번에 하나의 계좌만 연동할 수 있습니다.
- **재인증**: 증권사 토큰이 만료되면 자동 재발급을 시도합니다. 실패하면 "재인증 필요"가 뜨고, 연동 화면에서 키를 다시 입력하면 됩니다.
- 연동 과정을 실제 권한(scope) 조회로 확인하는 단계는 아직 없습니다. 지금은 연결 테스트(토큰 발급)로 확인합니다.

### 19.2 연동 해지

연동된 상태에서 연동 화면의 **"연동 해지"** → "정말 해지할까요? 되돌릴 수 없습니다." → **"키 삭제하고 해지"**를 누릅니다.

- 저장된 API 키를 **즉시 삭제**하고, 대기 중인 조건부 주문을 모두 취소합니다.
- 다음 경우에는 해지가 거부되고 이유가 표시됩니다. 확인이 끝난 뒤 다시 시도하세요.
  - 체결 여부를 증권사에서 아직 확인 중인('결과 확인 중'·미체결) 주문이 있을 때 — 미체결 주문을 취소하거나 확인이 끝날 때까지 기다리세요.
  - 조건부 주문이 지금 막 발동해 주문을 내고 있을 때

### 19.3 실전투자 대시보드

```
실전투자            상태: 정상 연결 · 한국투자증권 · API 지연 120ms

총 평가금액 · 가용 현금 · 평가손익

[보유 종목]  [최근 주문]  [정산 내역]          ⬇ 내보내기
바로가기: 실전 주문 · 조건부 주문 · 리밸런싱 · 연동 관리
```

- **보유 종목·잔고**는 증권사에서 가져옵니다. 응답이 늦으면 "증권사 응답이 없습니다. 잠시 후 자동으로 다시 시도합니다"가 뜹니다.
- **API 상태**: 마지막 증권사 호출의 지연 시간과 마지막 오류 종류를 보여 줍니다(서버 재시작 직후에는 `—`).
- **내보내기**: 보유·주문·정산 표를 CSV로 받습니다. 계좌번호는 가려지고 키·토큰은 들어가지 않습니다.
- 운영 중 실거래 주문이 일시 중단되면 "실거래 주문이 일시 중단되었습니다" 배너가 뜹니다. 그동안 새 주문과 리밸런싱 실행은 막히지만, 미체결 주문 취소와 내역 조회는 할 수 있습니다.

### 19.4 주문하기 (`/brokerage/orders`)

```
종목: [종목명 또는 코드 검색]       [매수] [매도]
주문 유형: [시장가] [지정가]     지정가: [70,000]   수량: [10]

주문 검증
  ✓ 수량이 1주 이상의 정수입니다
  ✓ 가용 현금 이내입니다 / 보유 수량 이내입니다
  ✓ 지정가가 0원보다 큽니다
  ✓ 호가 단위 (서버 검증)
  ✓ 가격제한폭(전일 종가 ±30%) (서버 검증)
예상 주문 금액 · 예상 수수료: 증권사 기준

[🤖 제안 받기]                  [주문 확인]
```

1. **입력 검증**: 필수 검증을 모두 통과해야 다음 단계로 넘어갑니다. 국내 종목 지정가의 **호가 단위**와 **가격제한폭(전일 종가 ±30%)**은 서버도 다시 검사해 어긋나면 거부합니다.
2. **실제 주문 확인**: "실제 주문을 보낼까요?" 단계에서 확인하는 순간의 주문 내용이 고정됩니다. 확인한 뒤 수량·가격을 바꾸면 확인이 무효가 되어 다시 확인해야 합니다.
3. **리스크 한도 검사**: 모의투자와 **같은 리스크 한도**([11. 리스크](#11-리스크))를 통과해야 합니다. 못 넘으면 "리스크 게이트에 의해 주문이 차단되었습니다"와 걸린 한도가 표시되고, 증권사로 주문이 가지 않습니다.
4. **증권사 접수**: 통과하면 "증권사에 주문이 접수되었습니다". 체결 여부는 주문 내역에서 확인합니다.

**'결과 확인 중' 주문**: 전송한 뒤 증권사 응답을 받지 못하면 그 주문은 **"결과 확인 중"**으로 표시되고 **자동으로 재전송하지 않습니다**. "확인이 끝날 때까지 같은 주문을 다시 내지 마세요." monticker가 증권사 주문 내역과 자동으로 맞춰 결과를 확정하며, 맞출 수 없으면 "증권사에서 확인"으로 바뀝니다 — 이때는 증권사 앱에서 체결 여부를 직접 확인하세요. 결과 확인 중이 되었을 때, 결과가 확정됐을 때, 수동 확인이 필요할 때 **알림이 오며 이 알림은 끌 수 없습니다.**

- 미체결 주문은 주문 내역에서 **취소**할 수 있습니다(취소도 실제 증권사에 전달). **정정**은 아직 지원하지 않습니다.
- **AI 주문 제안**은 [9.2](#92-주문-입력)와 같습니다 — 방향과 근거만 제안하고, 승인해도 주문이 나가지 않으며, "이 제안은 투자자문이 아니며, 실제 계좌에 대한 참고용 정보입니다"라는 고지가 붙습니다.

### 19.5 조건부 주문 — 손절 · 익절 · OCO

`/brokerage/conditional-orders` — 미리 정한 가격에 도달하면 monticker가 **실계좌로 자동 제출**하는 주문입니다.

```
모드:  ( ) 단일 조건      ( ) OCO (손절+익절)
[단일 조건]  트리거 조건 [이상 ▾] 트리거 가격 [72,000]  발동 시 [매수|매도] [시장가|지정가] 수량 [10]
[OCO]        손절가(이하) [65,000]   익절가(이상) [78,000]   수량 [10]
유효 기간:   [1일 | 7일 | 30일 | 60일 | 90일]
[등록]
```

- **단일 조건**: "가격이 X 이상/이하가 되면 매수/매도" 하나를 겁니다.
- **OCO**: 손절가와 익절가를 함께 걸고, 둘 중 하나가 먼저 발동하면 **나머지는 자동으로 취소**됩니다.
- **유효 기간**: 1·7·30·60·90일 중 선택(최대 90일). 마지막 날(한국 시간) 자정이 지나면 자동 만료됩니다.
- 조건이 충족되면 그 시점에 **리스크 한도 검사를 거친 뒤** 실제 주문이 제출됩니다. 한도에 걸리면 주문은 거부되고 "발동 실패"로 남으며, 실패 알림은 끌 수 없습니다.
- 실시간 시세가 연결되지 않거나 장중에 끊긴 종목은 그동안 발동하지 않고, 다시 연결되면 자동으로 감시합니다.
- 화면에는 감시 중 / 이번 달 발동 / 해지·만료 통계, **트리거 임박**(현재가가 트리거 가격의 2% 안쪽), 종목별 현재가와 "트리거까지" 거리, **발동 기록**(발동 시각과 연결된 증권사 주문 상태)이 표시됩니다.
- "주문이 체결되면 다음 주문을 넣는" 형태(OTO)는 지원하지 않습니다.

### 19.6 리밸런싱 — 목표 비중 맞추기

`/brokerage/rebalance` — 종목별 목표 비중을 정해 두고, 현재 보유와의 차이(괴리)가 임계값을 넘는 종목만 실제 주문으로 맞춥니다.

1. 종목을 추가하고 목표 비중을 입력합니다. 합계가 100%보다 작으면 나머지는 현금으로 남습니다. **"최적 비중 채우기"**는 [18.1](#181-효율적-프론티어와-분석-결과-비중)과 같은 계산으로 비중을 채웁니다(종목 2개 이상). Analytics에서 넘긴 초안도 여기에 채워집니다.
2. **"목표 비중 저장"**을 눌러야 미리보기와 실행에 반영됩니다. 저장하지 않은 변경은 경고로 표시됩니다.
3. **괴리 미리보기**: 종목별 목표·현재·괴리와 매수/매도 예상 금액, **추정 가격**(증권사 잔고 현재가 또는 최근 1분봉 종가), **예상 거래비용**(수수료 0.015%, 매도세 0.18% 기준의 추정치), 매수 예상 금액과 그중 신규 종목 매수 금액을 보여 줍니다. 임계값을 넘는 괴리가 없으면 "리밸런싱이 필요하지 않습니다".
4. **리밸런싱 실행** → 확인 단계를 거치면 대상 종목마다 실제 주문(시장가)이 차례로 제출됩니다. 서버가 실행 시점의 잔고로 다시 계산하므로 수량은 미리보기와 다를 수 있습니다. 각 주문은 개별로 리스크 한도 검사를 거치며, 걸린 주문은 그 건만 거부됩니다. 결과를 모르는 주문은 "체결 여부 확인 중 — 주문 내역에서 확인"으로 표시됩니다.

리밸런싱은 **직접 실행 버튼을 눌렀을 때만** 동작합니다. 정해진 주기로 자동 실행되지 않고, 주문을 한 건씩 따로 승인하는 기능은 없습니다.

`/compare` — 최대 4개 종목을 같은 기간(1개월·3개월·6개월·1년·3년)으로 비교합니다(아이콘 레일 "트레이딩" 아래).

## 21. 설정

아이콘 레일 "설정" 또는 내 계정 메뉴 → "설정"으로 들어갑니다. 왼쪽 설정 메뉴에는 화면 · 알림 · 구독 · 증권사 연동 · 리스크 한도 · 약관·개인정보 · 로그아웃이 있습니다.

### 21.1 화면 설정 (`/settings/appearance`)

- **테마**: 다크(Dracula), 고대비 다크. 라이트 테마와 **"시스템 설정 따르기"는 준비 중**입니다(앱은 다크 전용).
- **시세 색상**: 차트·호가·등락률·매수/매도 버튼 전체에 적용됩니다.
  - 글로벌 — 상승 초록 · 하락 빨강
  - 한국식 — 상승 빨강 · 하락 파랑
  - 색약 친화 — 상승 파랑 · 하락 주황
  - 모노 — 상승 밝은 회색 · 하락 어두운 회색
- **글자 크기**: 작게 · 보통 · 크게 · 더 크게. 화면 전체 글자와 간격이 함께 바뀌며 미리보기 문장으로 확인할 수 있습니다.
- **접근성**
  - **움직임 줄이기**: 기본은 운영체제 설정을 따릅니다. 켜면 화면 전환 효과와 차트 애니메이션을 줄입니다.
  - **숫자 고정폭 글꼴**: 가격·수량을 고정폭 글꼴로 정렬합니다. 끄면 본문 글꼴에 숫자 폭만 맞춥니다.
  - **가격 변동 깜빡임**: 실시간 가격이 바뀌면 잠깐 상승·하락 색으로 강조합니다. 움직임 줄이기가 켜져 있으면 깜빡이지 않습니다.

화면 설정은 **이 브라우저에** 저장됩니다(다른 기기와 공유되지 않음).

### 21.2 알림 설정 (`/settings/notifications`)

```
전체        전체 알림                                    [켬]
가격·이벤트 가격 알림 (설정한 목표가 도달)                [켬]  푸시 · 이메일
            거래량 급증                                  [켬]  푸시 · 이메일
            뉴스·공시 (관심종목 뉴스·중요 공시)            [켬]  푸시 · 이메일
            퀀트 시그널 (모의 신호 — 주문은 나가지 않음)   [켬]  푸시 · 이메일
계좌        체결·정산 (실전 주문 체결, T+2 정산 완료)     [켬]
            리스크 경고                       항상 받음 (끌 수 없음)
            '결과 확인 중' 주문               항상 받음 (끌 수 없음)
리포트      주간 투자 행동 리포트 (매주 월요일 · 이메일)   [켬]
            전략 마켓 소식 (광고성)                       [끔]
수신 동의   마케팅 정보 수신 동의 (선택)                   [동의/철회]
전달 채널   [✓] 앱 푸시  [✓] 이메일  [ ] 카카오 알림톡 [연동 예정]
방해 금지   [ ] 방해 금지 시간  시작 22:00 ~ 종료 07:00 (KST)
[저장]
```

- 바꾼 설정은 **"저장"을 눌러야** 반영됩니다. 마케팅 수신 동의만 누르는 즉시 기록됩니다.
- **전체 알림**을 끄면 끌 수 있는 알림이 모두 멈춥니다. '결과 확인 중' 주문, 조건부 주문 실패, 리스크 경고 알림은 계속 받습니다.
- **끌 수 없는 알림**: 리스크 경고(한도의 80%, 항목별 하루 한 번), '결과 확인 중' 주문(증권사 응답이 없을 때와 결과가 확인됐을 때), 실전 조건부 주문 발동 실패.
- **전략 마켓 소식**은 광고성 알림이라 마케팅 정보 수신 동의도 있어야 보냅니다.
- **방해 금지 시간**(한국 시간, 자정을 넘겨도 됨, 시작과 종료가 같으면 안 됨): 그 시간에는 끌 수 있는 알림의 **푸시만** 보내지 않습니다. 나중에 몰아서 보내지 않고 사라지며, 이메일과 알림 이력은 그대로 남습니다. 끌 수 없는 알림은 방해 금지 시간에도 바로 전달됩니다.
- **카카오 알림톡**은 **준비 중**(연동 예정)입니다.
- **뉴스·공시**: **관심종목에 넣은 종목**의 새 뉴스와 DART 공시를 알려 줍니다. 한 건은 한 번만 옵니다(관심종목 그룹 여러 곳에 같은 종목이 있어도).
  - 뉴스는 **발행 6시간 이내**, 공시는 **접수일(한국 시간)이 오늘**인 것만 알립니다. 지난 기사를 모아 가져와도 알리지 않습니다.
  - 공시는 사업·반기·분기보고서, 유상증자·자기주식, 합병·분할·인수처럼 **중요도가 높은 것만** 알립니다(임원·주요주주 변동 등은 알리지 않음).
  - 푸시·이메일은 **한 시간에 5건까지**입니다. 넘으면 알림 없이 알림 이력에만 "시간당 한도 초과"로 남습니다. 뉴스는 한 시간에 20건이 넘으면 이력에도 남기지 않습니다(공시는 남김).
  - 이 토글을 끄면(푸시·이메일 모두 끔) 알림 이력에도 쌓이지 않습니다. 방해 금지 시간에는 다른 알림처럼 푸시만 보내지 않습니다. 광고성 알림이 아니라 마케팅 동의와는 무관합니다.
  - 관심종목에서 종목을 빼면 그 뒤로는 오지 않습니다. 이 기능이 생기기 전의 뉴스·공시는 이력에 없습니다.
- **주간 투자 행동 리포트**는 매주 **월요일 오전(08:00 KST부터)** 지난주(월~일, 한국 시간) 모의투자 행동을 **이메일로 한 통** 보냅니다.
  - 내용: 모의 체결 수(매수·매도), 계획 준수율, 손절 준수율, 감정 분포, 행동 점수 주간 평균과 각 항목의 **전주 대비** 변화. 숫자는 [투자 지갑](#12-투자-지갑과-리플레이) 점수 카드와 같은 정의로 계산합니다. 판정할 거래가 없으면 "—"로 표시합니다.
  - 지난주 모의 체결이 없으면 보내지 않습니다. **이메일 인증**을 마친 계정에만 보내며, **전체 알림**과 **이메일 채널**이 켜져 있어야 합니다(이메일 채널이 꺼져 있으면 토글 아래에 안내가 뜹니다).
  - 행동을 돌아보는 피드백이며 종목 추천이나 매매 제안은 들어 있지 않습니다.
  - **그만 받기**: 메일 맨 아래 **"수신 거부"** 링크를 누르면 **로그인 없이** 확인 화면이 열리고, "수신 거부" 버튼을 누르면 주간 리포트 이메일만 꺼집니다(다른 알림 설정은 그대로). 링크를 여는 것만으로는 꺼지지 않습니다. Gmail·Apple Mail 등 메일 앱 상단의 **"수신 거부" 버튼**도 같은 동작을 합니다. 다시 받으려면 이 화면에서 토글을 켜세요. 메일의 "알림 설정" 링크(로그인 필요)로도 끌 수 있습니다.
  - 이메일이라 **방해 금지 시간과 무관**합니다. 같은 주의 리포트는 한 번만 보냅니다(메일 서버 일시 장애면 30분 간격으로 최대 3번까지 다시 시도).
- 푸시는 monticker 모바일 앱으로 전달되며, 앱에 등록된 기기가 없으면 이메일이 켜져 있을 때 이메일로 대신 보냅니다.

### 21.3 관심 분야 (`/settings/interests`)

온보딩에서 고른 관심 분야와 사용 방식을 바꿉니다.

- 관심 분야를 고르면 홈의 섹터 히트맵과 이벤트 피드에서 그 분야가 **앞쪽에 "관심" 표시와 함께** 보입니다. 원래 보이던 항목 안에서 순서만 바꾸고, 숨기는 항목은 없습니다.
- **"관심 분야 순"** 스위치로 이 정렬을 끌 수 있습니다(홈 패널 머리의 칩과 같은 설정).
- 알림 화면 이력에서는 **"관심 분야"** 필터 칩으로 관련 종목 알림만 골라 볼 수 있습니다. 푸시·이메일로 보내는 알림의 양은 바뀌지 않습니다.
- 분야별로 어떤 업종 이름을 묶는지 화면에서 확인할 수 있습니다. 업종 이름으로 판정하는 근사라 넓은 업종은 관련 없는 종목이 함께 앞에 올 수 있고, 배당주·ETF는 업종으로 구분할 수 없어 정렬에 쓰지 않습니다.
- 투자 추천이 아니라 정보를 보는 순서를 바꾸는 기능입니다.

## 22. 구독 플랜

`/subscription` — 내 계정 메뉴 → "구독"으로 들어갑니다.

| 플랜 | 월 요금 | 화면에 표시되는 포함 내용 |
|------|---------|------|
| **무료** | 0원 | 기본 시세 조회, 관심종목 10개, 알림 3개 |
| **Pro** | 9,900원 | 무제한 알림, AI 요약, 포트폴리오 분석 |
| **Quant** | 29,900원 | Quant Lab 전체, 전략 마켓 수익 분배, 백테스트 우선 실행 |

- 플랜별 실제 이용 범위(기능 제한)는 아직 확정 전입니다. 실전투자 연동은 본인 키를 등록하는 방식(BYOK)이며, 증권사 수수료는 별도입니다.
- "무료로 시작"은 즉시 적용됩니다. 유료 플랜은 **토스페이먼츠 자동결제 카드**를 등록한 뒤 고릅니다. 결제 연동이 준비되지 않은 환경에서는 "결제 설정이 올바르지 않습니다"가 표시되며, 이 경우 유료 플랜은 아직 이용할 수 없습니다.
- 현재 플랜, **다음 결제일**, 결제 수단, 결제 내역(결제 완료 / 실패 / 환불 / 만료)을 볼 수 있습니다. 자동결제 카드가 없으면 만료일에 갱신 결제가 되지 않는다고 안내됩니다.
- 구독 해지와 카드 해지는 같은 화면에서 합니다. 해지해도 결제 기간이 끝날 때까지 이용할 수 있습니다.
- **연간 결제**와 카드 변경(교체)은 **준비 중**입니다. 환불 정책은 법률 검토 후 확정됩니다.

## 24. 자주 묻는 질문

**Q. 실제 돈으로 거래할 수 있나요?**
기본 상태에서는 아니요 — 모의투자 계좌만 사용되며 어떤 화면에서도 실제 자금이 오가지 않습니다. 본인 명의의 증권사 API 키를 [실전투자](#19-실전투자-증권사-계좌-연동) 메뉴에서 직접 연동한 경우에만, 실전투자 화면에서 넣은 주문이 실제 계좌로 나갑니다. 종목 화면의 주문 패널은 실제 주문을 보내지 않습니다. monticker는 증권사가 아니며 여러분의 돈을 보관하지 않습니다.

**Q. 지금 보고 있는 게 모의 계좌인지 실계좌인지 어떻게 구분하나요?**
상단 바의 계좌 칩을 보세요. 노란 점의 "모의투자 계좌"는 가상 계좌이고, **주황색 "실전 계좌"**는 실제 증권사 계좌입니다. 실전 화면에는 경고 배너도 함께 붙습니다.

**Q. AI가 알아서 사고팔아 주나요?**
아니요. AI는 방향(매수/매도/보류)과 근거만 제안하고, 수량·가격을 정하거나 주문을 넣지 않습니다. "승인"을 눌러도 주문이 나가지 않습니다.

**Q. 자동 주문 규칙이나 퀀트 전략이 제 실계좌로 주문을 내나요?**
아니요. 자동 주문 규칙은 모의투자 계좌에만 주문하고, 퀀트 전략의 신호는 주문을 내지 않습니다. 실계좌에서 자동으로 나가는 주문은 본인이 직접 등록한 [실전 조건부 주문](#195-조건부-주문--손절--익절--oco)뿐입니다.

**Q. 실전 주문이 '결과 확인 중'으로 떠요. 다시 내야 하나요?**
아니요, **다시 내지 마세요.** 증권사 응답을 받지 못해 체결 여부를 확인하는 중이며, monticker는 자동으로 재전송하지 않습니다. 결과가 확정되면 알림이 옵니다. "증권사에서 확인"으로 바뀌면 증권사 앱에서 체결 여부를 직접 확인하세요.

**Q. 조건부 주문(손절/익절)은 증권사 앱의 예약주문과 같은 건가요?**
비슷하지만 다릅니다. monticker가 가격을 감시하다가 조건이 충족되면 그 시점에 리스크 한도 검사를 거쳐 주문을 넣습니다. 따라서 monticker 서버가 동작 중이고 실시간 시세가 연결돼 있을 때만 발동하며, 리스크 한도에 걸리면 조건이 충족돼도 주문이 거부될 수 있습니다.

**Q. 모의 지정가 주문이 왜 아직 체결되지 않았나요?**
모의 지정가는 최신 1분봉 종가가 지정가에 닿아야 체결됩니다. 1분 안에서 잠깐 스친 가격에는 체결되지 않을 수 있고, 장 마감 후처럼 시세가 멈춰 있으면 기다립니다. 처리는 가격 우선이 아니라 접수 순이지만, 가격이 닿으면 대기 순번과 관계없이 함께 체결됩니다([8.2](#82-지정가-주문이-체결되는-방식)).

**Q. 리스크 한도를 올렸는데 바로 적용되지 않아요.**
한도를 완화하거나 리스크 체크를 끄는 변경은 **24시간 뒤**에 적용됩니다. 리스크 화면의 "적용 대기 중인 변경"에서 확인하거나 취소할 수 있습니다. 한도를 엄격하게 바꾸는 것은 바로 적용됩니다.

**Q. 호가창이 "Mock"으로 표시되는데 왜 그런가요?**
실시간 증권사 API 키가 설정되지 않은 환경에서는 현재가 기준 시뮬레이션 호가를 보여 줍니다. 가격 흐름을 학습하는 데는 충분하지만 실제 호가와 다를 수 있습니다. 홈의 지수에 "(모의)"가 붙는 것도 같은 이유입니다.

**Q. Quant Lab 백테스트 결과의 신뢰도가 D인데 사용해도 되나요?**
사용은 가능하지만, 거래 횟수나 검증 기간이 부족해 결과가 우연일 가능성이 큽니다. 기간을 늘리거나 조건을 완화해 거래 횟수를 늘린 뒤 다시 검증해 보세요.

**Q. 투자 행동/생존 점수가 낮으면 어떻게 해야 하나요?**
점수 자체는 매매를 막지 않습니다. 피드백과 세부 지표(계획 준수율, 손절 준수율)를 참고해 다음 거래 습관을 조정해 보는 용도로 쓰세요.

**Q. 차트에 그린 선이 다른 컴퓨터에서는 안 보여요.**
그리기 도구로 그린 것과 화면 설정은 이 브라우저에만 저장됩니다. 기기 간 동기화는 아직 지원하지 않습니다.

**Q. "준비 중" 표시는 무엇인가요?**
디자인은 들어갔지만 기능은 아직 동작하지 않는 요소입니다. 누르거나 바꿔도 아무 일이 일어나지 않으며, 실제처럼 보이는 숫자 대신 `—`나 빈 상태로 표시합니다.

**Q. 용어가 어려운데 어디서 설명을 볼 수 있나요?**
[주식 도메인 지식 백과](../stock-knowledge/README.md)와 [용어집](../domain/glossary-and-domain-knowledge.md)에 RSI, MACD, VaR, Kelly Criterion 등 화면에 나오는 대부분의 용어가 설명되어 있습니다.
