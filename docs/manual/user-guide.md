# monticker 사용자 매뉴얼

monticker는 실시간 시세를 단순히 보여주는 앱이 아니라, **"지금 무슨 일이 일어나고 있는지"**를 보여주고, 모의투자로 안전하게 연습하며, 나만의 투자 전략을 직접 검증해볼 수 있는 종합 투자 학습 플랫폼입니다. 이 문서는 모든 화면과 기능을 처음부터 끝까지 설명합니다.

> ⚠️ monticker의 분석·점수·신호·AI 요약·주문 제안은 모두 **교육 및 시뮬레이션 목적의 참고 정보**이며 투자 자문이 아닙니다. 과거 성과는 미래 수익을 보장하지 않습니다. 실제 투자 판단과 책임은 본인에게 있습니다.
>
> 기본 상태에서는 어떤 화면에서도 실제 돈이 오가지 않습니다. 단, **[14. 실전투자](#14-실전투자-증권사-계좌-연동)** 메뉴에서 본인 명의의 증권사 API 키를 직접 연동하면 그 계좌로 실제 주문이 나갑니다. 이 기능은 현재 실계좌 검증과 법률 검토가 완료되지 않은 상태이니, 연동 전에 해당 섹션의 주의사항을 반드시 읽어주세요.

## 1. 시작하기

### 1.1 회원가입 / 로그인

상단 네비게이션 우측의 로그인 버튼을 누르면 회원가입(`/signup`) 또는 로그인(`/login`) 화면으로 이동합니다. 이메일·비밀번호·닉네임으로 가입하거나 **Google · 카카오 · 네이버 계정으로 바로 시작**할 수 있습니다. 이메일 가입 시에는 인증 메일이 발송되며, 비밀번호를 잊으면 로그인 화면의 "비밀번호 찾기"(`/forgot-password`)로 재설정 링크를 받을 수 있습니다. 로그인 시 모의투자용 가상 계좌가 자동으로 생성됩니다(기본 1,000만원).

처음 로그인하면 짧은 온보딩 안내(관심종목 추가 → 가격 알림 → 조건부 주문 → AI 제안)가 한 번 표시됩니다. 건너뛰어도 됩니다.

로그인하지 않아도 스크리너·종목 상세·뉴스 등 시세 조회 기능은 모두 사용할 수 있습니다. 모의투자, 관심종목, Quant Lab, 지갑 등 **개인화된 기능**은 로그인이 필요합니다.

### 1.2 전체 화면 한눈에 보기

상단 네비게이션 바에서 모든 주요 화면으로 이동할 수 있습니다.

```
스크리너

투자 도구 ▾    Quant Lab · 백테스팅 · 체결엔진 · 리스크 · Analytics
내 자산 ▾      포트폴리오 · 실전투자 · 지갑 · 관심종목 · 정산

[검색창]                          [알림]  [프로필 ▾ 구독 · 설정 · 로그아웃]
```

화면이 좁으면(모바일) 우측 햄버거 메뉴(☰)로 동일한 메뉴가 모입니다. 우측 상단의 해/달 아이콘으로 라이트/다크 테마를 전환할 수 있고, 글자 크기·고대비·캔들 색 구성은 [18. 설정](#18-설정)에서 바꿀 수 있습니다.

## 2. 스크리너 (메인 화면)

`/` — monticker에 접속하면 가장 먼저 보이는 화면입니다. 지금 시장에서 활발히 움직이는 종목을 실시간으로 보여줍니다.

### 2.1 화면 구성

```
스크리너                              ● 실시간

[실시간 차트] [급등·급락] [외국인·기관 동향]   ← 탭

[전체] [국내] [해외]                          ← 시장 필터
[거래대금순] [거래량순] [급상승] [급하락]      ← 정렬

순위  종목명         현재가      등락률    거래량       거래대금
1     삼성전자       71,200원   +2.1%    1,839,200    1,308억
2     SK하이닉스     182,500원  -0.8%    920,400      1,680억
...
```

### 2.2 탭 사용법

- **실시간 차트**: 선택한 정렬 기준(거래대금순/거래량순/급상승/급하락)으로 전 종목 랭킹을 보여줍니다.
- **급등·급락**: 자동으로 "급상승" 정렬로 전환되어 가장 많이 오른 종목 순으로 보여줍니다.
- **외국인·기관 동향**: 매수/매도 비중 바(buyRatio/sellRatio)를 함께 보여줘 수급 흐름을 가늠할 수 있습니다.

### 2.3 실시간 갱신

화면 상단의 초록색 점(● 실시간)은 WebSocket 연결 상태를 보여줍니다. 연결되어 있으면 가격이 별도 새로고침 없이 자동 갱신됩니다. 랭킹 자체는 10초 주기로 재계산됩니다.

### 2.4 종목 클릭

종목명을 클릭하면 해당 종목의 [상세 화면](#3-종목-상세)으로 이동합니다.

### 2.5 더 보기

테이블 하단까지 스크롤하면 다음 페이지가 자동으로 로드됩니다(무한 스크롤).

## 3. 종목 상세

`/stocks/{종목코드}` — 종목명을 클릭하거나 검색을 통해 진입하는, monticker에서 가장 정보 밀도가 높은 화면입니다.

### 3.1 검색으로 종목 찾기

네비게이션 바의 검색창에 종목명이나 코드를 입력하면 자동완성 목록이 뜹니다. (`/stocks/search`에서도 동일하게 검색 가능)

### 3.2 화면 구성

```
종목명 (코드)
현재가  등락률  거래량  시가총액

[실시간 차트]                    [호가창]
 1분봉 / 5분봉 / 1일봉             [종목 점수]  (국내 종목)
 RSI · MACD · VWAP 오버레이 토글    [투자자 동향] (국내 종목)
[거래량 차트]

[AI 요약]
[이벤트 타임라인]
[뉴스 패널]
[알림 설정]
[커뮤니티 댓글]
[관심종목 추가] [모의 매수] [모의 매도]
```

- **AI 요약**: 최근 이벤트·뉴스·가격 동향을 바탕으로 자동 생성된 한 문단 요약입니다. 참고용이며, 요약에 인용된 뉴스·이벤트는 "뉴스 보기"·"이벤트 보기"로 원문을 확인할 수 있습니다. 한 시간에 일정 횟수까지만 생성됩니다.
- **종목 점수**: 국내(KOSPI/KOSDAQ) 종목에 한해 재무 지표 기반 밸류에이션 점수를 보여줍니다. 해외 종목은 제공되지 않습니다.
- **투자자 동향**: 국내 종목의 개인·외국인·기관 매매 동향입니다. 증권사 API 키가 설정된 환경에서만 실데이터가 표시됩니다.
- **커뮤니티 댓글**: 이 종목에 대한 다른 사용자의 의견입니다. 자세한 내용은 [3.8](#38-종목-커뮤니티-댓글).

### 3.3 차트 보는 법

- 캔들 주기를 1분/5분/1일 중 선택할 수 있습니다.
- 차트 위 토글 버튼으로 **RSI**, **MACD**, **VWAP**(거래량가중평균가격) 오버레이를 켜고 끌 수 있습니다.
- 차트 위에는 가격급등·거래량급증·뉴스 발생 같은 **이벤트 마커**가 표시됩니다. 마커를 클릭하면 상세 내용을 볼 수 있습니다.

> 💡 monticker의 핵심 가치는 "가격이 왜 움직였는가"를 보여주는 것입니다. 단순히 가격만 보지 말고 이벤트 마커와 뉴스 패널을 함께 확인하세요.

### 3.4 호가창

매도호가(위, 빨강 계열) 10단계와 매수호가(아래, 파랑 계열) 10단계를 보여줍니다. 데이터 출처는 화면 한쪽에 표시됩니다.

- **KIS 실시간**: 한국투자증권 API 키가 설정된 경우 진짜 실시간 호가
- **Yahoo Finance**: 15분 지연 시세 기반 추정 호가
- **Mock**: 현재가 기준 시뮬레이션 호가 (기본값)

어느 경우든 실제 매매 의사결정에는 지연이나 시뮬레이션이 섞여 있을 수 있다는 점을 참고하세요.

### 3.5 이벤트 타임라인

해당 종목에서 발생한 가격급등, 거래량급증, 뉴스, 공시 등을 시간순으로 보여줍니다. 각 이벤트는 캔들 차트와 같은 색 코드를 사용해 차트의 어느 지점과 연관되는지 직관적으로 파악할 수 있습니다.

### 3.6 알림 설정

종목 상세 화면 하단에서 가격 알림을 등록할 수 있습니다.

```
알림 유형: [가격 이상] [가격 이하] [거래량 급증]
          [RSI 과매도] [RSI 과매수]
          [이동평균 상향 돌파] [이동평균 하향 이탈]
          [보유종목 하락 (모의투자)]
기준값:   ___________   ← 유형에 따라 가격 / RSI 값 / 이동평균 기간 / 하락률
[알림 저장]
```

조건이 충족되면 모바일 푸시 알림(Expo)과, 설정에 따라 이메일로도 전달됩니다. 같은 알림은 10분 안에 중복 발송되지 않습니다. 알림 수신 채널은 [18. 설정](#18-설정)에서 바꿀 수 있습니다.

### 3.7 모의 매수 / 모의 매도

화면 상단의 매수/매도 버튼을 누르면 주문 모달이 뜹니다. 자세한 사용법은 [6. 모의투자](#6-모의투자-paper-trading) 섹션을 참고하세요.

### 3.8 종목 커뮤니티 댓글

종목 상세 하단에서 이 종목에 대한 의견을 남기고 다른 사용자의 의견을 읽을 수 있습니다. 로그인이 필요합니다.

- 댓글에는 최근 발생한 **이벤트를 태그**로 붙일 수 있어 "어떤 급등/뉴스에 대한 의견인지"를 함께 남길 수 있습니다.
- **매수·매도 권유는 게시할 수 없습니다.** "지금 사세요", "무조건 팔아라" 같은 표현은 자동으로 걸러지며, 판정이 불확실한 경우에도 게시가 거부됩니다. 종목에 대한 분석·질문·정보 공유는 자유입니다.
- 부적절한 댓글은 각 댓글의 신고 버튼으로 사유와 함께 신고할 수 있습니다. 신고는 접수만 되며 자동으로 삭제되지는 않습니다.

> 커뮤니티 댓글은 다른 사용자의 개인 의견이며 monticker가 보증하거나 추천하는 내용이 아닙니다.

## 4. 관심종목

`/watchlist` — 자주 보는 종목을 그룹으로 묶어 관리합니다.

### 4.1 그룹 만들기

```
새 그룹 이름: [____________] [그룹 추가]
```

"기술주", "배당주"처럼 원하는 기준으로 여러 그룹을 만들 수 있습니다.

### 4.2 종목 추가

종목 상세 화면의 "관심종목 추가" 버튼으로 원하는 그룹에 종목을 담습니다. 각 종목에는 메모를 남길 수 있습니다.

### 4.3 그룹별 보기

`/watchlist` 화면에서 그룹별로 담긴 종목과 메모를 한눈에 볼 수 있습니다.

## 5. 알림

`/alerts` — 등록한 모든 알림 규칙과 발생 이력을 관리합니다.

### 5.1 알림 통계

화면 상단에서 활성 알림 개수, 최근 발생 건수 등 요약 통계를 볼 수 있습니다.

### 5.2 알림 규칙 종류

| 유형 | 조건 |
|------|------|
| 가격 이상 | 지정 가격을 넘으면 알림 |
| 가격 이하 | 지정 가격 아래로 떨어지면 알림 |
| 거래량 급증 | 평소 대비 거래량이 비정상적으로 늘면 알림 (기준값 입력 불필요) |
| RSI 과매도 / 과매수 | RSI(14)가 지정값 아래로 / 위로 가면 알림 (예: 30 이하, 70 이상) |
| 이동평균 상향 돌파 / 하향 이탈 | 현재가가 지정 기간(예: 20일) 이동평균선을 위로 뚫거나 아래로 떨어지면 알림 |
| 보유종목 하락 (모의투자) | 모의투자로 보유 중인 종목이 지정 비율 이상 떨어지면 알림. 실전투자 계좌 보유종목에는 적용되지 않습니다 |

같은 알림이 반복적으로 울리지 않도록 한 번 발동하면 **10분간 동일 알림이 다시 울리지 않습니다(쿨다운)**.

## 6. 모의투자 (Paper Trading)

monticker의 모의투자는 실제 돈이 들지 않는 가상 계좌(기본 1,000만원)로 매매를 연습하는 기능입니다. **"즉시 체결"** 방식으로, 종목 상세 화면에서 바로 매수/매도할 수 있습니다.

### 6.1 매수하기

종목 상세 화면에서 [매수] 버튼을 누르면 주문 모달이 뜹니다.

```
삼성전자 (005930)
현재가: ₩71,200
가용 현금: ₩9,500,000

수량: [ − ]  [ 10 ]  [ + ]   최대 133주
주문 금액: ₩712,000
주문 후 잔고: ₩8,788,000

[매수 ₩712,000]
```

수량을 직접 입력하거나 +/− 버튼, "최대 N주" 버튼으로 가용 현금 한도까지 한 번에 채울 수 있습니다. 매수 버튼을 누르면 현재가에 즉시 체결됩니다.

### 6.2 체결 후 — 투자 영수증

매수/매도가 체결되면 자동으로 **영수증 화면**이 뜹니다.

```
삼성전자 10주 매수 완료
체결 가격:  71,200원
주문 금액:  712,000원
체결 금액:  712,000원
수수료:        107원
차감 금액:  712,107원
체결 후 잔고: 8,787,893원
결제 상태:  ✓ SETTLED

[매수 이유 기록하기 →]
```

### 6.3 매수 이유 기록 (감정 태그)

영수증 화면에서 "매수 이유 기록하기"를 누르면 9가지 감정 중 하나를 선택할 수 있습니다.

```
[💪 확신] [🌱 장기 투자] [📰 뉴스 보고] [⚖️ 비중 조절]
[😰 불안] [🚀 급등 놓칠까봐] [👥 따라삼] [💧 물타기] [🔮 직감]

메모 (선택): ___________
[저장하기]
```

매번 기록할 필요는 없습니다("건너뛰기" 가능). 하지만 기록을 쌓을수록 [투자 지갑](#9-투자-지갑-wallet)에서 "어떤 감정으로 산 종목이 실제로 더 좋은 성과를 냈는지" 본인의 데이터로 확인할 수 있습니다.

### 6.4 매도하기

보유 종목 화면이나 종목 상세에서 [매도] 버튼을 누르면 동일한 방식으로 매도 주문을 넣을 수 있습니다. 보유 수량을 초과해 매도할 수 없습니다.

### 6.5 거래 내역 / 보유 종목

`/portfolio` 화면에서 현재 보유 종목과 평가손익, 최근 거래 내역을 확인할 수 있습니다.

## 7. 체결엔진

`/matching` — 실제 거래소처럼 동작하는 **호가창 기반 체결**을 체험할 수 있는 화면입니다. 6장의 "즉시 체결" 모의투자와는 별도의 독립적인 주문 시스템입니다.

### 7.1 주문 입력

```
종목: [삼성전자 ▾]      매수/매도: [매수] [매도]
주문 유형: [시장가] [지정가]      수량: [10]

지정가 (원): [70000]   ← 지정가 선택 시에만 표시

[리스크 사전 확인]   [매수 주문]
```

### 7.2 시장가 vs 지정가

- **시장가**: 현재가에 즉시 체결됩니다.
- **지정가**: 내가 원하는 가격을 입력합니다. 그 가격에 거래 상대가 있으면 즉시 체결되고, 없으면 "미체결" 상태로 호가창에 등록되어 대기합니다.

### 7.3 리스크 사전 확인

주문을 넣기 전에 "리스크 사전 확인" 버튼을 누르면, 실제로 체결하지 않고 5가지 리스크 한도를 통과하는지 미리 확인할 수 있습니다.

```
✅ 리스크 한도 통과
✓ 일일 손실 한도   오늘 손실 -1.2% / 한도 -3.0%
✓ 종목 집중도      삼성전자 비중 18.4% / 한도 30%
✓ VaR 한도         2.1% / 한도 5.0%
```

한도를 넘으면 다음과 같이 표시되며, 실제 주문도 자동으로 거부됩니다.

```
🚫 일일 손실 한도 초과
✗ 일일 손실 한도   오늘 손실 -3.4% / 한도 -3.0%
```

### 7.4 미체결 주문 / 체결 이력

화면 우측에서 현재 대기 중인 지정가 주문을 확인하고 취소할 수 있으며, 아래쪽에서 최근 체결 내역(체결가, 수수료)을 확인할 수 있습니다.

### 7.5 AI 주문 제안

주문 폼 옆의 **"제안 받기"** 버튼을 누르면 AI가 선택한 종목의 최근 이벤트·뉴스·지표를 읽고 **매수 / 매도 / 보류** 중 하나의 방향과 그 근거를 제안합니다.

```
🤖 매수 제안                                    [승인] [거부]
근거: 거래량이 5분 평균 대비 4.8배 급증했고, HBM 공급 확대 뉴스가
      동반됐습니다. RSI 62로 과매수 구간은 아닙니다.

이 제안은 투자자문이 아니며, 모의투자 참고용 시뮬레이션 정보입니다.
```

꼭 알아둘 점:

- AI는 **수량과 가격을 정하지 않습니다.** 방향과 이유만 제안합니다.
- **"승인"을 눌러도 주문이 나가지 않습니다.** 승인은 "이 제안을 참고하겠다"는 기록일 뿐이며, 실제 주문은 평소처럼 주문 폼에서 수량·가격을 직접 입력하고 주문 버튼을 눌러야 합니다. 그 주문도 똑같이 리스크 한도 검사를 거칩니다.
- 제안은 요청할 때만 생성되며, 자동으로 계속 생성되지 않습니다.

같은 기능이 [실전투자 주문 화면](#143-주문하기)에도 있으며, 그쪽은 실제 계좌가 걸리는 만큼 더 강한 면책 문구가 붙습니다.

## 8. 리스크

`/risk` — 내 모의투자 계좌의 위험 노출도를 한눈에 확인하고, 한도를 직접 설정하는 화면입니다.

### 8.1 현재 리스크 수준

```
총 자산: 9,980,301원      오늘 손익: +12,400원      미체결 주문: 2건

일일 손실률       [■■░░░░░░░░] 0.4% / 3.0%
최대 집중도(삼성전자) [■■■■░░░░░░] 18.4% / 30.0%
추정 VaR (95%)    [■■■░░░░░░░] 2.1% / 5.0%
1시간 주문 빈도   [■░░░░░░░░░] 1회 / 5회
```

막대그래프 색상이 초록(안전) → 노랑(주의) → 빨강(위험)으로 바뀌며 한도에 가까워질수록 위험을 직관적으로 보여줍니다.

### 8.2 한도 직접 설정

```
일일 손실 한도(%):     [3.0]
종목당 최대 비중(%):   [30.0]
VaR 한도(%):           [5.0]
최대 보유 종목 수:     [10]
1시간 최대 주문 수:    [5]
☑ 리스크 체크 활성화

[한도 저장]
```

초보자는 기본값을 그대로 두는 것을 권장합니다. 충분히 익숙해지면 본인의 위험 허용도에 맞게 직접 조정하세요. 한도를 비활성화할 수도 있지만, 그 경우 체결엔진의 사전 차단 기능이 동작하지 않습니다.

> 💡 이 한도는 모의투자 전용 학습 장치입니다. 실제 투자에는 적용되지 않습니다.

## 9. 투자 지갑 (Wallet)

`/wallet` — 모의투자 계좌의 "내 돈이 지금 어떤 상태에 있는지"를 보여주는 화면입니다. 세 개의 탭으로 구성됩니다.

### 9.1 돈의 이동 지도

```
총 자산: 9,980,301원

💵 사용 가능 현금   [■■■■■■░░░░] 5,573,976원  (55.8%)
🔒 주문 예약금      [░░░░░░░░░░]         0원   (0%)
📈 보유 주식 평가액 [■■■░░░░░░░] 4,406,325원  (44.2%)
⏳ 정산 대기 금액   [░░░░░░░░░░]         0원   (0%)
```

"왜 출금 가능한 금액이 총 자산보다 적은지"를 직관적으로 보여줍니다. 막대그래프 비율로 자산 구성을 한눈에 파악할 수 있습니다.

### 9.2 원장 타임라인

모든 입금/매수/매도/수수료 이벤트를 시간순으로 보여줍니다.

```
✅ 체결   삼성전자 10주 매수 체결         -712,107원   잔고 8,787,893원
🎯 정산완료  SK하이닉스 5주 매도 정산     +912,500원   잔고 9,700,393원
```

### 9.3 투자 점수

```
[투자 행동 점수]        [투자 생존 점수]
       95점                    80점
       A                        A

📋 피드백
• 감정적 충동 거래 없음 (+10점)
```

- **투자 행동 점수**: 오늘 하루 충동매매·과다거래·추격매수가 없었는지 평가합니다.
- **투자 생존 점수**: 지금 포트폴리오가 한 종목에 너무 쏠려 있거나 현금이 너무 적지 않은지 평가합니다.

두 점수는 서로 다른 것을 측정하므로 함께 확인하는 것이 좋습니다. 점수 하단에는 항상 "모의투자 전용 교육용 피드백이며 투자 조언이 아니다"라는 안내가 표시됩니다.

### 9.4 주문 리플레이

`/wallet/replay` — 특정 날짜를 골라 그날의 모든 매매를 다시 따라가 볼 수 있습니다.

```
[2026-06-30 ▾]

총 손익: +12,300원      거래 횟수: 4회

09:10  📥 매수   카카오 5주 @52,000원
09:13  📤 매도   카카오 5주 @53,100원   +2.1%
10:20  📥 매수   네이버 3주 @210,000원
15:30  📤 매도   네이버 3주 @212,500원  +1.2%
```

하루의 투자 과정을 게임 로그처럼 복기하며 "오늘 내가 무엇을 잘했고 무엇을 고쳐야 하는지" 돌아볼 수 있습니다.

## 11. 백테스팅

`/backtest` — 3가지 내장 전략을 과거 데이터에 적용해 성과를 시뮬레이션합니다.

### 11.1 사용법

```
종목: [삼성전자 ▾]
전략: [이동평균 크로스오버] [RSI 과매수/과매도] [EMA 돌파 전략]
기간: [2026-05-24] ~ [2026-06-22]
초기 자본: [10,000,000]
손절(%): [5]   익절(%): [10]

[백테스트 실행]
```

| 전략 | 매수 조건 |
|------|----------|
| 이동평균 크로스오버 | 단기 이동평균이 장기 이동평균을 아래에서 위로 돌파할 때 |
| RSI 과매수/과매도 | RSI가 30 이하 구간을 벗어날 때 매수, 70 이상 구간을 벗어날 때 매도 |
| EMA 돌파 전략 | 거래량 급증 + 상승 추세 동시 충족 시 |

### 11.2 결과 읽는 법

```
총 수익률: +18.4%        연환산 수익률: +22.1%
Sharpe Ratio: 1.32        최대 낙폭(MDD): -9.8%
승률: 58.3%               손익비: 1.45
거래 횟수: 24회           평균 보유: 3.2일
```

수익률만 보지 말고 **MDD(최대 낙폭)**를 함께 확인하세요 — "이 전략을 따라 했다면 중간에 최악의 경우 얼마나 손실을 견뎌야 했는가"를 보여주는 핵심 지표입니다.

## 12. Quant Lab

`/quant-lab` — 코딩 없이 나만의 투자 규칙(룰셋)을 만들고 검증하는 공간입니다.

### 12.1 보관함

```
Quant Lab                          [+ 새 룰셋]

거래량 돌파 단기 전략   [백테스트 완료]  v2
  수정 | 백테스트 | 삭제
```

내가 만든 모든 룰셋을 목록으로 보여줍니다. 각 룰셋은 작성 중/백테스트 완료/운용 중 등의 상태를 가집니다.

### 12.2 룰셋 만들기

`/quant-lab/builder` — "+ 새 룰셋" 버튼으로 진입합니다.

```
전략 이름: [거래량 돌파 단기 전략]
전략 설명: [거래량이 급증하며 이동평균을 돌파하는 종목 매수]

━━━ 매수 조건 ━━━  연산자: [AND] [OR]
[현재가 vs 이동평균 ▾] [초과 ▾]                    [✕]
[거래량 배율 ▾] [초과 ▾] 값: [2]                    [✕]
[RSI ▾] [사이 ▾] 값: [30] ~ [70]                    [✕]
+ 조건 추가

━━━ 매도 조건 ━━━  연산자: [AND] [OR]
[수익률 ▾] [이상 ▾] 값: [8]                         [✕]
[손실률 ▾] [이하 ▾] 값: [-4]                        [✕]
+ 조건 추가

포지션 사이징: 1회 매수에 총 자본의 [10] % 사용

[룰셋 저장 →]
```

### 12.3 사용 가능한 조건 지표

| 지표 | 의미 |
|------|------|
| 현재가 vs 이동평균 | 가격이 이동평균선 위/아래에 있는지 |
| 거래량 배율 | 평소 대비 거래량이 몇 배 늘었는지 |
| RSI | 과매수/과매도 상태 (0~100) |
| MACD 크로스 | 골든크로스(상승 전환)/데드크로스(하락 전환) |
| N일 가격변화율 | 최근 N일간 가격이 몇 % 변했는지 |
| 볼린저밴드 | 상단/하단 밴드 돌파 여부 |
| 수익률 / 손실률 | (매도 조건 전용) 현재 보유 포지션의 손익률 |

조건은 AND(모두 만족)/OR(하나만 만족) 연산자로 조합할 수 있습니다.

### 12.4 백테스트 실행하기

룰셋 상세 화면(`/quant-lab/{id}`)에서 종목과 기간을 선택해 백테스트를 실행합니다.

```
종목: [삼성전자 ▾]   시작일: [2024-01-01]   종료일: [2026-06-01]
초기 자본: [10,000,000]

[▶ 백테스트 실행]
수수료 0.015% + 슬리피지 0.1% 반영 · 과거 성과가 미래 수익을 보장하지 않습니다
```

### 12.5 결과와 신뢰도 점수

```
신뢰도 B    2024-01-01 ~ 2026-06-01

총 수익률: +24.1%       연환산 수익률: +14.2%
최대 낙폭(MDD): -11.3%  벤치마크 대비: +9.8%
승률: 56.2%             손익비: 1.38
거래 횟수: 18회          평균 보유: 4.1일

신뢰도 B — 전반적으로 신뢰할 수 있으나 더 긴 검증 기간이 필요합니다.
```

신뢰도는 단순 수익률이 아니라 "이 결과를 얼마나 믿을 수 있는가"를 알려줍니다.

| 등급 | 기준 |
|------|------|
| A | 거래 50회 이상 + 검증 기간 2년 이상 |
| B | 거래 20회 이상 + 검증 기간 1년 이상 |
| C | 거래 10회 이상 |
| D | 거래 10회 미만 — 과최적화 위험 높음 경고 |

신뢰도가 낮을수록(C, D) 결과를 맹신하지 말고 더 긴 기간으로 다시 검증해보세요.

### 12.6 포워드 테스트 — 실시간으로 검증하기

백테스트는 과거 데이터입니다. 룰셋 상세 화면(`/quant-lab/{id}`)에서 **"포워드 테스트 시작"**을 누르면 지금부터의 실제 시장 흐름으로 같은 규칙을 검증합니다.

```
포워드 테스트 14일차                      [포워드 테스트 중지]

발생 신호: 23개      가상 진입: 18개
평균 수익률: +1.2%   승률: 55.5%   (백테스트 예상 승률: 58.1%)

[자산 곡선 차트]
[신호 이력]  09-18 09:31  매수 신호 · 09-20 15:02  청산 신호 …
```

- 평가는 **장 마감 후 하루 한 번**(한국 시간 16:00) 이루어집니다. 장중에는 신호가 바로 보이지 않을 수 있습니다.
- 백테스트와 마찬가지로 **한 번에 한 종목**만 검증합니다.
- "신호 보기"를 켜면 새 신호가 발생할 때 화면에 실시간으로 표시됩니다("실시간 신호 연결됨").
- 백테스트 승률과 포워드 테스트 승률의 차이가 크면 과최적화를 의심하세요.

### 12.7 전략 마켓 — 공유하고 구독하기

`/quant-lab/market` — 다른 사용자가 공유한 전략을 둘러보고 구독하거나, 내 룰셋을 공유하는 곳입니다.

**내 룰셋 공유하기**: 룰셋 상세에서 "전략 마켓에 공유"를 누르고 구독료(0이면 무료)를 정합니다.

**전략 구독하기**: 마켓 목록에서 "구독"을 누르면 그 전략의 **신호**(매수/매도/청산 발생 여부)를 받아볼 수 있습니다.

꼭 알아둘 점:

- 구독자는 **신호만** 받습니다. 어떤 조건으로 만들어진 전략인지(룰셋 내용)는 공개되지 않으며, 제작자만 볼 수 있습니다. 반대로 내 룰셋을 공유해도 규칙 자체는 노출되지 않습니다.
- 전략은 "수익률 1위"가 아니라 **검증 기간과 신뢰도** 기준으로 보세요. 마켓의 어떤 전략도 수익을 보장하지 않으며, 신호를 따를지는 본인의 판단입니다.
- 유료 구독 결제는 현재 준비 중이라 "유료 구독 결제 연동 준비 중입니다"로 표시됩니다. 무료 전략은 바로 구독할 수 있습니다.

### 12.8 제작자 수익

`/quant-lab/earnings` — 내가 공유한 전략의 구독 현황과 수익을 확인합니다. 구독료의 **70%가 제작자 몫**으로 적립되며, 출금 가능 잔액이 10,000원 이상이면 출금을 신청할 수 있습니다. (결제 연동이 완료되기 전까지는 실제 정산이 발생하지 않습니다.)

2026-04-12 ~ 2026-06-20

선택한 종목의 최근 차트에서 이중바닥, 이중천장, 헤드앤숄더, 상승/하락 삼각형 같은 전형적인 차트 패턴을 자동으로 찾아줍니다. 완성도(%) 점수가 높을수록 패턴이 더 명확합니다.

## 14. 실전투자 (증권사 계좌 연동)

`/brokerage` — 본인 명의의 **한국투자증권** 또는 **토스증권** 계좌를 API 키로 연동해 실제 주문을 넣는 화면입니다. 상단 메뉴 "내 자산 → 실전투자"로 진입합니다.

> ⚠️ **이 메뉴에서 넣는 주문은 실제 증권사 계좌로 체결됩니다.** 실제 돈이 움직입니다.
>
> - monticker는 증권사가 아닙니다. 여러분이 증권사에서 직접 발급받은 API 키로 여러분을 대신해 주문을 전달하는 도구일 뿐이며, 자금을 보관하지 않습니다.
> - 이 기능은 현재 **실계좌 검증과 법률 검토가 완료되지 않은 상태**입니다. 실제 자금으로 사용하기 전에 소액으로 충분히 테스트하고, 한국투자증권의 경우 **모의투자 계좌**로 먼저 연동해 보세요.
> - 화면의 어떤 정보도 투자 자문이 아닙니다. 최종 판단과 책임은 본인에게 있습니다.

### 14.1 계좌 연동하기

`/brokerage/connect` — "증권사 계좌 연동" 화면에서 증권사를 고르고 키를 입력합니다.

```
증권사 선택:  ( ) 한국투자증권    ( ) 토스증권

한국투자증권 Open API 포털에서 발급받은
  App Key:      ______________
  App Secret:   ______________
  계좌번호:     숫자만 입력 (예: 1234567801)

[연동하기]
```

- **키 발급처**: 한국투자증권은 [KIS Developers](https://apiportal.koreainvestment.com), 토스증권은 토스증권 Open API 개발자 센터. 발급 절차는 각 증권사 안내를 따르며, 실명 인증이 필요합니다.
- **한국투자증권은 모의투자 계좌를 지원**합니다. 실계좌 키 대신 모의투자용 키를 등록하면 실제 돈 없이 전체 흐름을 연습할 수 있습니다. 토스증권은 모의투자 서버가 없어 실계좌로만 동작합니다.
- 입력한 키는 암호화되어 저장되며, 화면에 다시 표시되지 않습니다.
- 한 번에 하나의 계좌만 연동할 수 있습니다. 이미 연동돼 있으면 "이미 계좌가 연동되어 있습니다"로 안내됩니다.

**재인증**: 증권사 토큰이 만료되면 monticker가 자동으로 재발급을 시도합니다. 자동 재발급이 실패하면 실전투자 화면에 "재인증 필요" 배지가 뜨고, 연동 화면에서 키를 다시 입력하면 됩니다.

### 14.2 실전투자 대시보드

```
실전투자                         상태: 정상 연결 · 한국투자증권

총 평가금액  12,340,000원       가용 현금  3,200,000원

[보유종목]  [주문내역]  [정산내역]  [조건부 주문 페이지 →]
```

- **보유종목·잔고**는 증권사에서 실시간으로 가져옵니다. 증권사 응답이 늦으면 "증권사 응답이 없습니다. 잠시 후 자동으로 다시 시도합니다"가 표시되고 자동 재시도합니다.
- **주문내역**에서 대기 중인 주문을 취소할 수 있습니다. 취소도 실제 증권사에 전달됩니다.
- 증권사 장애 등으로 연결이 끊기면 실주문·잔고 조회가 잠시 막힙니다(503). 잠시 후 다시 시도하세요.

### 14.3 주문하기

`/brokerage/orders`

```
종목: [종목명 또는 코드 검색]      [매수] [매도]
주문 유형: [시장가] [지정가]      수량: [10]
지정가 (원): [70000]

예상 주문 금액: 700,000원         가용 현금: 3,200,000원

[🤖 제안 받기]                    [주문 제출]
```

주문 흐름은 모의투자 체결엔진과 같지만, 몇 가지가 다릅니다:

1. **입력 검증** — 수량은 1 이상의 정수, 매수는 가용 현금, 매도는 보유 수량을 넘을 수 없습니다. 넘으면 제출 전에 막힙니다.
2. **리스크 한도 검사** — 모의투자와 **같은 5가지 리스크 한도**([8. 리스크](#8-리스크)에서 설정한 값)를 통과해야 합니다. 통과하지 못하면 "리스크 게이트에 의해 주문이 차단되었습니다"와 함께 어떤 한도에 걸렸는지 표시되며, 증권사로 주문이 가지 않습니다.
3. **증권사 접수** — 통과하면 "증권사에 주문이 접수되었습니다"가 뜹니다. 체결 여부는 주문내역에서 확인합니다.

**AI 주문 제안**("제안 받기")은 [7.5](#75-ai-주문-제안)와 동일하게 동작합니다 — 방향과 근거만 제안하고, 승인해도 주문이 나가지 않으며, 제안 아래에는 "이 제안은 투자자문이 아니며, 실제 계좌에 대한 참고용 정보입니다"라는 고지가 붙습니다.

### 14.4 조건부 주문 — 손절 · 익절 · OCO

`/brokerage/conditional-orders` — 미리 정한 가격에 도달하면 자동으로 실제 주문을 제출하는 기능입니다.

```
조건부 주문 등록

종목: [종목명 또는 코드 검색]
모드:  ( ) 단일 조건      ( ) OCO (손절+익절)

[단일 조건]
  트리거 조건: [가격 이상] [가격 이하]    트리거 가격: [72000]
  발동 시 주문: [매수] [매도]  수량: [10]

[OCO]
  손절가 (이 가격 이하로 떨어지면 발동): [65000]
  익절가 (이 가격 이상 오르면 발동):     [78000]
  수량: [10]

[등록]

등록된 조건부 주문
  삼성전자  OCO  손절 65,000 / 익절 78,000  10주   대기 중   [취소]
```

- **단일 조건**: "가격이 X 이상/이하가 되면 매수/매도" 하나를 겁니다.
- **OCO (One-Cancels-Other)**: 손절가와 익절가를 동시에 걸어두고, 둘 중 하나가 먼저 발동하면 **나머지는 자동으로 취소**됩니다. 보유 종목의 리스크 관리에 씁니다.
- 조건이 충족되면 그 시점에 **리스크 한도 검사를 거친 뒤** 실제 주문이 제출됩니다. 한도에 걸리면 조건이 맞아도 주문은 거부되며, 등록 목록에서 상태로 확인할 수 있습니다.
- 조건부 주문은 만료일이 있습니다. 목록에서 만료일을 확인하세요.
- "주문이 체결되면 다음 주문을 넣는" 형태(OTO)는 지원하지 않습니다.

### 14.5 리밸런싱 — 목표 비중 맞추기

`/brokerage/rebalance` — 종목별 목표 비중을 정해두고, 현재 보유와의 차이(괴리)가 임계값을 넘는 종목만 골라 실제 주문으로 맞추는 기능입니다.

```
목표 비중                                    [최적 비중 계산해 채우기]
  삼성전자   40%
  NAVER      30%
  AAPL       30%      합계 100%
  [종목 추가 — 종목명 또는 코드 검색]

실행 임계값: [5]%   ← 괴리가 이 값 이상인 종목만 리밸런싱 대상
[목표 비중 저장]

괴리 미리보기
  삼성전자   목표 40%  현재 52%  괴리 +12%p  → 매도 ~1,480,000원
  NAVER      목표 30%  현재 27%  괴리  -3%p  → (임계값 미만, 건너뜀)
  AAPL       목표 30%  현재 21%  괴리  -9%p  → 매수 ~1,110,000원

[리밸런싱 실행]
```

1. 종목을 추가하고 비중을 입력합니다. 합계가 100%가 되어야 저장됩니다. "최적 비중 계산해 채우기"를 누르면 [13.1 포트폴리오 최적화](#131-포트폴리오-최적화)와 같은 계산으로 추천 비중이 채워집니다(종목 2개 이상 필요). 기대 수익률과 예상 변동성이 함께 표시됩니다.
2. **저장**해야 미리보기와 실행에 반영됩니다. 저장하지 않은 변경은 노란 경고로 표시됩니다.
3. **괴리 미리보기**로 어떤 종목이 얼마나 매수/매도될지 먼저 확인합니다. 임계값을 넘는 괴리가 없으면 "리밸런싱이 필요하지 않습니다"로 안내됩니다.
4. **리밸런싱 실행**을 누르면 대상 종목마다 실제 주문이 순서대로 제출됩니다. 각 주문은 개별적으로 리스크 한도 검사를 거치며, 한도에 걸린 주문은 그 건만 거부됩니다.

리밸런싱은 **직접 실행 버튼을 눌렀을 때만** 동작합니다. 정해진 주기에 자동으로 실행되지 않습니다.

## 15. 정산

`/settlement` — 모의투자 체결 건이 정산되는 과정을 보여줍니다. 실제 증시처럼 **체결 후 T+2 영업일**에 정산이 완료되며, 그 전까지는 "정산 대기" 상태로 [9.1 돈의 이동 지도](#91-돈의-이동-지도)의 "정산 대기 금액"에 잡힙니다.

```
모의투자 정산 내역            [전체] [대기 중] [정산 완료] [실패]

09-19  삼성전자  매수 10주   거래 금액 700,000   수수료(0.015%) 105   세금 0      순 정산액 -700,105   정산 완료
09-21  NAVER     매도  5주   거래 금액 900,000   수수료 135          세금 1,620   순 정산액 +898,245   대기 중
```

- 수수료 0.015%는 매수·매도 모두, 세금(증권거래세+농특세 0.18%)은 매도에만 붙습니다.
- 주말은 영업일에서 제외됩니다.
- 정산 내역이 없으면 "아직 정산 내역이 없습니다. 모의투자를 시작해보세요"가 표시됩니다.

실전투자 계좌의 정산은 증권사가 처리하며, [14.2 대시보드](#142-실전투자-대시보드)의 "정산내역" 탭에서 증권사 기준 내역을 볼 수 있습니다.

## 16. 구독 플랜

`/subscription` — 프로필 메뉴 → "구독"으로 진입합니다.

| 플랜 | 월 요금 | 포함 |
|------|---------|------|
| **무료** | 0원 | 기본 시세 조회, 관심종목 10개, 알림 3개 |
| **Pro** | 9,900원 | 무제한 알림, AI 요약, 포트폴리오 분석 |
| **Quant** | 29,900원 | Quant Lab 전체, 전략 마켓 수익 분배, 백테스트 우선 실행 |

- "무료로 시작"은 즉시 적용됩니다. 유료 플랜은 자동결제 카드를 등록한 뒤 선택하며, 결제는 토스페이먼츠를 통해 진행됩니다.

- 구독 해지와 자동결제 카드 해지는 같은 화면에서 할 수 있으며, 결제 이력(결제 완료 / 실패 / 환불 / 만료)이 아래에 표시됩니다.

## 20. 자주 묻는 질문

**Q. 실제 돈으로 거래할 수 있나요?**
기본 상태에서는 아니요 — 모의투자 계좌만 사용되며 어떤 화면에서도 실제 자금이 오가지 않습니다. 본인 명의의 증권사 API 키를 [실전투자](#14-실전투자-증권사-계좌-연동) 메뉴에서 직접 연동한 경우에만, 그 화면에서 넣은 주문이 실제 계좌로 나갑니다. monticker는 증권사가 아니며 여러분의 돈을 보관하지 않습니다.

**Q. AI가 알아서 사고팔아 주나요?**
아니요. AI는 방향(매수/매도/보류)과 근거만 제안하고, 수량·가격을 정하거나 주문을 넣지 않습니다. "승인"을 눌러도 주문이 나가지 않으며, 실제 주문은 항상 본인이 주문 폼에서 직접 실행해야 합니다.

**Q. 조건부 주문(손절/익절)은 증권사 앱의 예약주문과 같은 건가요?**
비슷하지만 다릅니다. monticker의 조건부 주문은 증권사에 예약을 걸어두는 것이 아니라, monticker가 가격을 감시하다가 조건이 충족되면 그 시점에 리스크 한도 검사를 거쳐 주문을 넣습니다. 따라서 monticker 서버가 동작 중일 때만 발동하며, 리스크 한도에 걸리면 조건이 충족돼도 주문이 거부될 수 있습니다.

**Q. 호가창이 "Mock"으로 표시되는데 왜 그런가요?**
실시간 증권사 API 키가 설정되지 않은 환경에서는 현재가 기준 시뮬레이션 호가를 보여줍니다. 가격 흐름을 학습하는 데는 충분하지만 실제 호가와 다를 수 있습니다.

**Q. Quant Lab 백테스트 결과의 신뢰도가 D인데 사용해도 되나요?**
사용은 가능하지만, 거래 횟수나 검증 기간이 부족해 결과가 우연일 가능성이 큽니다. 기간을 늘리거나 조건을 완화해 거래 횟수를 늘린 뒤 다시 검증해보세요.

**Q. 체결엔진(/matching)과 모의투자(매수/매도 버튼)는 뭐가 다른가요?**
일반 매수/매도 버튼은 항상 현재가에 즉시 전량 체결됩니다. 체결엔진은 실제 거래소처럼 호가창에서 가격·시간 우선 순서로 매칭되며, 지정가 주문이 체결되지 않고 대기할 수도 있습니다. 체결의 작동 원리를 배우고 싶다면 체결엔진을 사용해보세요.

**Q. 투자 행동/생존 점수가 낮으면 어떻게 해야 하나요?**
점수 자체는 매매를 막지 않습니다. 피드백에 적힌 구체적인 이유(과다거래, 단일 종목 집중 등)를 참고해 다음 거래 습관을 조정해보는 용도로 활용하세요.

**Q. 용어가 어려운데 어디서 설명을 볼 수 있나요?**
개발자를 위한 용어집이지만 [docs/domain/glossary-and-domain-knowledge.md](../domain/glossary-and-domain-knowledge.md)에 RSI, MACD, VaR, Kelly Criterion 등 화면에 등장하는 대부분의 용어가 설명되어 있습니다.
