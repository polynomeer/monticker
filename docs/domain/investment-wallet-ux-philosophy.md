# Investment Wallet — 감정과 행동을 기록하는 이유

## 1. 문제: 투자 앱은 결과만 보여주고 과정은 지운다

전통적인 증권 앱의 거래 내역은 "몇 시 몇 분, 무엇을, 얼마에" 거래했는지만 남긴다. 결과(수익률)와 과정(왜 그 거래를 했는지) 사이의 연결고리가 끊어져 있다. 그래서 사용자는 손실이 나도 "왜 졌는지"를 복기하지 못하고, 같은 실수를 반복한다.

monticker의 가설은 단순하다 — **"무엇을 샀는지"보다 "왜 샀는지"를 기록해야 투자 습관이 바뀐다.**

## 2. 감정 태그 — 판단의 동기를 데이터로 만든다

매수 시점에 감정을 선택하게 하는 것은 사용자에게 추가적인 입력 부담을 지우는 일이다. 그럼에도 이 마찰을 감수하는 이유는, 나중에 수익률과 연결했을 때만 의미가 생기기 때문이다.

```
'급등 놓칠까 봐' 태그로 산 종목의 평균 수익률: -3.2%
'장기 투자' 태그로 산 종목의 평균 수익률:    +4.8%
```

이 두 줄은 어떤 투자 조언보다 강력하다 — **본인의 데이터로 본인의 패턴을 보여주기 때문**이다. "추격매수 하지 마세요"라는 일반론은 흘려듣기 쉽지만, "당신이 추격매수한 종목들의 평균 수익률은 -3.2%였습니다"는 무시하기 어렵다.

9종의 감정 태그(확신/불안/따라삼/뉴스보고/급등놓칠까봐/장기투자/직감/비중조절/물타기)는 임상적 분류가 아니라, 실제 개인 투자자들이 스스로 인지하는 매수 동기를 그대로 옮긴 것이다. 학술적으로 정교한 행동재무학 카테고리를 쓰지 않은 이유는, 사용자가 1초 안에 "이거다" 싶은 항목을 고를 수 있어야 데이터가 쌓이기 때문이다.

## 3. 투자 영수증 — 체결을 "결제 경험"으로 바꾼다

증권 앱은 보통 체결 결과를 표 형태로 보여준다. monticker는 토스 페이먼츠 스타일의 영수증 UI를 차용했다.

```
삼성전자 3주 매수 완료
주문 금액: 210,000원
체결 금액: 209,700원
수수료:        300원
남은 예약금:     0원
결제 상태:  정산 완료
```

이것이 단순 UI 취향의 문제가 아닌 이유: **사람들은 "거래했다"보다 "결제했다"는 프레임을 더 신중하게 받아들인다.** 카드 결제 영수증을 받으면 지출을 인지하듯, 투자 영수증은 "이 돈이 실제로 움직였다"는 감각을 즉시 제공한다. 이는 매수 빈도가 지나치게 가벼워지는 것(원클릭 충동 매수)을 완화하는 심리적 마찰이기도 하다.

## 4. 돈의 이동 지도 — "왜 출금 가능 금액이 잔고보다 적은가"

대부분의 초보 투자자가 혼란스러워하는 지점은 "총 자산"과 "지금 쓸 수 있는 돈"의 차이다.

```
총 자산 1,000,000원
  사용 가능 현금:   200,000원
  주문 예약금:      150,000원
  보유 주식 평가액: 600,000원
  정산 대기 금액:    50,000원
```

이 분해는 회계적으로는 당연하지만, 사용자 경험 관점에서는 "내 돈이 지금 어떤 상태인지"를 처음으로 명시적으로 보여주는 장치다. 특히 주문 예약금 개념은 "주문을 넣었는데 왜 잔고가 바로 안 줄어드는지/주는지"에 대한 혼란을 사전에 해소한다.

## 5. 행동 점수와 생존 점수 — 다른 것을 측정한다

```
오늘의 투자 습관 점수: 78점     ← 오늘 하루의 '행동'을 평가
투자 생존 점수: 64점            ← 지금 이 순간의 '포지션 위험'을 평가
```

두 점수를 분리한 이유는 측정 대상이 다르기 때문이다. 행동 점수는 "오늘 충동적으로 거래했는가"를 묻고, 생존 점수는 "지금 포트폴리오가 한 번의 악재로 무너질 만큼 집중되어 있는가"를 묻는다. 둘 다 높을 수도, 둘 다 낮을 수도, 한쪽만 낮을 수도 있다 — 예를 들어 오늘 충동매매는 없었지만(행동 점수 높음) 단일 종목에 70% 이상 몰빵되어 있다면(생존 점수 낮음) 사용자는 서로 다른 두 가지 경고를 동시에 받는다.

```
주의 요인:
  한 종목 비중이 72%입니다.
  현금 비중이 3%밖에 없습니다.
```

이 피드백은 의도적으로 **수익률을 언급하지 않는다.** "당신은 돈을 잃고 있습니다"가 아니라 "당신의 리스크 구조가 이렇습니다"라고 말한다. 결과가 아니라 구조를 지적하는 것이 투자자문처럼 보이지 않으면서도 실질적인 도움을 주는 방법이다.

## 6. 명시적 경계 — 이것은 투자 조언이 아니다

```
모의투자 전용 교육용 피드백입니다. 실제 투자 조언이 아닙니다.
```

행동·생존 점수, 감정 분석 모두 이 고지를 동반한다. monticker가 "당신의 투자 습관을 평가합니다"라고 말하는 순간 투자자문업으로 해석될 여지가 생기므로, 점수와 피드백은 항상 **과거 행동에 대한 서술**(이미 일어난 일을 데이터로 보여줌)이지 **미래 행동에 대한 지시**(무엇을 사거나 팔라는 권유)가 아니라는 경계를 UI 문구 차원에서부터 지킨다.
