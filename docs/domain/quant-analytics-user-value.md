# Quant Analytics — 다섯 기능이 사용자에게 실제로 주는 것

Portfolio Optimizer, Tax Optimizer, Position Sizer, Pattern Recognizer, Regime Detector — 다섯 기능은 기술적으로는 독립적이지만, 제품 관점에서는 하나의 메시지를 공유한다: **"감으로 하던 판단을 수치로 보여준다."**

## 1. 포트폴리오 최적화 — "분산은 직관이 아니라 계산이다"

개인 투자자가 "분산투자 해야지"라고 말할 때, 실제로는 종목 수만 늘리고 종목 간 상관관계는 고려하지 않는 경우가 많다. 두 종목이 똑같이 반도체 업종이라면 종목 수가 늘어도 위험은 거의 줄지 않는다.

```
현재 포트폴리오는 프론티어 아래에 있습니다.
비중 조정 시 동일 위험에서 +1.2%p 추가 수익이 가능합니다.
```

이 한 문장은 "이 종목을 사세요"가 아니라 "당신이 가진 종목들의 비중을 조정하면 같은 위험에서 더 나은 결과를 얻을 수 있습니다"라고 말한다. 종목 추천이 아니라 **이미 보유한 자산의 배분 효율성**을 다루므로, 투자자문업과의 경계에서 비교적 안전한 영역이다 — 무엇을 사라고 하지 않고, 가진 것을 어떻게 나눌지만 이야기한다.

## 2. 세금 최적화 — "팔지 않으면 보이지 않는 돈"

손익통산(tax-loss harvesting)은 기관 투자자나 세무 전문가에게는 익숙하지만, 개인 투자자 대부분은 존재 자체를 모른다.

```
올해 실현 이익: +1,200,000원 (양도세 22% = 264,000원)
삼성전자 평가손실 -500,000원 → 매도 시 절세 효과 110,000원
```

이 기능의 핵심 가치는 "손실을 본 종목을 팔라고 권유"하는 것이 아니라, **이미 손실 중인 자산을 그냥 들고만 있을 때 놓치는 기회**를 수치로 보여주는 것이다. "손실 회피 편향" 때문에 사람들은 손실 종목을 정리하기를 본능적으로 꺼린다 — 이 기능은 그 손실이 적어도 세금 측면에서는 의미 있게 쓰일 수 있다는 사실을 알려줌으로써, 비합리적으로 오래 들고 있는 행동을 줄이도록 돕는다.

```
⚠️ 모의투자 교육용 시뮬레이션입니다. 실제 세무 신고에 사용할 수 없습니다.
```

다만 이 계산은 FIFO 정확도를 갖추지 않은 근사치이므로(`event-sourcing-ledger.md` 참고), 실제 세무 판단의 근거로 쓰일 수 없다는 점을 항상 명시한다. 이는 "세금 계산기"가 아니라 "손익통산이라는 개념을 체감하게 하는 교육 도구"로 포지셔닝하는 이유이기도 하다.

## 3. Kelly Criterion — "얼마나 베팅할지도 전략의 일부다"

백테스트를 마친 사용자는 보통 "이 전략이 좋은가 나쁜가"만 본다. 정작 "이 전략으로 한 번에 얼마를 베팅해야 하는가"는 직관(흔히 "10%면 적당하겠지")으로 정한다.

```
이 전략의 켈리 비율: 18.4%
권장 비율 (Half Kelly): 9.2%
→ 1회 매수 시 총 자본의 9.2%를 추천합니다.
```

Kelly Criterion은 같은 승률·손익비를 가진 전략이라도 베팅 비율에 따라 장기 성과가 크게 달라진다는 것을 수학적으로 보여준다. Full Kelly가 아니라 Half Kelly를 기본 권장값으로 제시하는 이유는, 이론적 최적치는 추정 오차에 매우 민감해 실무에서는 절반 수준으로 보수화하는 것이 표준 관행이기 때문이다 — "이론적으로 최선"이 아니라 "실전에서 안전한" 값을 우선한다.

## 4. 차트 패턴 인식 — "이중바닥이 무엇인지 몰라도 보여준다"

차트 패턴(헤드앤숄더, 이중바닥 등)은 기술적 분석에서 오래된 개념이지만, 초보 투자자는 차트를 봐도 패턴을 스스로 식별하지 못한다.

```
이중 바닥 패턴 감지 (완성도 82%)
→ 통계적으로 상승 반전 가능성이 있는 패턴입니다.
```

"완성도 82%"라는 표현은 의도적으로 확신을 낮춘다 — "이 종목은 오릅니다"가 아니라 "이런 모양의 패턴이 통계적으로 관찰됩니다"라고만 말한다. 패턴 인식의 목적은 매매 신호를 주는 것이 아니라, 기술적 분석이라는 도구를 처음 접하는 사용자가 **차트를 보는 방법을 학습**하도록 돕는 것이다.

## 5. 시장 국면 감지 — "전략의 약점을 숨기지 않는다"

백테스트 결과가 좋아 보여도, 그 기간이 우연히 상승장이었다면 하락장에서는 완전히 다른 결과가 나올 수 있다.

```
상승장 (2023.01~07): +18.2%  MDD -4.1%
하락장 (2022.01~10):  -8.4%  MDD -22.3%
⚠️ 이 전략은 하락장에서 MDD가 5배 이상 확대됩니다.
```

이 기능이 다른 네 기능과 결정적으로 다른 점은 **긍정적인 정보를 주지 않을 수도 있다**는 것이다. 좋은 성과만 강조하는 다른 퀀트 플랫폼과 달리, monticker는 전략이 어떤 국면에서 약한지를 의도적으로 드러낸다. 이는 Quant Lab 전체의 신뢰도 점수 체계와 같은 철학을 공유한다 — "당신의 전략이 완벽하다"고 말하지 않는 것이 장기적으로 더 신뢰받는 길이라는 판단이다.

## 6. 다섯 기능을 관통하는 하나의 원칙

다섯 기능 모두 "무엇을 사라/팔라"는 지시형 문장을 피하고, "지금 상태가 이렇다"는 서술형 정보를 제공한다. 이는 단순한 어휘 선택이 아니라, monticker가 투자자문업이 아닌 **분석 도구**로 남기 위한 제품 전체의 일관된 설계 원칙이다 (`quant-lab-positioning.md` 참고). 사용자가 최종 판단을 내리고, monticker는 그 판단에 필요한 수치를 정확하고 투명하게 보여주는 역할에 머문다.
