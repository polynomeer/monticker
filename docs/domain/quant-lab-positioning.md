# Quant Lab — 왜 "전략 마켓"이 아니라 "전략 연구소"인가

## 1. 문제: 퀀트 기능은 쉽게 투자자문업으로 오해받는다

사용자가 만든 룰셋을 백테스트하고, 좋은 성과가 나오면 다른 사용자와 공유하거나 판매할 수 있게 한다 — 이 한 줄짜리 기획은 매력적이지만, 한국 자본시장법 체계에서는 **유사투자자문업**과 경계가 모호해지는 지점이다. 금융위원회는 허위·미실현 수익률 제시, 좋은 기간만 골라 보여주는 광고, 손실 가능성을 가리는 표현을 부당 표시·광고로 규제하고 있으며, 점검을 지속적으로 강화하겠다고 밝히고 있다.

monticker가 다루는 것이 "종목 추천"이 아니라 "검증 도구"임을 제품 설계 단계에서부터 명확히 하지 않으면, 기능이 잘 만들어질수록 오히려 규제 리스크가 커지는 역설에 빠진다.

## 2. 그래서 선택한 포지셔닝

> 코딩 없이 투자 규칙을 만들고, 과거 데이터와 실시간 모의투자로 검증한 뒤, 검증된 전략을 비공개로 운용하거나 공유·판매할 수 있는 퀀트 전략 플랫폼.

핵심은 사용자가 구매하는 것이 **"종목 추천"이 아니라 "전략 실행 권한"**이라는 점이다.

| 금지하는 것 | 제공하는 것 |
|------------|------------|
| "이 종목을 사세요" | "이 전략이 오늘 신호를 냈습니다" |
| 룰셋 원문 판매 | 룰셋을 비공개로 둔 채 신호 구독권 판매 |
| 수익률 1위 랭킹 | 신뢰도·MDD·검증 기간 기준 랭킹 |
| 무조건 오르는 전략 | 시장 국면별 성과를 모두 공개 (하락장 포함) |

구매자가 룰셋 원문을 볼 수 없다는 것은 단순한 지적재산권 보호 장치가 아니다 — "이 사람의 판단을 따른다"가 아니라 "이 검증된 도구를 실행한다"는 프레이밍 자체를 만드는 장치다.

## 3. 단계적 신뢰 구축 — 처음부터 마켓으로 가지 않는다

```
룰셋 빌더 (개인용)
  → 백테스트
  → 포워드 테스트 (실시간 시장에서 30일 이상 검증)
  → 비공개 공유 (링크)
  → 전략 마켓 (검증 배지 + 신고 시스템)
```

판매 기능을 가장 마지막 단계에 둔 이유는 두 가지다.

**첫째, 제품적으로** — 룰셋 빌더와 백테스트만으로도 "감으로 투자하던 사용자를 규칙 기반 투자자로 바꾼다"는 핵심 가치는 이미 전달된다. 마켓이 없어도 제품은 완결된다.

**둘째, 신뢰 구축 관점에서** — 검증되지 않은 전략이 곧바로 판매 가능하다면 플랫폼의 신뢰도는 첫 사기성 전략 한 건으로 무너진다. 포워드 테스트 30일이라는 게이트는 "백테스트 성과가 좋아도 실시간 시장에서는 다르게 작동할 수 있다"는 사실을 사용자에게 직접 보여주는 장치이자, 판매자가 운용 중 룰셋을 손대지 못하게 막는 버전 고정 장치이기도 하다.

## 4. 신뢰도 점수가 막으려는 것 — 과최적화

백테스트 수익률은 조건을 충분히 만지작거리면 언제든 좋게 만들 수 있다. 이것이 과최적화(overfitting)이며, 퀀트 전략 마켓이 무너지는 가장 흔한 방식이다. monticker의 신뢰도 점수(A~D)는 거래 횟수와 검증 기간을 동시에 요구함으로써, "운 좋은 상승장 10거래 전승"이 최고 등급으로 둔갑하는 것을 막는다.

```
A: 50회 이상 거래 + 2년 이상 검증
B: 20회 이상 거래 + 1년 이상 검증
C: 10회 이상 거래
D: 그 외 (과최적화 위험 높음으로 명시 경고)
```

사용자에게 "이 전략은 좋습니다"가 아니라 "이 전략은 이 정도 신뢰도로 검증됐습니다, 판단은 본인 몫입니다"라고 말하는 것 — 이것이 monticker가 투자자문업과 구분되는 가장 중요한 한 문장이다.

## 5. 컴플라이언스는 기능이지 부가물이 아니다

```
이 전략의 성과는 과거 데이터 또는 모의 운용 결과를 기준으로 계산되었습니다.
과거 성과는 미래 수익을 보장하지 않습니다.
실제 투자 판단과 책임은 사용자 본인에게 있습니다.
```

이 고지문은 법무 검토용 부록이 아니라 모든 전략 카드, 백테스트 결과, 신뢰도 배지 옆에 항상 함께 노출되는 UI 요소로 설계했다. 판매자 등록 시에도 "수익률 보장 표현 금지", "손실 보전 약속 금지" 같은 항목에 명시적으로 동의해야 하며, 플랫폼 차원에서 전략명 금칙어 필터와 과장 광고 문구 감지를 검수 단계에 둔다.
