# 2장. 주식 시장의 구조

> **핵심 한 줄**: 주식 시장은 "언제, 어디서, 어떤 규칙으로" 거래가 이루어지는지를 정의하는 인프라다.

---

## 2.1 거래소 — KRX, KOSPI, KOSDAQ, KONEX

한국의 주식 거래는 모두 **KRX(Korea Exchange, 한국거래소)**를 통해 이루어집니다.  
KRX는 세 개의 시장을 운영합니다.

| 시장 | 특징 | 상장 요건 |
|------|------|----------|
| **KOSPI** | 유가증권시장. 삼성전자, SK하이닉스 등 대형 우량주 | 자기자본 300억 원 이상, 3년 이상 영업 |
| **KOSDAQ** | 코스닥. 성장성 중심의 중소·벤처 기업 | 자기자본 30억 원 이상, 이익 요건 다양 |
| **KONEX** | 중소기업 전용 초기 시장. 유동성 낮음 | 요건 완화, 지정자문인 필요 |

> **개발자 참고**: monticker의 `Stock` 도메인 모델에는 `exchange` 필드가 있어 KOSPI/KOSDAQ을 구분합니다.  
> 스크리너 필터 `exchange=KOSPI`로 시장 구분 조회가 가능합니다.

## 2.2 거래 시간대

| 시간대 | 시간 (KST) | 특징 |
|--------|-----------|------|
| **장전 동시호가** | 08:00 ~ 09:00 | 주문만 접수. 09:00에 단일가로 일괄 체결 |
| **정규 거래** | 09:00 ~ 15:20 | 연속 체결. 가격/시간 우선 원칙 |
| **장마감 동시호가** | 15:20 ~ 15:30 | 종가 결정. 단일가 방식 |
| **시간외 단일가** | 15:40 ~ 18:00 | 전일 종가±10% 범위 내 10분 단위 단일가 체결 |

### 동시호가(Single Price Auction)란?

정해진 시간 동안 쌓인 모든 주문을 한 번에 **단 하나의 가격**으로 체결시키는 방식.  
이 가격을 **균형가격(Equilibrium Price)**이라 하며, 체결 수량이 최대화되는 가격을 이론적으로 찾습니다.

```
체결 가능 수량 = min(누적 매수량, 누적 매도량)
균형가격 = 위 수량을 최대로 만드는 가격
```

## 2.3 거래일 (Trading Day) / 휴장일

- 월~금이 거래일이지만, **공휴일은 휴장**
- 대체공휴일, 설날 연휴, 추석 연휴 등도 휴장
- 크리스마스(12/25)는 거래 없음

> **T+2 계산에서 결정적**: 영업일(Business Day)이 아닌 날은 T+2 카운트에서 제외됩니다.  
> monticker의 `BusinessDayCalculator`는 공휴일 캘린더를 참조해 정산일을 계산합니다.

```kotlin
// monticker 예시 — PaperSettlementService
fun settlementDate(tradeDate: LocalDate): LocalDate {
    var date = tradeDate
    var count = 0
    while (count < 2) {
        date = date.plusDays(1)
        if (isBusinessDay(date)) count++
    }
    return date
}
```

## 2.4 T+2 결제 (Settlement)

거래(Trade)가 체결된 날을 **T일**이라 하면, 실제 돈과 주식의 교환(결제, Settlement)은 **T+2 영업일**에 일어납니다.

| 날짜 | 사건 |
|------|------|
| T일 | 매수/매도 주문 체결. 주식은 아직 내 것이지만 "확정 예정" 상태 |
| T+1 | 증권사 내부 정산 처리 |
| T+2 | 매수자 계좌에서 돈이 나가고, 매도자 계좌에서 주식이 나감. **실물 결제 완료** |

### 왜 T+2인가?

역사적으로는 물리적 주권(종이 주식)을 실제로 전달해야 했기 때문에 수일이 걸렸습니다.  
전산화된 오늘날에도 결제 리스크 관리, 오류 검증을 위해 T+2가 유지됩니다.  
미국은 2024년부터 T+1으로 단축했습니다.

## 2.5 시장 참여자

| 참여자 | 역할 |
|--------|------|
| **개인투자자 (Retail)** | 직접 매매 |
| **기관투자자 (Institution)** | 펀드, 연기금, 보험사. 대규모 자금 운용 |
| **외국인 (Foreign)** | 해외 기관/개인. KOSPI 시가총액의 30~40% 보유 |
| **증권사 (Broker/Dealer)** | 주문 중개 + 자기매매 |
| **마켓메이커 (Market Maker)** | 유동성 공급. 항상 매수/매도 호가 제시 |

**수급(수요와 공급)**: 기관과 외국인의 매매 동향은 시장 방향에 큰 영향을 줍니다.  
"외국인 순매수" = 외국인이 오늘 산 주식 금액 - 판 주식 금액 (양수면 순매수, 음수면 순매도)

## 2.6 DMA와 알고리즘 트레이딩

**DMA (Direct Market Access)**: 브로커를 통하지 않고 거래소 시스템에 직접 주문을 전송하는 방식.  
속도가 빠르고 수수료가 낮지만, 증권사 심사가 필요합니다.

**알고리즘 트레이딩(Algo Trading)**: 사전 정의된 규칙과 코드로 자동 주문 집행.  
monticker의 퀀트 전략 자동 실행도 일종의 알고리즘 트레이딩 개념을 따릅니다.

## 2.7 회로 차단기 (Circuit Breaker) / 사이드카 (Sidecar)

급격한 시장 변동 시 거래를 일시 중단하는 안전장치입니다.

### 서킷브레이커 (CB)

| 발동 조건 | 조치 |
|----------|------|
| KOSPI가 전일 대비 **8% 이상** 하락 + 1분 지속 | 20분간 모든 주문 접수·체결 중단 |
| **15% 이상** 하락 + 1분 지속 | 추가 20분 중단 (하루 2회 한도) |
| **20% 이상** 하락 | 당일 거래 전면 중단 |

### 사이드카 (Sidecar)

선물 가격이 현물 대비 급변할 때 **선물 프로그램 매매를 5분간 차단**하는 장치.  
현물 시장에 대한 선물의 연쇄적 충격을 막기 위함입니다.
