# 3장. 주문의 종류

> **핵심 한 줄**: 주문 유형은 "얼마에 살 것인가"와 "언제까지 유효한가"의 조합이다.

---

## 3.1 시장가 주문 (Market Order)

**"지금 당장, 현재 시장 최우선 가격에 체결해라"**

- 가격을 지정하지 않음. 상대방의 최우선 호가(Best Ask/Bid)에 즉시 체결
- **장점**: 확실하게 체결됨
- **단점**: 체결 가격 보장 없음. 급등/급락 중에 주문하면 예상보다 훨씬 나쁜 가격에 체결될 수 있음 (슬리피지)

```
매수 시장가 → 현재 매도 호가 1순위에서 체결
매도 시장가 → 현재 매수 호가 1순위에서 체결
```

> **monticker 페이퍼 트레이딩**: 시장가 주문은 현재 `last_price` × (1 ± 슬리피지율)로 체결가를 추정합니다.

---

## 3.2 지정가 주문 (Limit Order)

**"이 가격 이하(매수) 또는 이상(매도)으로만 체결해라"**

- 가격을 직접 지정
- 지정한 가격보다 불리한 가격에는 절대 체결되지 않음
- 상대방이 없으면 **미체결 상태로 호가창에 대기** (미결 주문, Open Order)

```
매수 지정가 50,000원 → 50,000원 이하에서만 체결
매도 지정가 55,000원 → 55,000원 이상에서만 체결
```

| 구분 | 시장가 | 지정가 |
|------|--------|--------|
| 체결 보장 | 높음 | 낮음 (미체결 가능) |
| 가격 보장 | 없음 | 있음 |
| 적합한 상황 | 빠른 진입/청산 필요 | 특정 가격에서만 매매 원할 때 |

---

## 3.3 한국 거래소 특수 지정가 유형

| 주문 유형 | 설명 |
|----------|------|
| **최유리 지정가** | 주문 시점의 최우선 상대 호가로 지정. 시장가처럼 빨리 체결되지만 지정가로 처리 |
| **최우선 지정가** | 주문 시점의 최우선 자기 호가로 지정. 호가창 맨 앞에 서지만 상대보다 1틱 불리 |
| **조건부 지정가** | 정규장에서는 지정가, 마감 시 미체결이면 자동으로 시장가로 전환 |

---

## 3.4 IOC와 FOK

주문의 **유효 기간(Time-In-Force, TIF)**을 정의하는 방식입니다.

### IOC (Immediate Or Cancel)

- 주문 즉시 체결 가능한 수량만 체결하고, **나머지는 자동 취소**
- 부분 체결(Partial Fill) 허용

```
매수 IOC 100주 → 50주만 체결 가능 → 50주 체결 + 나머지 50주 자동 취소
```

### FOK (Fill Or Kill)

- 전체 수량이 **즉시 완전 체결**되지 않으면 **전량 취소**
- 부분 체결 불허. 대규모 기관 주문에서 사용

```
매수 FOK 100주 → 100주 모두 즉시 체결 불가 → 전량 취소
```

### GTC (Good Till Cancelled)

- 명시적으로 취소할 때까지 주문 유지. 한국 거래소는 당일(DAY) 기준이 기본.

---

## 3.5 스톱 주문 (Stop Order)

**"특정 가격에 도달하면 그때 주문을 발동해라"**

### 스톱 매도 (Stop Loss)

손실을 제한하기 위한 자동 청산 주문.

```
보유 주식 매입가: 50,000원
스톱 가격 설정: 45,000원
→ 주가가 45,000원에 도달하면 → 자동으로 시장가 매도 발동
```

### 스톱 리밋 (Stop Limit)

스톱 가격 도달 시 **시장가가 아닌 지정가로** 발동.

```
스톱 가격: 45,000원 / 리밋 가격: 44,800원
→ 주가가 45,000원에 도달 → 44,800원 지정가 매도 주문 발동
→ 급락 중이면 44,800원에도 미체결될 수 있음
```

> **리스크 관리에서 핵심**: 스톱 주문이 없으면 "조금만 더 기다리면 오르겠지"라는 심리로 손실이 눈덩이처럼 불어납니다.  
> monticker 퀀트 룰셋에서 `stop_loss_pct`로 스톱 로스 비율을 설정할 수 있습니다.

---

## 3.6 OCO (One Cancels the Other)

두 개의 주문을 동시에 넣고, **하나가 체결되면 다른 하나는 자동 취소**되는 조합.

```
예시: 현재 주가 50,000원에 주식 보유 중
  - 이익 실현 주문: 55,000원에 매도 지정가
  - 손실 제한 주문: 46,000원에 스톱 주문
  → 어느 한쪽이 체결되면 나머지 취소
```

한국 거래소에서는 OCO가 직접 지원되지 않아, 증권사 HTS/MTS에서 소프트웨어적으로 구현합니다.

---

## 3.7 주문 수명 주기 (Order Lifecycle)

```
주문 제출
    │
    ▼
[PENDING] ─── 거래소 수신 전
    │
    ▼
[OPEN] ─────── 호가창에 등록됨 (미체결 대기)
    │
    ├─── 상대방 주문 매칭 ───► [FILLED] ── 전량 체결
    │                      └─► [PARTIALLY_FILLED] ── 부분 체결
    │
    └─── 취소/만료 ──────────► [CANCELLED] / [EXPIRED]
```

> monticker의 `OrderStatus` enum이 이 상태들을 그대로 반영합니다.

## 요약

| 주문 종류 | 가격 지정 | 체결 보장 | 주요 용도 |
|----------|----------|----------|----------|
| 시장가 | ✗ | 높음 | 빠른 진입/청산 |
| 지정가 | ✓ | 낮음 | 원하는 가격 매매 |
| 최유리 지정가 | 자동 | 높음 | 시장가 대안 |
| IOC | ✓ | 부분 | 즉시 체결 후 잔량 취소 |
| FOK | ✓ | 전체 또는 없음 | 대량 완전 체결 |
| 스톱 | 트리거 | 트리거 후 발동 | 손절/이익실현 자동화 |
