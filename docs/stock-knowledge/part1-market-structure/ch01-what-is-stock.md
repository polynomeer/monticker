# 1장. 주식이란 무엇인가

> **핵심 한 줄**: 주식은 회사 소유권의 일부를 종이(또는 전자 장부)로 쪼개놓은 것이다.

---

## 1.1 주식 (Stock / Share)

**주식(株式)**은 주식회사가 자본을 조달하기 위해 발행하는 증권으로, 회사 소유권의 일부를 나타냅니다.

- 회사가 100주를 발행했고 내가 10주를 보유하면 → 나는 이 회사의 **10% 주주**
- 주주는 회사 이익(배당)에 참여할 권리, 경영에 참여할 권리(의결권)를 갖는다
- 회사가 망하면 주주는 **가장 마지막에** 남은 재산을 가져간다 (채권자 > 우선주주 > 보통주주)

```
회사 가치 (순자산 + 미래 이익)
────────────────────────────── = 1주당 적정 가치
       발행 주식 수
```

### 왜 주식을 발행하는가?

회사가 사업을 키우려면 자금이 필요합니다. 자금 조달 방법은 두 가지입니다.

| 방법 | 특징 | 비용 |
|------|------|------|
| **차입(대출/채권)** | 원금+이자 상환 의무 | 이자율 |
| **주식 발행** | 상환 의무 없음, 대신 소유권 희석 | 배당 + 지분 희석 |

---

## 1.2 주주의 권리

### 재산적 권리
- **배당받을 권리**: 회사가 이익을 배당할 때 보유 주식 수에 비례해 수령
- **잔여재산 분배권**: 회사 청산 시 채무 변제 후 남은 재산 수령

### 공익적 권리
- **의결권**: 주주총회에서 안건에 투표 (보통 1주 = 1표)
- **정보 접근권**: 재무제표, 공시 자료 열람 권리
- **대표소송권**: 이사의 의무 위반에 대해 회사를 대신해 소송 제기

---

## 1.3 보통주 vs 우선주

| 구분 | 보통주 (Common Stock) | 우선주 (Preferred Stock) |
|------|----------------------|------------------------|
| 의결권 | 있음 | 없거나 제한적 |
| 배당 우선순위 | 낮음 | 높음 (고정 배당) |
| 청산 우선순위 | 낮음 | 높음 |
| 주가 변동성 | 높음 | 낮음 |
| 한국 종목 코드 예 | 삼성전자 (005930) | 삼성전자우 (005935) |

한국에서는 우선주 종목명 뒤에 **"우"**를 붙이고, 코드 끝자리가 5로 끝나는 경우가 많습니다.

---

## 1.4 시가총액 (Market Capitalization)

```
시가총액 = 현재 주가 × 발행 주식 수
```

예시: 삼성전자 주가 75,000원, 발행주식 5,969,782,550주  
→ 시가총액 ≈ **447조 원**

### 시가총액 구간별 분류 (한국 기준)

| 구분 | 기준 | 특징 |
|------|------|------|
| 대형주 (Large Cap) | 시총 상위 100개 | 유동성 높음, 변동성 낮음 |
| 중형주 (Mid Cap) | 시총 101~300위 | 균형적 |
| 소형주 (Small Cap) | 그 외 | 유동성 낮음, 변동성 높음 |

> monticker에서 스크리닝 시 시가총액 필터를 자주 사용합니다.  
> `market_cap_min`, `market_cap_max` 파라미터로 조회 범위를 좁힙니다.

## 1.5 상장 (Listing) / IPO (기업공개)

**IPO (Initial Public Offering)**: 회사가 처음으로 주식을 공개 시장에 내놓는 것

### IPO 과정
1. 기업이 증권사(주관사)를 선정
2. 금융당국에 증권신고서 제출
3. **수요예측(Book Building)**: 기관투자자에게 희망 공모가 범위 제시
4. **공모청약**: 개인투자자가 공모가로 주식 신청
5. 상장 첫날 공개 시장에서 거래 시작

### 상장 vs 비상장

| 구분 | 상장 (Listed) | 비상장 (Unlisted) |
|------|-------------|-----------------|
| 거래 방법 | 거래소를 통해 누구나 | 장외거래, 제한적 |
| 투명성 | 공시 의무 | 낮음 |
| 유동성 | 높음 | 낮음 |
| 가치 발견 | 시장 가격으로 실시간 | 어려움 |

---

## 1.6 액면가 / 발행가 / 시가

| 용어 | 정의 |
|------|------|
| **액면가 (Face Value, Par Value)** | 주식을 처음 발행할 때 정한 이론적 최소 가치. 한국은 보통 100원, 500원, 1,000원, 5,000원. 시장 가격과 무관. |
| **발행가 (Issue Price)** | IPO나 유상증자 시 실제로 팔리는 가격. 액면가보다 높은 것이 일반적(초과 발행). |
| **시가 (Market Price)** | 현재 주식시장에서 형성된 거래 가격. 수요와 공급이 실시간으로 결정. |

### 주당 순자산가치 (BPS, Book Value Per Share)

```
BPS = 자기자본 ÷ 발행주식 수
PBR = 주가 ÷ BPS
```

PBR이 1 미만이면 시장이 회사 장부가치보다 낮게 평가하는 것. 가치투자자들이 주목합니다.

---

## 요약

```
주식 = 회사 소유권 조각
시가총액 = 주가 × 발행주식 수 = 시장이 평가하는 회사 전체 가치
IPO = 비상장 → 상장으로의 전환
보통주 = 의결권 있음 / 우선주 = 배당 우선
```
