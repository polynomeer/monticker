# 4장. 호가창 (Order Book) 심층

> **핵심 한 줄**: 호가창은 "지금 사려는 사람들"과 "지금 팔려는 사람들"의 모든 의도가 쌓여 있는 실시간 수요·공급 장부다.

---

## 4.1 Bid / Ask / Spread

| 용어 | 의미 | 누가 제시? |
|------|------|-----------|
| **Bid (매수 호가)** | 사려는 사람이 제시한 최고 가격 | 매수 대기자 |
| **Ask (매도 호가)** | 팔려는 사람이 제시한 최저 가격 | 매도 대기자 |
| **Spread** | Ask − Bid | 시장 마찰 비용 |

```
매도 호가   55,200원  ← Ask (매도 1호가)
            55,100원
            55,000원
────────────────────
            54,900원
            54,800원
매수 호가   54,700원  ← Bid (매수 1호가)

Spread = 55,200 − 54,700 = 500원
```

**스프레드가 좁을수록** 유동성이 높은 종목입니다.  
삼성전자 같은 대형주는 스프레드가 100원 이하, 소형주는 수백~수천 원에 달할 수 있습니다.

---

## 4.2 호가 단위 (Tick Size)

한국 거래소는 가격대별로 **주문 가격의 최소 단위**를 정해두고 있습니다.

| 주가 구간 | 호가 단위 |
|----------|---------|
| 2,000원 미만 | 1원 |
| 2,000원 ~ 5,000원 미만 | 5원 |
| 5,000원 ~ 20,000원 미만 | 10원 |
| 20,000원 ~ 50,000원 미만 | 50원 |
| 50,000원 ~ 200,000원 미만 | 100원 |
| 200,000원 ~ 500,000원 미만 | 500원 |
| 500,000원 이상 | 1,000원 |

```
삼성전자 주가 75,000원 → 호가 단위 100원
→ 74,900, 75,000, 75,100원으로만 주문 가능
→ 75,050원 주문은 불가
```

> monticker의 `TickSizeCalculator`가 이 규칙을 구현합니다. 백테스팅 시 체결가 계산에 사용됩니다.

---

## 4.3 체결 우선순위

호가창에 주문이 쌓일 때 어떤 주문이 먼저 체결되는지를 결정하는 규칙입니다.

### 1순위: 가격 우선 (Price Priority)

- **매수**: 더 높은 가격 주문이 우선 (비싸게 사려는 사람이 먼저)
- **매도**: 더 낮은 가격 주문이 우선 (싸게 팔려는 사람이 먼저)

### 2순위: 시간 우선 (Time Priority, FIFO)

같은 가격이면 **먼저 들어온 주문**이 우선.  
초고빈도거래(HFT)에서 마이크로초 단위 주문 순서가 중요한 이유입니다.

### 3순위: 수량 우선 (Volume Priority)

일부 시장에서 동일 가격·동일 시간이면 수량이 많은 주문을 우선하기도 하지만,  
KRX는 가격 → 시간 순으로만 적용합니다.

```
예시:
  주문A: 55,000원에 100주 매수 (09:01:00 접수)
  주문B: 55,000원에 200주 매수 (09:01:05 접수)
  주문C: 55,100원에 50주 매수  (09:01:10 접수)

체결 우선순위: C → A → B
(가격 우선: C가 가장 높음 / 같은 가격이면 시간 우선: A가 B보다 먼저)
```

---

## 4.4 호가 깊이 (Market Depth)

1호가만이 아닌, 여러 단계의 호가와 수량을 보는 것이 **Market Depth** (또는 Depth of Market, DOM)입니다.

```
매도 호가 잔량         가격        매수 호가 잔량
─────────────────────────────────────────────
           3,200주    56,000원
           2,100주    55,500원
           1,500주    55,200원    ← Ask 1호가
───────────────────────────────────────────── 
                      54,700원    2,800주    ← Bid 1호가
                      54,500원    4,100주
                      54,000원    6,700주
```

- **매도 잔량이 매수 잔량보다 훨씬 많다** → 상승 압력이 약함
- **매수 잔량이 두텁다** → 가격 지지 역할. 일정 가격 이하로 내려가기 어려움

---

## 4.5 CLOB (Central Limit Order Book)

**중앙 집중형 지정가 주문장**. KRX를 포함한 대부분의 거래소가 이 방식을 사용합니다.

- 모든 주문이 **단일 전자 장부**에 집중
- 가격·시간 우선으로 자동 매칭
- 투명성 높음 (호가창이 공개)

```
CLOB 매칭 엔진:
  1. 새 주문 수신
  2. 반대편 호가와 매칭 가능한지 확인
  3. 매칭 가능 → 체결 (Fill 이벤트 발행)
  4. 매칭 불가 → 호가창에 등록
```

> monticker의 `/matching` 엔진은 CLOB 알고리즘을 구현합니다.

---

## 4.6 Dark Pool

**거래소 밖에서 이루어지는 대규모 기관 거래**.

- 호가창에 공개되지 않아 시장 충격(Market Impact) 최소화
- 대규모 기관이 수십만 주를 사고팔 때 사용
- 체결가가 공개 시장 Bid/Ask 사이에서 결정

> 개인투자자는 일반적으로 접근 불가. 한국에서는 KRX의 **대량매매(블록딜)** 제도가 유사한 역할.

---

## 4.7 Best Bid/Ask

- **Best Bid**: 현재 매수 호가 중 가장 높은 가격 (= 매수 1호가)
- **Best Ask**: 현재 매도 호가 중 가장 낮은 가격 (= 매도 1호가)
- **Mid Price**: (Best Bid + Best Ask) ÷ 2 — 현재 "공정 가격"의 추정치

```
Best Bid = 54,700원
Best Ask = 55,200원
Mid Price = 54,950원
```

VWAP, 지정가 주문 전략에서 Mid Price를 기준점으로 자주 사용합니다.

---

## 요약

```
호가창 = 매수/매도 대기 주문의 집합
Spread = Ask - Bid (좁을수록 유동성 좋음)
호가 단위 = 가격대별 최소 주문 단위 (KRX 규정)
체결 우선순위: 가격 → 시간
CLOB = 중앙 집중형 매칭 시스템
```
