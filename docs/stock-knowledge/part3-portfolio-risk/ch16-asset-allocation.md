# 16장. 자산 배분

> **핵심 한 줄**: "계란을 한 바구니에 담지 마라"의 수학적 구현이 자산 배분이다.

---

## 16.1 마코위츠 평균-분산 최적화 (MPT)

해리 마코위츠(1952)가 제안한 **현대 포트폴리오 이론(Modern Portfolio Theory)**.

핵심 아이디어: **상관관계가 낮은 자산들을 조합하면 리스크를 줄이면서 동일한 수익을 달성할 수 있다**.

```
포트폴리오 기대 수익률:
E(Rp) = Σ(wᵢ × E(Rᵢ))

포트폴리오 분산:
σp² = Σᵢ Σⱼ wᵢ × wⱼ × σᵢ × σⱼ × ρᵢⱼ

제약 조건: Σwᵢ = 1, wᵢ ≥ 0
```

최적화 문제: 목표 수익률 하에서 **σp를 최소화**하는 가중치 w를 찾는다.

---

## 16.2 효율적 프론티어 (Efficient Frontier)

다양한 자산 조합에 대해 (기대수익률, 리스크)를 그리면 나타나는 **최적 경계선**.

```
기대수익률
    │                   * 비효율 포트폴리오
    │              * ← 효율적 프론티어
    │         *
    │     *  (이 곡선 위의 포트폴리오만 선택)
    │  *
    │
    └──────────────────── 리스크(σ)
```

**효율적 포트폴리오**: 동일 리스크에서 가장 높은 수익률을 내는 조합.  
**비효율 포트폴리오**: 프론티어 아래에 있는 점들 — 더 나은 조합이 존재함.

**최적 포트폴리오**: 무위험 자산(국채)과 효율적 프론티어의 **접점(Tangency Portfolio)**  
= Sharpe Ratio를 최대화하는 포트폴리오

---

## 16.3 가중 방법별 비교

### 등가중 (Equal Weight)

```
N개 종목 → 각각 1/N씩
```

- 장점: 단순, 특정 종목 쏠림 없음
- 단점: 시가총액이나 리스크 무시

### 시가총액 가중 (Cap Weighted)

```
종목 비중 = 시가총액 ÷ 전체 시가총액
```

- KOSPI 지수의 방식
- 큰 회사에 자동으로 더 많은 비중
- 상승한 종목 비중이 자동 증가 (모멘텀 효과)

### 리스크 가중 / 리스크 패리티 (Risk Parity)

```
각 자산의 포트폴리오 리스크 기여분을 동일하게
wᵢ ∝ 1/σᵢ (단순 역변동성 버전)
```

- 변동성이 큰 주식 → 비중 낮춤
- 변동성이 낮은 채권 → 비중 높임
- 브리지워터의 "올웨더 포트폴리오"가 대표적

---

## 16.4 리밸런싱 (Rebalancing)

시간이 지나면 자산 가격 변동으로 비중이 목표에서 벗어납니다.  
이를 **원래 목표 비중으로 되돌리는** 과정.

```
초기 배분:
주식 60% / 채권 40%

1년 후 주가 급등:
주식 75% / 채권 25%  ← 목표 이탈

리밸런싱: 주식 15% 매도 → 채권 15% 매수
```

### 리밸런싱 방법

| 방법 | 기준 | 장점 | 단점 |
|------|------|------|------|
| **주기적** | 매월/분기/연 | 단순 | 불필요한 거래 |
| **밴드 방식** | ±5%p 이탈 시 | 효율적 | 모니터링 필요 |
| **혼합** | 주기적 + 밴드 | 균형적 | 복잡 |

### 리밸런싱의 역설적 효과

- 비중이 커진 자산(= 많이 오른 자산)을 **팔고**
- 비중이 줄어든 자산(= 많이 빠진 자산)을 **사는** 것
- 자동으로 **고가 매도, 저가 매수** 효과 → 장기 복리에 유리

---

## 16.5 공분산 행렬과 분산투자

N개 자산 포트폴리오의 리스크는 **N×N 공분산 행렬**로 표현됩니다.

```
Σ = [[σ₁², σ₁₂, σ₁₃],
     [σ₂₁, σ₂², σ₂₃],
     [σ₃₁, σ₃₂, σ₃²]]

포트폴리오 분산 = wᵀ Σ w
```

현실적 문제:
- 100개 종목: 100×100 = 10,000개 원소 추정 필요
- 데이터가 적으면 추정 오류가 큼 → **추정 리스크**
- 해결: 팩터 모델 사용 (공분산을 팩터 구조로 단순화)

## 자산 배분 예시 포트폴리오

### 보수적 투자자

```
국내 주식: 30%
해외 주식: 20%
국내 채권: 30%
해외 채권: 10%
현금성 자산: 10%
```

### 성장 지향 투자자

```
국내 주식: 40%
해외 주식: 40%
채권: 15%
대안 투자: 5%
```

### 퀀트 전략 포트폴리오 (monticker)

```
KOSPI 대형주 모멘텀 전략: 40%
KOSDAQ 소형주 가치 전략: 30%
현금 (미투자): 30%  ← 기회 포착용
```

## 요약

```
MPT = 상관계수가 낮은 자산 조합으로 리스크 감소
효율적 프론티어 = 최적 자산 조합의 경계선
등가중 = 단순하지만 단순한 이유로 좋음
리스크 패리티 = 각 자산의 위험 기여를 동일화
리밸런싱 = 목표 비중 유지 → 자동 고가 매도/저가 매수
```
