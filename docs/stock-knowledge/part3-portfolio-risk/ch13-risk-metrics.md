# 13장. 리스크 지표

> **핵심 한 줄**: 수익률은 "얼마 벌었냐"고, 리스크는 "얼마나 불확실하게 벌었냐"다. 둘을 함께 봐야 진짜 성과가 보인다.

---

## 13.1 변동성 (Volatility)

수익률의 **표준편차**로 측정합니다. 변동성이 높을수록 예측하기 어렵고 리스크가 큽니다.

```
σ = √(Σ(rᵢ − r̄)² ÷ N)

rᵢ: 각 기간 수익률
r̄: 평균 수익률
N: 기간 수
```

**연환산 변동성**:
```
연 변동성 = 일 변동성 × √252
```

### 해석

| 연 변동성 | 자산 유형 |
|----------|----------|
| 2~5% | 채권 (안정적) |
| 10~20% | 대형주 |
| 20~40% | 중소형주, 성장주 |
| 40%+ | 소형주, 테마주, 암호화폐 |

> 변동성 자체는 나쁜 것이 아닙니다. 높은 변동성 = 더 큰 하락 가능성 + 더 큰 상승 가능성.  
> 중요한 것은 **리스크 대비 수익**의 비율입니다.

## 13.2 MDD (Maximum Drawdown, 최대 낙폭)

특정 기간 내 **고점 대비 최대 하락 폭**.

```
Drawdown(t) = (P(t) − MaxPeak(t)) ÷ MaxPeak(t)
MDD = min(Drawdown(t)) for all t
```

```
자산 가치:
100 → 120 → 80 → 110 → 90 → 130

고점:   100  120  120  120  120  130
낙폭:    0    0   -33%  -8% -25%   0
MDD = -33%  (120에서 80으로)
```

### MDD의 중요성

- 손실을 복구하는 데 걸리는 시간(Recovery Period)과 직결
- MDD 50% → 원금 회복에 **+100% 수익** 필요

```
손실률  → 회복에 필요한 수익률
-10%  → +11.1%
-20%  → +25.0%
-33%  → +50.0%
-50%  → +100.0%
-75%  → +300.0%
```

> monticker 백테스트 결과에서 MDD는 핵심 지표입니다.  
> MDD가 30% 이상이면 심리적으로 버티기 매우 어렵습니다.

## 13.3 VaR (Value at Risk)

**특정 신뢰 수준에서 특정 기간 동안 발생할 수 있는 최대 손실**.

```
VaR(95%, 1일) = X원
→ "오늘 하루 동안 95% 확률로 X원 이상 손실이 나지 않는다"
→ 달리 말하면, 5% 확률로 X원 초과 손실 가능
```

### 계산 방법

#### 역사적 시뮬레이션

과거 N일간의 실제 수익률을 정렬 → 하위 5% 지점이 VaR

```
과거 500일 일별 수익률 정렬
  하위 5% = 25번째 나쁜 날의 수익률
  → VaR(95%) = 그날 손실
```

#### 파라메트릭 방법 (정규분포 가정)

```
VaR(95%, 1일) = μ − 1.645 × σ
(μ: 평균 일별 수익률, σ: 일별 표준편차)
```

### VaR의 한계

- 정규분포 가정이 현실과 다름 (꼬리 위험 과소평가)
- **5%의 상황**이 실제로 어떤지 알 수 없음 → CVaR 필요

---

## 13.4 CVaR (Conditional VaR) / Expected Shortfall

VaR의 임계값을 **초과했을 때 평균 손실**.

```
CVaR(95%) = VaR(95%)를 초과하는 손실들의 평균
```

```
VaR(95%) = 100만원 손실
CVaR(95%) = 150만원 손실
→ 나쁜 5%의 날에는 평균적으로 150만원을 잃는다
```

VaR보다 꼬리 위험을 더 잘 반영합니다. 바젤 III 이후 금융 규제에서 CVaR을 더 선호합니다.

## 13.5 베타 (Beta)

포트폴리오가 **시장 지수(벤치마크) 대비 얼마나 민감하게 움직이는가**.

```
β = Cov(포트폴리오 수익률, 시장 수익률) ÷ Var(시장 수익률)
```

| β 값 | 의미 |
|------|------|
| β = 1 | 시장과 동일하게 움직임 |
| β > 1 | 시장보다 민감 (고위험 고수익) |
| β < 1 | 시장보다 덜 민감 (방어적) |
| β = 0 | 시장과 무관 (무상관) |
| β < 0 | 시장과 반대 (예: 인버스 ETF) |

예시:
- KOSPI +10% → β=1.5 주식은 약 +15%
- KOSPI -10% → β=1.5 주식은 약 -15%

## 13.6 상관계수 (Correlation) / 분산투자 효과

두 자산의 수익률이 **같은 방향으로 움직이는 정도**.

```
ρ(A,B) = Cov(A,B) ÷ (σA × σB)
범위: -1 ≤ ρ ≤ 1
```

| ρ 값 | 의미 |
|------|------|
| +1 | 완전 동행 (분산투자 효과 없음) |
| 0 | 무관 (분산투자 최대 효과) |
| -1 | 완전 역행 (완벽한 헤지) |

### 분산투자 효과

```
포트폴리오 분산 = w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρσ₁σ₂

ρ = -1이면 포트폴리오 분산 = 0 (위험 완전 제거)
ρ = 0이면 포트폴리오 분산 < 개별 분산의 가중 합
```

실제로 ρ = -1인 자산 조합은 거의 없지만, 낮은 상관계수만으로도 위험을 크게 줄일 수 있습니다.

---

## 13.7 트래킹 에러 (Tracking Error)

포트폴리오 수익률이 **벤치마크에서 얼마나 벗어나는지**의 표준편차.

```
TE = σ(포트폴리오 수익률 - 벤치마크 수익률)
```

- TE가 낮으면 → 인덱스 펀드에 가까운 포트폴리오
- TE가 높으면 → 적극적 운용 (Active Management)

---

## 요약

```
변동성(σ) = 수익률의 표준편차. 불확실성의 크기
MDD = 고점 대비 최대 낙폭. 버틸 수 있는 최악의 시나리오
VaR = 특정 신뢰도에서 최대 예상 손실
CVaR = VaR 초과 시 평균 손실 (꼬리 위험)
Beta = 시장 민감도
Correlation = 두 자산의 동행 정도 (낮을수록 분산 효과)
```
