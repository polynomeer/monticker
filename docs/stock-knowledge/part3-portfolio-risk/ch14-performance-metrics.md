# 14장. 성과 측정 지표

> **핵심 한 줄**: 좋은 전략은 많이 버는 것이 아니라, 리스크 한 단위당 더 많이 버는 것이다.

---

## 14.1 Sharpe Ratio

가장 널리 쓰이는 **위험 조정 수익률** 지표.

```
Sharpe Ratio = (Rp − Rf) ÷ σp

Rp: 포트폴리오 수익률
Rf: 무위험 이자율 (예: 국고채 3년물 금리)
σp: 포트폴리오 수익률의 표준편차
```

### 해석

| Sharpe | 평가 |
|--------|------|
| < 0 | 무위험 자산만 못함 |
| 0 ~ 1 | 보통 |
| 1 ~ 2 | 양호 |
| > 2 | 우수 |
| > 3 | 매우 우수 (장기 유지 어려움) |

### 예시 비교

| 전략 | 수익률 | 표준편차 | Rf=3% | Sharpe |
|------|--------|---------|-------|--------|
| A | 15% | 10% | 3% | **(15-3)/10 = 1.2** |
| B | 30% | 30% | 3% | (30-3)/30 = 0.9 |

A가 절대 수익률은 낮지만 위험 대비 효율이 더 좋습니다.

### Sharpe의 한계

- 상방 변동성과 하방 변동성을 동일하게 처리 (좋은 변동성도 패널티)
- 수익률이 정규분포를 따른다고 가정

---

## 14.2 Sortino Ratio

Sharpe의 한계를 보완: **하방 리스크만** 페널티로 사용.

```
Sortino Ratio = (Rp − Rf) ÷ σ_downside

σ_downside = 음의 수익률(손실 구간)만의 표준편차
```

상승 변동성은 좋은 것이므로 분모에서 제외합니다.  
일반적으로 Sortino > Sharpe인 전략이 더 선호됩니다.

---

## 14.3 Calmar Ratio

연환산 수익률을 **MDD(최대 낙폭)**로 나눈 값.

```
Calmar Ratio = 연환산 수익률 ÷ |MDD|
```

예시:
- 연 수익률: 20%
- MDD: 15%
- Calmar = 20 / 15 = **1.33**

### 해석

| Calmar | 의미 |
|--------|------|
| < 0.5 | 나쁨 |
| 0.5 ~ 1 | 보통 |
| > 1 | 좋음 |
| > 2 | 우수 |

Sharpe보다 **실제 심리적 고통**을 더 잘 반영합니다.  
투자자가 버텨야 했던 최악의 구간 대비 보상을 보여줍니다.

---

## 14.4 Information Ratio

벤치마크 대비 **초과 수익(Alpha)를 트래킹 에러로 나눈** 지표.

```
IR = Alpha ÷ Tracking Error
   = (Rp − Rb) ÷ σ(Rp − Rb)

Rb: 벤치마크 수익률
```

액티브 펀드 매니저 평가에 주로 사용합니다.  
IR > 0.5이면 우수한 액티브 운용으로 봅니다.

---

## 14.5 승률 (Win Rate) / 손익비 (Profit Factor)

### 승률 (Win Rate)

```
승률 = 이익 거래 수 ÷ 전체 거래 수 × 100%
```

### 손익비 (Profit Factor)

```
손익비 = 총 이익 ÷ 총 손실의 절댓값
```

| 손익비 | 의미 |
|--------|------|
| < 1.0 | 전략이 돈을 잃음 |
| 1.0 ~ 1.5 | 보통 |
| > 1.5 | 양호 |
| > 2.0 | 우수 |

### 승률과 손익비의 관계

**승률이 낮아도 수익 가능**:

```
승률 40%, 평균 수익:손실 = 3:1
기대값 = 0.4 × 3 − 0.6 × 1 = +0.6 (양수 → 수익)

승률 60%, 평균 수익:손실 = 1:2
기대값 = 0.6 × 1 − 0.4 × 2 = −0.2 (음수 → 손실)
```

> 높은 승률 전략이 반드시 좋은 전략이 아닙니다.  
> 손절을 제때 안 하면 승률은 높지만 한 번의 큰 손실로 모두 날릴 수 있습니다.

## 14.6 기대값 (Expected Value) 계산

한 번의 거래에서 **평균적으로 얼마를 기대할 수 있는가**.

```
EV = (승률 × 평균 수익) − (패율 × 평균 손실)
```

예시:
- 승률: 50%
- 평균 이익: 100,000원
- 평균 손실: 70,000원
- EV = (0.5 × 100,000) − (0.5 × 70,000) = 15,000원

EV > 0이면 **장기적으로 수익이 나는 전략**.


## 요약

```
Sharpe = (수익 - 무위험) / 전체 변동성
Sortino = (수익 - 무위험) / 하방 변동성 (더 공정)
Calmar = 연 수익 / MDD (버텨야 할 최악 대비 보상)
IR = Alpha / Tracking Error (액티브 운용 평가)
승률 × 손익비 = 전략의 기대값
높은 승률 ≠ 좋은 전략
```
