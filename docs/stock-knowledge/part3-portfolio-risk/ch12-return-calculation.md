# 12장. 수익률의 계산과 해석

> **핵심 한 줄**: 수익률은 "투자한 돈이 얼마나 불었는가"를 비율로 표현한 것이고, 어떻게 계산하느냐에 따라 결과가 달라진다.

---

## 12.1 단순 수익률 vs 로그 수익률

### 단순 수익률 (Simple Return, Arithmetic Return)

```
r = (P₁ − P₀) ÷ P₀ = P₁/P₀ − 1
```

예시: 50,000원에 사서 55,000원에 팜 → r = (55,000 − 50,000) / 50,000 = **+10%**

### 로그 수익률 (Log Return, Continuous Return)

```
r_log = ln(P₁ / P₀)
```

예시: ln(55,000 / 50,000) = ln(1.1) ≈ **+9.53%**

### 왜 두 가지가 있는가?

| 특성 | 단순 수익률 | 로그 수익률 |
|------|-----------|-----------|
| 직관성 | 높음 (% 그대로) | 낮음 |
| 합산 | 복잡 (곱으로 연결) | **간단 (덧셈으로 연결)** |
| 통계적 특성 | 비대칭 분포 | **정규분포에 가까움** |
| 퀀트 모델 적합성 | 낮음 | **높음** |

```
로그 수익률의 덧셈 특성:
r_log(총) = r_log(1일) + r_log(2일) + ... + r_log(N일)

단순 수익률은 곱셈:
(1 + r_total) = (1 + r₁) × (1 + r₂) × ...
```

> monticker의 백테스트 엔진은 내부 계산에 로그 수익률을 사용하고,  
> 사용자 표시는 단순 수익률(%)로 변환합니다.

## 12.2 누적 수익률 / 기간별 수익률

### 누적 수익률 (Cumulative Return)

```
누적 수익률 = (최종 자산 − 초기 자산) ÷ 초기 자산
           = (1 + r₁) × (1 + r₂) × ... × (1 + rₙ) − 1
```

예시:
- 1월: +10%
- 2월: -5%
- 3월: +8%
- 누적 = (1.10 × 0.95 × 1.08) − 1 = 1.1286 − 1 = **+12.86%**

(단순 합산 10 − 5 + 8 = 13%와 다름. 복리 효과)

### 일별/월별/연별 수익률 집계

```
일별 → 월별: (1 + r_d1) × (1 + r_d2) × ... − 1
월별 → 연별: (1 + r_m1) × (1 + r_m2) × ... × (1 + r_m12) − 1
```

---

## 12.3 연환산 수익률 (Annualized Return)

서로 다른 기간의 성과를 **연 단위로 비교**하기 위해 환산합니다.

```
연환산 수익률 = (1 + 누적 수익률)^(365 / 투자일수) − 1
```

예시:
- 6개월(180일)에 +15% 달성
- 연환산 = (1.15)^(365/180) − 1 = (1.15)^2.028 − 1 ≈ **+32.3%**

---

## 12.4 CAGR (Compound Annual Growth Rate, 연평균 복합 성장률)

다년간 투자 성과를 연 단위로 환산하는 표준 지표.

```
CAGR = (최종 가치 ÷ 초기 가치)^(1 / 연수) − 1
```

예시:
- 3년 전 1,000만원 투자
- 현재 1,728만원
- CAGR = (1,728 / 1,000)^(1/3) − 1 = 1.728^0.333 − 1 = **+20%**

```
검증: 1,000 × 1.2 × 1.2 × 1.2 = 1,728 ✓
```

CAGR은 중간의 등락을 무시하고 **평균적으로 매년 몇 % 성장했는가**를 보여줍니다.

---

## 12.5 벤치마크 대비 초과 수익률 (Alpha)

내 포트폴리오가 시장 지수(벤치마크)보다 얼마나 잘했는가.

```
Alpha = 포트폴리오 수익률 − 벤치마크 수익률
```

예시:
- 내 포트폴리오: +25%
- KOSPI 지수: +18%
- Alpha = +7% (시장보다 7%p 더 벌었음)

### 젠슨의 알파 (Jensen's Alpha)

리스크를 감안한 초과 수익률.

```
Jensen's Alpha = Rp − [Rf + β × (Rm − Rf)]

Rp: 포트폴리오 수익률
Rf: 무위험 이자율 (국고채 금리)
β: 포트폴리오의 베타
Rm: 시장 수익률
```

예시:
- Rp = 25%, Rf = 3%, β = 1.2, Rm = 18%
- 기대 수익률 = 3% + 1.2 × (18% − 3%) = 21%
- Jensen's Alpha = 25% − 21% = **+4%** (리스크 대비 초과 수익)

## 수익률 계산 체크리스트

투자 성과 보고서를 볼 때 반드시 확인해야 할 것:

- [ ] **기간이 명확한가?** "수익률 50%"는 1년인지 3년인지 모름
- [ ] **수수료/세금 포함인가?** 세전/세후 차이 큼
- [ ] **복리인가 단리인가?** 장기 투자에서 복리가 훨씬 큼
- [ ] **벤치마크와 비교했는가?** 시장이 30% 올랐는데 20% 올렸다면 나쁜 성과
- [ ] **운 vs 실력?** 단기 고수익은 운일 가능성 높음

## 요약

```
단순 수익률 = (P₁−P₀)/P₀ (일반 표현)
로그 수익률 = ln(P₁/P₀) (통계 모델용)
누적 수익률 = 복리 계산 (단순 합산 아님)
CAGR = 연평균 복합 성장률 (다년간 비교 기준)
Alpha = 시장 대비 초과 수익 (양수이면 시장 아웃퍼폼)
```
