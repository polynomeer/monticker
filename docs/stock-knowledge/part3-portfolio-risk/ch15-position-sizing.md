# 15장. 포지션 사이징

> **핵심 한 줄**: 어떤 종목을 사느냐보다 **얼마나 사느냐**가 장기 생존을 결정한다.

---

## 15.1 고정 금액 / 고정 비율

### 고정 금액 (Fixed Dollar)

매번 동일한 금액으로 투자.

```
총 자산: 10,000,000원
매 거래당 고정 금액: 1,000,000원
```

단순하지만 자산이 늘어도 투자 크기가 그대로여서 비효율적.

### 고정 비율 (Fixed Percentage)

총 자산의 **일정 비율**로 투자.

```
총 자산: 10,000,000원
투자 비율: 10%
→ 이번 거래 투자액: 1,000,000원

수익으로 자산 → 12,000,000원
→ 다음 거래 투자액: 1,200,000원 (자동 증가)
```

복리 성장을 자연스럽게 반영합니다.

---

## 15.2 Kelly Criterion (켈리 공식)

기대값이 양수인 게임에서 **최적 베팅 비율**을 수학적으로 도출합니다.

```
Kelly % = (p × b − q) ÷ b

p: 승률
q: 패율 = 1 - p
b: 승리 시 수익 / 손실 비율 (손익비)
```

예시:
- 승률 p = 60% (0.6)
- 손익비 b = 1.5 (이길 때 1.5배, 질 때 1배 손실)
- q = 0.4
- Kelly = (0.6 × 1.5 − 0.4) ÷ 1.5 = (0.9 − 0.4) / 1.5 = **33.3%**

→ 총 자산의 33.3%를 투자하는 것이 장기적으로 자산을 가장 빠르게 성장시킵니다.

### Kelly의 수학적 배경

Kelly 비율보다 많이 투자하면 → 장기적으로 자산이 **0으로 수렴**  
Kelly 비율이 최적 성장 지점

---

## 15.3 Half-Kelly / Fractional Kelly

Kelly 공식의 최대 투자 비율은 현실에서 **너무 위험**합니다.

실제 승률/손익비 추정에 오차가 있고, Kelly 전략은 **MDD가 매우 큼**.

```
Half-Kelly = Kelly % × 0.5
Quarter-Kelly = Kelly % × 0.25
```

실전에서 기관/헤지펀드는 대부분 **Quarter-Kelly 이하**를 사용합니다.

| 전략 | Kelly의 % | 기대 성장 | MDD |
|------|-----------|---------|-----|
| Full Kelly | 100% | 최대 | 매우 큼 |
| Half-Kelly | 50% | 75% 수준 | 절반 |
| Quarter-Kelly | 25% | 50% 수준 | 작음 |

---

## 15.4 리스크 퍼센트 방식 (1~2% Rule)

**한 번의 거래에서 총 자산의 1~2% 이상 잃지 않는다**는 원칙.

```
총 자산: 10,000,000원
허용 리스크: 1% = 100,000원

매수가: 55,000원
스톱 로스: 53,500원
손실 크기: 1,500원/주

최대 매수 수량 = 100,000 ÷ 1,500 = 66주
투자 금액 = 66 × 55,000 = 3,630,000원 (자산의 36%)
```

스톱 로스 거리에 따라 투자 수량이 자동 결정됩니다.  
변동성이 큰 종목 → 자동으로 적은 수량 매수.

---

## 15.5 변동성 기반 포지션 조정 (ATR 단위)

ATR을 단위로 삼아 종목 간 **위험의 크기를 동일하게** 맞춥니다.

```
단위 = (허용 리스크) ÷ ATR(N)

허용 리스크: 100,000원
ATR(14): 1,500원
→ 단위 = 100,000 ÷ 1,500 = 66주

다른 종목 ATR(14): 500원
→ 단위 = 100,000 ÷ 500 = 200주
```

같은 리스크 예산으로 변동성이 낮은 종목은 더 많이, 높은 종목은 더 적게 삽니다.

---

## 15.6 포지션 사이징과 포트폴리오 집중도

| 방법 | 권장 최대 단일 포지션 | 특징 |
|------|---------------------|------|
| 초보 투자자 | 5~10% | 안전 |
| 중급 투자자 | 10~20% | 균형 |
| 집중 투자 | 20~50% | 높은 확신 필요 |
| Kelly 이론 | 100% | 수학적 최적 (현실에서 위험) |

> 워런 버핏은 "분산투자는 무지의 보호막"이라 했지만,  
> 그의 버크셔도 실제로는 적당한 집중 투자를 합니다.

## 요약

```
고정 비율 = 자산의 일정 % 투자 (가장 단순하고 복리 친화적)
Kelly = 기대값 기반 수학적 최적 비율 (현실에서 과도)
Half-Kelly = Kelly의 50% (실전 권장)
1~2% Rule = 한 거래 최대 손실을 자산의 1~2%로 제한
ATR 방식 = 변동성 동일화 (다종목 포트폴리오)
```
