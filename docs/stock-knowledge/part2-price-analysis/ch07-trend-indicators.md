# 7장. 추세 지표

> **핵심 한 줄**: 추세 지표는 "지금 시장이 어느 방향으로 가고 있는가"를 수치로 표현한다.

---

## 7.1 이동평균선 (Moving Average)

과거 N일간의 종가를 평균 낸 선. 가격의 노이즈를 제거하고 추세를 드러냅니다.

### SMA (Simple Moving Average, 단순이동평균)

```
SMA(5) = (C₋₄ + C₋₃ + C₋₂ + C₋₁ + C₀) ÷ 5
```

- 모든 날의 종가에 동일한 가중치
- 계산이 단순하지만 최근 데이터에 민감하지 않음

### EMA (Exponential Moving Average, 지수이동평균)

최근 데이터에 더 높은 가중치를 부여합니다.

```
α = 2 ÷ (N + 1)
EMA₀ = α × C₀ + (1 - α) × EMA₋₁
```

N=10이면 α = 2/11 ≈ 0.182 → 오늘 종가가 18.2% 반영  
N=10 SMA보다 **가격 변화에 빠르게 반응**합니다.

### WMA (Weighted Moving Average, 가중이동평균)

최근 데이터에 선형 가중치를 부여.  
WMA(5) = (5×C₀ + 4×C₋₁ + 3×C₋₂ + 2×C₋₃ + 1×C₋₄) ÷ 15

### 어떤 MA를 써야 하나?

| 상황 | 추천 |
|------|------|
| 빠른 신호 필요 (단기) | EMA |
| 안정적 추세 파악 (중장기) | SMA |
| 일반적 퀀트 전략 | EMA |

### 주요 MA 기간

| 기간 | 의미 |
|------|------|
| MA(5) | 단기. 한 주의 평균 |
| MA(20) | 중기. 한 달의 평균 |
| MA(60) | 중장기. 한 분기 |
| MA(120) | 장기. 반년 |
| MA(200) | 추세의 최종 기준선 (기관 투자자 기준선) |

## 7.2 골든 크로스 / 데드 크로스

이동평균선 두 개가 교차하는 지점을 추세 전환 신호로 해석합니다.

### 골든 크로스 (Golden Cross) — 매수 신호

```
단기 MA (예: MA20)가 장기 MA (예: MA60)를 아래에서 위로 돌파
→ 상승 추세 시작 신호
```

```
        /  MA20
       / ×  ← 골든 크로스
      /   \______ MA60
```

### 데드 크로스 (Dead Cross) — 매도 신호

```
단기 MA가 장기 MA를 위에서 아래로 돌파
→ 하락 추세 시작 신호
```

> 단점: **후행 지표**입니다. 이미 많이 오른 후 신호가 나옵니다. "양치기 신호"가 많음.

## 7.3 MACD (Moving Average Convergence Divergence)

두 EMA의 차이를 이용해 추세의 **방향성과 모멘텀**을 동시에 파악합니다.

```
MACD Line    = EMA(12) − EMA(26)
Signal Line  = EMA(9) of MACD Line
Histogram    = MACD Line − Signal Line
```

### 해석

| 신호 | 의미 |
|------|------|
| **MACD > 0** | 단기 EMA > 장기 EMA. 상승 추세 |
| **MACD < 0** | 단기 EMA < 장기 EMA. 하락 추세 |
| **MACD 상향 돌파 Signal** | 매수 신호 |
| **MACD 하향 돌파 Signal** | 매도 신호 |
| **Histogram 양전환** | 모멘텀 증가 시작 |
| **다이버전스 (Divergence)** | 가격은 신고가인데 MACD는 저하 → 추세 약화 |

```
가격 차트:      ───/───/──────/──── (신고가 갱신)
MACD:           ───/──\/──────\ (고점 하락) → 하락 다이버전스 경고
```

## 7.4 파라볼릭 SAR (Parabolic Stop and Reverse)

추세 추종 + 손절가 제시를 동시에 하는 지표.

```
상승 추세 중: SAR 점이 캔들 아래에 표시 → 점이 가격에 닿으면 추세 종료 + 매도 신호
하락 추세 중: SAR 점이 캔들 위에 표시 → 점이 가격에 닿으면 추세 종료 + 매수 신호
```

파라미터:
- **AF (가속계수)**: 초기값 0.02, 신고/신저 갱신 시마다 0.02씩 증가, 최대 0.2

실제 스톱 로스 기준선으로 활용합니다.

## 7.5 ADX / +DI / -DI (Average Directional Index)

추세의 **강도(방향 아님)**를 측정합니다.

```
+DI: 상승 방향 움직임의 강도
-DI: 하락 방향 움직임의 강도
ADX: +DI와 -DI의 차이의 평균 → 추세 강도
```

| ADX 값 | 의미 |
|--------|------|
| 0 ~ 25 | 추세 없음 (횡보) |
| 25 ~ 50 | 추세 있음 |
| 50 ~ 75 | 강한 추세 |
| 75 ~ 100 | 매우 강한 추세 (드묾) |

```
ADX > 25 이고 +DI > -DI → 강한 상승 추세 중
ADX > 25 이고 -DI > +DI → 강한 하락 추세 중
ADX < 25 → 추세 추종 전략 피할 것
```

> monticker 퀀트 룰셋에서 `ADX > 25` 조건으로 추세장에서만 매매하는 필터를 구현할 수 있습니다.

## 지표 선택 가이드

| 목적 | 추천 지표 |
|------|----------|
| 추세 방향 | MA, EMA |
| 추세 전환 타이밍 | MACD, 골든/데드 크로스 |
| 추세 강도 확인 | ADX |
| 동적 스톱 로스 | 파라볼릭 SAR |

## 요약

```
SMA = 단순 평균 (후행, 안정적)
EMA = 최근에 더 가중치 (빠른 반응)
골든 크로스 = 단기 MA > 장기 MA → 매수 신호 (후행)
MACD = EMA 차이로 모멘텀 파악
ADX = 추세 강도만 (방향 X)
SAR = 동적 스톱 로스 기준
```
