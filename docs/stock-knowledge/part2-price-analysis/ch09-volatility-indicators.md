# 9장. 변동성 지표

> **핵심 한 줄**: 변동성 지표는 "가격이 얼마나 넓게 흔들리는가"를 측정해 리스크와 기회의 크기를 평가한다.

---

## 9.1 볼린저 밴드 (Bollinger Bands)

이동평균선 중심에 **표준편차 기반의 상·하단 밴드**를 씌운 지표.

```
Middle Band = SMA(20)
Upper Band  = SMA(20) + (2 × 표준편차)
Lower Band  = SMA(20) − (2 × 표준편차)
```

정규분포 기준으로 가격의 **약 95%가 밴드 안에** 머뭅니다.

### 밴드 폭 (Bandwidth)

```
Bandwidth = (Upper − Lower) ÷ Middle × 100
```

- 밴드가 좁아짐 = 변동성 축소 (스퀴즈). **큰 움직임 예고**
- 밴드가 넓어짐 = 변동성 확대. 추세 진행 중

### 주요 신호

| 상황 | 해석 |
|------|------|
| 가격이 Upper Band 돌파 | 과매수 또는 강한 상승 추세 |
| 가격이 Lower Band 하향 돌파 | 과매도 또는 강한 하락 추세 |
| 가격이 Middle Band(SMA20) 위 유지 | 상승 추세 |
| 밴드 스퀴즈 후 돌파 | 방향성 급등락 시작 신호 |
| 더블 바텀 (W패턴, Lower Band에서) | 상승 반전 신호 |

```
밴드 스퀴즈:

Upper ──────────────────────────────
         ╔════╗           ← 스퀴즈 구간
Middle ─ ╚════╝ ─────────/──
         ────────── Lower /
                        ↑ 돌파 후 급등
```

> monticker 백테스트 룰셋에서 볼린저 밴드 하단 이탈 → 매수, 상단 이탈 → 매도 전략을 자주 씁니다.

## 9.2 ATR (Average True Range)

**True Range**: 가격 이동의 실제 범위를 측정하는 값.

```
True Range = max(
    H − L,            ← 당일 고저 차이
    |H − C₋₁|,       ← 전일 종가 대비 당일 고가
    |L − C₋₁|        ← 전일 종가 대비 당일 저가
)

ATR(N) = True Range의 N일 이동평균 (보통 14일)
```

### 활용

#### 스톱 로스 설정

```
매수가: 55,000원
ATR(14): 1,500원
스톱 가격: 55,000 − (2 × 1,500) = 52,000원
```

ATR 기반 스톱은 **변동성에 맞게 자동 조정**됩니다.  
변동성이 큰 종목은 더 넓은 스톱, 안정적인 종목은 좁은 스톱.

#### 포지션 사이징

```
리스크 허용액: 100,000원
ATR: 1,500원
→ 최대 보유 주식 수 = 100,000 ÷ 1,500 = 약 66주
```

> monticker의 `RiskCalculator`에서 ATR 기반 포지션 사이징을 지원합니다.

## 9.3 역사적 변동성 (Historical Volatility, HV)

과거 가격 데이터로 계산한 **실제 변동성**.

```
일일 로그 수익률: r_i = ln(C_i / C_{i-1})
HV(N) = 표준편차(r_i) × √252  ← 연환산
```

√252를 곱하는 이유: 연간 거래일이 약 252일이므로 일별 변동성을 연 단위로 환산.

```
일 변동성 1% → HV = 1% × √252 ≈ 15.87%
```

HV가 높을수록:
- 리스크 큼 → 더 넓은 스톱 로스 필요
- 옵션 프리미엄이 비쌈
- 포트폴리오 집중 시 위험

---

## 9.4 내재 변동성 (Implied Volatility, IV)

**옵션 시장에서 역산된** 미래 변동성 예측치.

```
옵션 가격 = f(현재 주가, 행사가, 만기, 무위험 이자율, 변동성)
IV = 현재 옵션 시장 가격을 블랙-숄즈 모형에 대입해 역산한 변동성
```

- HV는 과거 / IV는 **시장이 예상하는 미래**
- IV가 HV보다 높으면 → 옵션이 비싸게 거래됨 (불안감)
- IV가 HV보다 낮으면 → 옵션이 싸게 거래됨 (안정 기대)

---

## 9.5 VIX (공포지수)

**S&P 500 옵션의 내재 변동성 지수**. Chicago Board Options Exchange(CBOE)가 산출.

| VIX 값 | 시장 분위기 |
|--------|-----------|
| 10~15 | 매우 안정. 낮은 공포 |
| 15~20 | 보통 |
| 20~30 | 불안. 경계 |
| 30 이상 | 공포. 급락 가능성 |
| 50 이상 | 공황 (2008 금융위기, 2020 코로나 당시) |

한국판 VIX: **VKOSPI** (KOSPI200 옵션 기반)

```
VIX와 S&P 500은 강한 음의 상관관계
주가 급락 → VIX 급등 (역관계)
```

> 글로벌 시장의 위험 선호도를 판단할 때 VIX를 참고합니다.  
> VIX 급등 시 monticker의 이벤트 감지기가 "글로벌 리스크 상승" 이벤트를 발행할 수 있습니다.

## 지표별 특성 비교

| 지표 | 성격 | 주요 용도 |
|------|------|----------|
| 볼린저 밴드 | 상대적 변동성 | 과매수/과매도, 돌파 신호 |
| ATR | 절대적 변동성 | 스톱 설정, 포지션 사이징 |
| HV | 과거 변동성 | 리스크 평가, 옵션 비교 |
| IV | 미래 기대 변동성 | 옵션 가격 평가 |
| VIX | 시장 공포 지수 | 글로벌 센티멘트 |

## 요약

```
볼린저 밴드 = SMA ± 2σ (변동성 기반 동적 채널)
밴드 스퀴즈 = 큰 움직임 예고
ATR = 실제 가격 진폭. 스톱 로스 설정에 핵심
HV = 과거 변동성 (연환산)
IV = 옵션 시장이 예상하는 미래 변동성
VIX = 미국 시장 공포 지수
```
