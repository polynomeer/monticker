# 8장. 모멘텀 지표

> **핵심 한 줄**: 모멘텀 지표는 "가격이 얼마나 빠르게, 얼마나 강하게 움직이는가"를 측정해 과열/과냉을 판단한다.

---

## 8.1 RSI (Relative Strength Index, 상대강도지수)

가장 널리 사용되는 모멘텀 지표. **0~100 사이의 값**으로 과매수/과매도를 판단합니다.

### 계산법

```
RS = 평균 상승폭 ÷ 평균 하락폭  (기간: 보통 14일)
RSI = 100 − (100 ÷ (1 + RS))
```

예시 (14일 기준):
- 상승한 날의 평균 변화: 1.2원
- 하락한 날의 평균 변화: 0.8원
- RS = 1.2 / 0.8 = 1.5
- RSI = 100 − (100 / 2.5) = 60

### 해석 기준

| RSI 값 | 의미 | 행동 |
|--------|------|------|
| **70 이상** | 과매수 (Overbought) | 매도 신호 검토 |
| **30 이하** | 과매도 (Oversold) | 매수 신호 검토 |
| **50 기준선** | 50 상향 = 강세 / 하향 = 약세 |
| **다이버전스** | 가격 신고가 + RSI 하락 → 약세 다이버전스 |

```
RSI: 70 ──┐         (과매수 구간)
           │
RSI: 50 ─────────── (중립)
           │
RSI: 30 ──┘         (과매도 구간)
```

> **주의**: RSI 70 = 즉시 매도 신호가 아닙니다.  
> 강한 상승 추세에서는 RSI가 80~90을 유지할 수 있습니다.  
> 추세 지표(ADX, MA)와 **반드시 함께** 사용해야 합니다.

## 8.2 Stochastic (스토캐스틱)

현재 가격이 최근 N일의 고가/저가 범위에서 **어디에 위치하는지**를 백분율로 표현합니다.

```
%K = (현재 종가 − N일 최저가) ÷ (N일 최고가 − N일 최저가) × 100
%D = %K의 M일 SMA (보통 3일)
```

### 파라미터 (5, 3, 3)이 기본

- N=5: 5일 기간
- M=3: %D 평활 기간
- 슬로우 스토캐스틱: %K를 한 번 더 평활화

### 해석

| 값 | 의미 |
|----|------|
| **%K > 80** | 과매수 |
| **%K < 20** | 과매도 |
| **%K가 %D를 상향 돌파 (20 이하에서)** | 매수 신호 |
| **%K가 %D를 하향 돌파 (80 이상에서)** | 매도 신호 |

RSI와 차이점: RSI는 변화의 속도, 스토캐스틱은 **위치(range 내 위치)**에 집중합니다.

---

## 8.3 Williams %R

스토캐스틱과 유사하지만 **역방향(−100 ~ 0)**으로 표시됩니다.

```
%R = (N일 최고가 − 현재 종가) ÷ (N일 최고가 − N일 최저가) × (−100)
```

| 값 | 의미 |
|----|------|
| **0 ~ -20** | 과매수 구간 |
| **-80 ~ -100** | 과매도 구간 |

스토캐스틱과 매우 유사하므로 함께 사용하는 것은 중복입니다.

---

## 8.4 CCI (Commodity Channel Index)

현재 가격이 **통계적 평균에서 얼마나 벗어났는지**를 측정합니다.

```
Typical Price (TP) = (H + L + C) ÷ 3
Mean TP = TP의 N일 SMA
Mean Deviation = TP와 Mean TP 차이의 평균
CCI = (TP − Mean TP) ÷ (0.015 × Mean Deviation)
```

| 값 | 의미 |
|----|------|
| **+100 이상** | 과매수 (강한 상승 추세) |
| **-100 이하** | 과매도 (강한 하락 추세) |
| **0 기준선** | 중립 |

원래 원자재(Commodity) 시장용이었지만 주식에도 널리 적용합니다.

---

## 8.5 ROC (Rate of Change, 변화율)

N일 전 가격 대비 현재 가격의 **변화율(%)** 을 직접적으로 표시합니다.

```
ROC(N) = (현재 종가 − N일 전 종가) ÷ N일 전 종가 × 100
```

예시:
- 오늘 종가: 55,000원
- 10일 전 종가: 50,000원
- ROC(10) = (55,000 − 50,000) / 50,000 × 100 = +10%

### 활용

- **모멘텀 전략**: 최근 6~12개월 ROC가 높은 종목 매수
- **0선 교차**: ROC가 0을 상향 돌파 → 매수, 하향 이탈 → 매도
- 팩터 투자의 **모멘텀 팩터** 계산에 사용

> monticker 스크리너에서 `roc_20d`, `roc_60d` 같은 파라미터로 모멘텀 기반 필터링을 지원합니다.

## 모멘텀 지표 비교

| 지표 | 범위 | 주요 신호 | 장점 |
|------|------|----------|------|
| RSI | 0~100 | 70/30 | 가장 보편적, 다이버전스 활용 |
| Stochastic | 0~100 | 80/20 | 단기 과매수/과매도 정확 |
| Williams %R | -100~0 | -20/-80 | 단기 반전 포착 |
| CCI | 제한 없음 | ±100 | 비정상적 가격 움직임 포착 |
| ROC | % | 0 교차 | 모멘텀 크기 직접 측정 |

### 함께 쓰면 좋은 조합

```
추세 지표 (ADX/MA) → 추세 방향 확인
                  +
모멘텀 지표 (RSI) → 진입 타이밍 포착
                  +
거래량 지표 (OBV/VWAP) → 신호 신뢰도 확인
```

---

## 요약

```
RSI = 상승/하락 강도 비율 (14일 기준, 70/30 기준선)
Stochastic = 최근 범위 내 현재 위치 (80/20 기준선)
ROC = N일 전 대비 변화율 (모멘텀 팩터)
CCI = 통계적 평균에서의 이탈 정도
모멘텀 지표 단독 사용 위험 → 추세 지표와 함께 사용
```
