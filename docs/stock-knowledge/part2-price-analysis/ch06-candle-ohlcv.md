# 6장. 캔들과 OHLCV

> **핵심 한 줄**: 캔들 하나는 특정 시간 동안 가격이 어떻게 움직였는지를 4개의 숫자(OHLC)와 거래량(V)으로 압축한 것이다.

---

## 6.1 OHLCV 정의

| 약자 | 이름 | 의미 |
|------|------|------|
| **O** | Open (시가) | 해당 시간 구간 첫 번째 체결 가격 |
| **H** | High (고가) | 해당 시간 구간 중 가장 높은 체결 가격 |
| **L** | Low (저가) | 해당 시간 구간 중 가장 낮은 체결 가격 |
| **C** | Close (종가) | 해당 시간 구간 마지막 체결 가격 |
| **V** | Volume (거래량) | 해당 시간 구간 동안 거래된 총 주식 수 |

### 시간 단위 (Timeframe)

| 구분 | 설명 |
|------|------|
| **틱(Tick)** | 체결 1건마다 하나의 캔들. 가장 세밀한 단위 |
| **1분봉** | 1분 단위. 단기 스캘핑 트레이더 사용 |
| **5분봉, 15분봉, 30분봉** | 데이 트레이더 주로 사용 |
| **1시간봉** | 스윙 트레이더 참고 |
| **일봉 (Daily)** | 하루 단위. 가장 일반적 |
| **주봉 (Weekly)** | 한 주 단위. 중장기 추세 파악 |
| **월봉 (Monthly)** | 한 달 단위. 장기 투자자 |

> monticker의 `Candle` 모델은 `timeframe` 필드로 1m, 5m, 15m, 1h, 1d 등을 구분합니다.

---

## 6.2 캔들 형태 해석

```
         │  ← 위 꼬리 (Upper Shadow / Upper Wick)
         │     고가(H)까지 올라갔다가 내려온 흔적
    ┌────┤
    │    │  ← 몸통 (Body): 시가와 종가 사이 구간
    │    │
    └────┤
         │  ← 아래 꼬리 (Lower Shadow / Lower Wick)
         │     저가(L)까지 내려갔다가 올라온 흔적
```

### 양봉 (Bullish / Green Candle)

**종가 > 시가**: 가격이 올랐음. 매수세 우위.

```
     │
  ┌──┘  ← Close (종가) — 더 높음
  │
  │  몸통: 올랐음
  │
  └──┐  ← Open (시가) — 더 낮음
     │
```

### 음봉 (Bearish / Red Candle)

**종가 < 시가**: 가격이 내렸음. 매도세 우위.

```
     │
  ┌──┘  ← Open (시가) — 더 높음
  │
  │  몸통: 내렸음
  │
  └──┐  ← Close (종가) — 더 낮음
     │
```

### 주요 캔들 패턴

| 패턴 | 형태 | 의미 |
|------|------|------|
| **도지 (Doji)** | 시가 ≈ 종가 (십자형) | 매수/매도 균형. 추세 전환 가능성 |
| **망치 (Hammer)** | 긴 아래 꼬리, 짧은 몸통 | 하락 추세에서 반전 가능성 |
| **역망치 (Inverted Hammer)** | 긴 위 꼬리, 짧은 몸통 | 상승 반전 가능성 |
| **팽이 (Spinning Top)** | 짧은 몸통, 양쪽 꼬리 | 방향 불확실 |
| **마루보즈 (Marubozu)** | 꼬리 없는 긴 몸통 | 강한 일방향 움직임 |

## 6.3 시가/종가/고가/저가의 의미

### 시가 (Open)

- 장 시작 시 처음 체결된 가격
- **동시호가**로 결정되므로 전일 종가와 다를 수 있음 (갭 발생)
- 장전 호재/악재가 시가에 반영됨

### 종가 (Close)

- 가장 중요한 가격. 대부분의 기술적 지표(MA, RSI 등)는 종가 기준으로 계산
- 당일의 "최종 판단"을 나타냄
- 기관의 매수/매도 판단이 장 마감 시 집중되는 경향

### 고가/저가 (High/Low)

- 장중 가격의 극단값
- ATR, 볼린저 밴드 등에서 변동성 계산에 사용
- 지지/저항 분석에서 의미 있는 가격대

---

## 6.4 거래량 (Volume)의 중요성

거래량은 **가격 변동의 신뢰도를 검증**하는 도구입니다.

```
가격 상승 + 거래량 증가 → 강한 상승. 신뢰할 수 있는 추세
가격 상승 + 거래량 감소 → 약한 상승. 지속 가능성 의심
가격 하락 + 거래량 급증 → 공황 매도. 바닥 형성 가능성
가격 횡보 + 거래량 감소 → 관심 저하. 큰 움직임 전 조용한 시기
```

### 거래대금 vs 거래량

- **거래량**: 거래된 주식 수 (단위: 주)
- **거래대금**: 거래된 금액 (단위: 원) = 거래량 × 평균 체결가

고가 주식(예: 삼성바이오로직스 80만원)은 거래량이 적어도 거래대금이 클 수 있습니다.  
서로 다른 종목 간 유동성 비교 시 **거래대금**을 사용합니다.

## 6.5 갭 (Gap)

전일 종가와 당일 시가 사이의 **가격 공백**.

```
전일 종가: 50,000원
당일 시가: 52,000원  → 상승갭(Gap Up) +4%
```

### 갭의 종류

| 종류 | 상황 | 의미 |
|------|------|------|
| **상승갭 (Gap Up)** | 시가 > 전일 종가 | 장전 호재 (실적 발표, 공시 등) |
| **하락갭 (Gap Down)** | 시가 < 전일 종가 | 장전 악재 |
| **갭 메우기 (Gap Fill)** | 갭이 발생한 후 이전 가격대로 복귀 | 빈번히 발생. 갭 레벨이 지지/저항 역할 |
| **섬형 반전 (Island Reversal)** | 연속 갭으로 고립된 캔들 섬 형성 | 강한 추세 전환 신호 |

> monticker의 `StockEvent` 감지기는 갭 상승/하락을 중요 이벤트로 감지하고 알림을 발행합니다.

## 6.6 캔들 데이터 파이프라인 (monticker)

```
시장 체결 데이터 (틱)
        │
        ▼
  Tick Aggregator
   (1분 단위 집계)
        │
        ▼
  1분봉 Candle ──► Redis Streams ──► 구독 클라이언트
        │                              (WebSocket)
        ▼
  TimescaleDB
  (장기 보관)
        │
        ▼
  5분/15분/1시간/일봉 집계
  (materialized view 또는 집계 서비스)
```

## 요약

```
OHLCV = Open, High, Low, Close, Volume
양봉 = 종가 > 시가 (상승)
음봉 = 종가 < 시가 (하락)
거래량 = 가격 신뢰도 검증 도구
갭 = 전일 종가와 당일 시가의 차이
```
