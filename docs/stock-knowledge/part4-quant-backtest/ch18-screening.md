# 18장. 스크리닝 (Screening)

> **핵심 한 줄**: 스크리닝은 수천 개 종목 중 내 조건에 맞는 후보만 걸러내는 1차 필터다.

---

## 18.1 스크리너의 역할

한국 주식 시장에는 **2,500개 이상의 종목**이 상장되어 있습니다.  
모든 종목을 직접 분석하는 것은 불가능하므로, **정량 조건**으로 후보를 좁혀야 합니다.

```
전체 종목 2,500개
    │
    ▼ 1단계: 유동성 필터 (거래대금 > 5억, 시총 > 300억)
    │
    ▼ 2단계: 재무 필터 (PER < 15, PBR < 1.5, ROE > 10%)
    │
    ▼ 3단계: 기술적 필터 (RSI < 40, 거래량 급등)
    │
    ▼ 최종 후보: 20~50개 → 상세 분석
```

스크리닝은 **제거**하는 과정이지, 선택하는 과정이 아닙니다.

---

## 18.2 재무 지표 기반 스크리닝

### 가치 지표 필터

```
PER < 10        → 이익 대비 저평가
PBR < 1         → 자산 대비 저평가
EV/EBITDA < 8   → 기업가치 대비 저평가
PSR < 0.5       → 매출 대비 저평가
```

### 수익성 지표 필터

```
ROE > 10%          → 자기자본 대비 이익 우수
영업이익률 > 5%    → 본업에서 충분한 이익
매출 성장률 > 0    → 성장 중
이익 성장률 > 0    → 이익도 증가
```

### 재무 건전성 필터

```
부채비율 < 100%    → 재무 안정
유동비율 > 150%    → 단기 지급 능력
이자보상배율 > 3   → 이자를 이익으로 충분히 감당
```

---

## 18.3 기술적 지표 기반 스크리닝

### 과매도 반전 스크리닝

```
RSI(14) < 30               → 과매도 구간
가격 > MA(200)              → 장기 상승 추세 유지 중
거래량 > 평균 거래량 × 1.5  → 관심 증가
```

### 추세 돌파 스크리닝

```
종가 > MA(20)                          → 단기 추세 상
종가가 52주 신고가 90% 이상             → 강세 구간
MACD 히스토그램 양전환                  → 모멘텀 반전
```

### 변동성 수축 후 돌파

```
볼린저 밴드 폭 < 최근 20일 최소값       → 스퀴즈 상태
오늘 종가 > 어제 볼린저 상단            → 상단 돌파
거래량 > 평균의 2배                     → 돌파 신뢰성 확보
```

## 18.4 거래량·변동률 급등 감지

monticker의 실시간 이벤트 감지기가 이를 자동으로 탐지합니다.

### 거래량 급등

```
기준: 오늘 거래량 ÷ 과거 20일 평균 거래량 > N
```

| 비율 | 중요도 |
|------|--------|
| 2배 | Low |
| 3배 | Medium |
| 5배 | High |
| 10배+ | Critical (뉴스/공시 확인 필수) |

### 가격 급등/급락

```
기준: 당일 수익률 절댓값 > N%
```

| 기준 | 의미 |
|------|------|
| ±5% | 관심 |
| ±10% | 중요 이벤트 |
| ±15%+ | 테마주 또는 공시 |
| +29% ~ +30% | 상한가 근접 |
| -29% ~ -30% | 하한가 근접 |

## 18.5 monticker 스크리너 사용법

```
GET /api/screener?
  exchange=KOSPI
  &market_cap_min=100000000000    ← 1,000억 이상
  &per_max=15
  &pbr_max=1.5
  &roe_min=0.10
  &rsi_14_max=40
  &volume_ratio_min=1.5
  &sort=volume_ratio_desc
  &page=0&size=20
```

### 스크리너 조건 저장 및 알림

```
POST /api/screener/watchlist
{
  "name": "가치주 과매도 스캔",
  "conditions": { ... },
  "alertEnabled": true
}
```

조건에 맞는 종목이 나타나면 실시간 알림을 받을 수 있습니다.

## 스크리닝 주의사항

1. **Look-ahead Bias 방지**: 스크리닝 당시 알 수 없었던 미래 데이터를 사용하지 말 것
2. **생존자 편향**: 현재 상장된 종목만 볼 경우 이미 상장폐지된 종목의 나쁜 성과를 누락
3. **지표 중복**: PER, PBR, PSR을 동시에 쓰면 같은 팩터를 중복 측정
4. **데이터 품질**: 재무 데이터 오류, 계절성 고려

## 요약

```
스크리닝 = 수천 종목 → 수십 후보로 필터링
재무 필터: 가치(PER/PBR) + 수익성(ROE) + 건전성(부채)
기술 필터: RSI + MA + 거래량
급등 감지: 거래량 비율, 가격 변화율 실시간 모니터링
스크리닝은 시작이지 끝이 아님 → 상세 분석 필요
```
