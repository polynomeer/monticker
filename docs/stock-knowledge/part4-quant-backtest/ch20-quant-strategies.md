# 20장. 퀀트 전략 유형

> **핵심 한 줄**: 퀀트 전략은 인간의 감정을 배제하고 규칙에 따라 일관되게 투자한다는 것이 핵심이다.

---

## 20.1 추세추종 (Trend Following)

**"오르는 것은 더 오른다, 내리는 것은 더 내린다"는 관성 효과를 이용.**

### 기본 구조

```
진입 조건: 가격 > MA(200) AND MA(50) > MA(200) (골든 크로스)
청산 조건: 가격 < MA(200) OR 스톱 로스 발동

또는:

진입: 52주 신고가 돌파
청산: 52주 고가 대비 20% 하락 (트레일링 스톱)
```

### 특성

| 항목 | 내용 |
|------|------|
| 승률 | 낮음 (30~45%) |
| 손익비 | 높음 (2~5배) |
| 기대값 | 양수 (손익비가 승률 단점 상쇄) |
| 단점 | 횡보장에서 잦은 거짓 신호(휩쏘) |
| 강점 | 대형 추세 포착 |

> **몇 번의 큰 승리가 많은 작은 손실을 메운다는 원리.**

---

## 20.2 평균회귀 (Mean Reversion)

**"멀리 벗어난 것은 평균으로 돌아온다"는 원리.**

```
진입 조건: RSI(14) < 30 (과매도) → 매수
청산 조건: RSI(14) > 50 → 매도

또는 볼린저 밴드:
진입: 하단 밴드 이탈 → 매수
청산: 중간 밴드(MA20) 도달 → 매도
```

### 특성

| 항목 | 내용 |
|------|------|
| 승률 | 높음 (60~70%) |
| 손익비 | 낮음 (1~1.5배) |
| 단점 | 강한 추세장에서 역추세 포지션으로 큰 손실 |
| 강점 | 횡보장에서 꾸준한 수익 |

추세추종과 반대 특성이므로 **두 전략을 결합**하면 시장 환경에 강인한 포트폴리오가 됩니다.

---

## 20.3 페어 트레이딩 (Pairs Trading)

**역사적으로 함께 움직이던 두 종목이 일시적으로 벌어지면, 좁혀질 것으로 베팅.**

```
종목 A (예: 삼성전자), 종목 B (예: SK하이닉스)
→ 두 종목은 반도체 업종으로 강한 상관관계

스프레드 = 가격A ÷ 가격B (또는 로그 차이)
→ 스프레드가 평균 + 2σ 이상 → 종목A 매도 + 종목B 매수
→ 스프레드가 평균으로 회귀 → 청산
```

### 장점

- **시장 중립(Market Neutral)**: 전체 시장이 오르거나 내려도 상관없음
- 개별 이벤트 리스크 감소

### 단점

- 상관관계가 **영구히 깨지는 경우** (구조적 변화)
- 두 포지션 동시 관리의 복잡성

---

## 20.4 통계적 차익거래 (Statistical Arbitrage, Stat Arb)

페어 트레이딩을 수십~수백 쌍으로 확장한 것.

```
같은 섹터 내 20개 종목 쌍을 동시에 트레이딩
→ 포트폴리오 수준에서 시장 중립 유지
→ 개별 쌍의 노이즈가 서로 상쇄
```

기술적 복잡도 높음. 고빈도 데이터와 빠른 실행 필요.

## 20.5 모멘텀 전략

**17장의 모멘텀 팩터를 직접 전략으로 구현.**

### 크로스 섹션 모멘텀 (Cross-Sectional Momentum)

```
매월 리밸런싱:
  1. 전체 종목을 과거 12개월(최근 1개월 제외) 수익률로 정렬
  2. 상위 20%: 매수 (Long)
  3. 하위 20%: 매도 (Short) ← 공매도 가능 시장에서
```

### 시계열 모멘텀 (Time-Series Momentum, TSMOM)

```
각 종목 개별 판단:
  과거 12개월 수익률 > 0 → 매수
  과거 12개월 수익률 < 0 → 매도
```

---

## 20.6 마켓 타이밍 (Market Timing)

**시장 전체의 방향을 예측해 주식 비중을 조절.**

```
방어적 마켓 타이밍:
  KOSPI > MA(200): 주식 100%
  KOSPI < MA(200): 채권 또는 현금 100%
```

```
변동성 조정:
  VIX < 20: 주식 80%
  VIX > 30: 주식 40%, 현금 60%
```

> 대부분의 연구에서 장기적으로 Buy & Hold와 유사하거나 오히려 열등한 경우도 있습니다.  
> 완벽한 타이밍은 없지만 **리스크 관리 목적**으로 부분 활용합니다.

## monticker에서의 전략 구현

### 룰셋(RuleSet) 빌더 구조

```kotlin
data class QuantRule(
    val entryConditions: List<Condition>,   // 진입 조건들 (AND)
    val exitConditions: List<Condition>,    // 청산 조건들 (OR)
    val stopLossPct: Double?,              // 스톱 로스 (%)
    val takeProfitPct: Double?,            // 이익 실현 (%)
    val positionSizingMethod: SizingMethod,
    val holdingDaysMax: Int?,              // 최대 보유 기간
)
```

### 전략 유형별 파라미터 예시

```json
{
  "name": "RSI 역추세 전략",
  "type": "MEAN_REVERSION",
  "entryConditions": [
    {"indicator": "RSI_14", "operator": "LESS_THAN", "value": 30},
    {"indicator": "MA_200", "operator": "PRICE_ABOVE", "value": null}
  ],
  "exitConditions": [
    {"indicator": "RSI_14", "operator": "GREATER_THAN", "value": 50}
  ],
  "stopLossPct": 0.08,
  "positionSizingMethod": "RISK_PERCENT",
  "riskPercent": 0.01
}
```

## 요약

```
추세추종: 오르면 사고 내리면 팜. 낮은 승률, 높은 손익비
평균회귀: 벗어나면 돌아온다. 높은 승률, 낮은 손익비
페어 트레이딩: 두 종목 스프레드 거래. 시장 중립
통계적 차익거래: 다수 쌍의 Stat Arb. 고난도
모멘텀: 팩터 기반 순위 → 상위 매수
마켓 타이밍: 시장 전체 방향 예측 (어려움)
추세추종 + 평균회귀 결합 → 환경에 강인한 포트폴리오
```
