# 17장. 팩터 투자 (Factor Investing)

> **핵심 한 줄**: 팩터는 "왜 어떤 주식들이 체계적으로 더 잘 되는가"에 대한 학문적 설명이다.

---

## 17.1 팩터란 무엇인가

**팩터(Factor)**는 주식 수익률의 **공통 원인**을 설명하는 변수입니다.

특정 특성(팩터)을 가진 주식들이 장기적으로 시장 평균보다 높은 수익률을 냈다는  
수십 년의 학술 연구 결과를 투자 전략으로 구현한 것이 **팩터 투자(스마트 베타)**.

```
수익률 = 시장 수익률(β) + 팩터 프리미엄들 + 잔차(개별 요인)
```

---

## 17.2 가치 팩터 (Value Factor)

**저평가된 주식이 장기적으로 고평가 주식보다 높은 수익률을 낸다.**

### 주요 지표

| 지표 | 공식 | 해석 |
|------|------|------|
| **PER** (주가수익비율) | 주가 ÷ EPS | 낮을수록 저평가 |
| **PBR** (주가순자산비율) | 주가 ÷ BPS | 1 미만이면 장부가 이하 |
| **PCR** (주가현금흐름비율) | 주가 ÷ CFPS | 낮을수록 현금창출 대비 저평가 |
| **PSR** (주가매출비율) | 시가총액 ÷ 매출액 | 낮을수록 저평가 |
| **EV/EBITDA** | 기업가치 ÷ EBITDA | 부채 포함 가치 대비 이익 |

```
EPS (주당순이익) = 당기순이익 ÷ 발행주식 수
BPS (주당순자산) = 자기자본 ÷ 발행주식 수
EBITDA = 이자/세금/감가상각 전 이익
```

### 가치 투자의 논리

- 시장은 단기적으로 **과잉 반응**해 좋은 기업을 비싸게, 나쁜 기업을 싸게 평가
- 장기적으로 **평균 회귀(Mean Reversion)** → 저평가 주식이 제 가치를 찾아감
- **경고**: 가치주 함정(Value Trap) — 싼 이유가 있는 경우

---

## 17.3 모멘텀 팩터 (Momentum Factor)

**최근 수익률이 좋았던 주식이 계속 좋은 성과를 낸다 (관성 효과).**

```
크로스 섹션 모멘텀:
  과거 12개월 수익률 (최근 1개월 제외) 기준으로 상위 종목 매수
  → 1개월 보유 후 리밸런싱
```

### 왜 작동하는가

- 정보의 느린 확산 (Slow Diffusion)
- 투자자들의 과소 반응 (Underreaction)
- 추세추종 플레이어들의 집결

### 모멘텀 팩터의 위험

- **모멘텀 크래시**: 시장 급반전 시 모멘텀 전략이 큰 손실
- 2009년 3월 반등: 모멘텀 주식 급락

---

## 17.4 품질 팩터 (Quality Factor)

**재무적으로 건전한 기업이 장기적으로 더 잘 된다.**

| 지표 | 의미 |
|------|------|
| **ROE** (자기자본이익률) | 주주 자본 대비 이익 창출 능력 |
| **ROA** (총자산이익률) | 전체 자산 대비 이익 |
| **영업이익률** | 매출에서 영업비용 제외 후 |
| **부채비율** | 부채 ÷ 자기자본 (낮을수록 안전) |
| **이익의 일관성** | 변동성 없이 꾸준한 이익 |
| **Accruals** | 현금 기반 이익 vs 발생주의 이익 차이 |

```
ROE = 당기순이익 ÷ 자기자본 × 100
ROE 15% 이상이 일반적으로 "우수"한 기준
```

---

## 17.5 저변동성 팩터 (Low Volatility Factor)

**변동성이 낮은 주식이 장기적으로 변동성이 높은 주식보다 리스크 대비 성과가 좋다.**

이것은 직관에 반하는 현상 — "High Risk = High Return"의 역설.

이유:
- 손실 회피 심리 (Lottery Preference)
- 레버리지 제약 기관의 안전자산 선호
- 변동성 낮은 주식이 상대적으로 저평가

---

## 17.6 멀티팩터 모델

여러 팩터를 결합해 더 안정적인 초과 수익을 추구합니다.

### Fama-French 3요인 모델

```
Rp − Rf = α + β₁(Rm − Rf) + β₂·SMB + β₃·HML + ε

SMB (Small Minus Big): 소형주 − 대형주 수익률 차이
HML (High Minus Low): 고PBR − 저PBR 수익률 차이
```

### Fama-French 5요인 모델

3요인 + 수익성 팩터(RMW) + 투자 팩터(CMA)

### 실전 멀티팩터 스코어링

```
종합 팩터 점수 = 
  가치 점수 × 0.3 +
  모멘텀 점수 × 0.3 +
  품질 점수 × 0.3 +
  저변동성 점수 × 0.1
```

> monticker 스크리너에서 각 팩터 지표를 필터로 조합해 멀티팩터 스크리닝을 구현할 수 있습니다.

---

## 요약

```
팩터 = 초과 수익의 체계적 원인
가치 팩터: PER/PBR 낮은 주식
모멘텀 팩터: 최근 수익률 좋은 주식
품질 팩터: ROE/이익 일관성 높은 주식
저변동성 팩터: 변동성 낮은 주식
멀티팩터: 여러 팩터 결합 → 더 안정적
```
