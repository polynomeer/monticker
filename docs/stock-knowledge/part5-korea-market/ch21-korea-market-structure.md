# 21장. 한국 증시 구조

> **핵심 한 줄**: 한국 주식 시장은 전 세계 주요 시장 중에서도 개인투자자의 비중이 크고, 독특한 규제와 관행이 있다.

---

## 21.1 KOSPI / KOSDAQ / KONEX 차이

| 구분 | KOSPI | KOSDAQ | KONEX |
|------|-------|--------|-------|
| 정식 명칭 | 유가증권시장 | 코스닥시장 | 코넥스시장 |
| 대상 | 대형 우량 기업 | 중소·벤처·기술 기업 | 중소기업 초기 단계 |
| 상장 기업 수 | 약 800개 | 약 1,700개 | 약 150개 |
| 시가총액 기준 | 높음 (자기자본 300억+) | 낮음 (자기자본 30억+) | 완화 |
| 거래 비중 | 전체의 약 60% | 약 40% | 미미 |
| 대표 지수 | KOSPI, KOSPI200 | KOSDAQ, KOSDAQ150 | — |

### KOSPI200

KOSPI 전체에서 유동성·규모 기준 상위 200개 종목으로 구성.  
선물, 옵션, ETF의 기초 자산으로 사용되는 가장 중요한 지수.

### KOSDAQ150

KOSDAQ에서 유동성·시총 기준 150개 종목. 바이오, IT 기업 비중 높음.

## 21.2 코스피/코스닥의 특성 차이

| 항목 | KOSPI | KOSDAQ |
|------|-------|--------|
| 대표 섹터 | 반도체, 금융, 자동차, 화학 | 바이오, IT, 게임, 엔터 |
| 변동성 | 상대적으로 낮음 | 높음 |
| 외국인 비중 | 높음 (30~40%) | 낮음 (10% 미만) |
| 기관 비중 | 높음 | 낮음 |
| 개인 비중 | 약 50% | 약 65%+ |
| 테마 민감도 | 중간 | 매우 높음 |

## 21.3 상한가 / 하한가 (±30%)

한국 거래소는 하루 동안 주가가 **전일 종가 대비 ±30% 이상 변동되는 것을 금지**합니다.

```
전일 종가: 10,000원
상한가: 13,000원 (+30%)
하한가:  7,000원 (-30%)
```

### 상한가 투자 전략

- 상한가 종목은 다음 날도 계속 오를 가능성이 있는지 분석
- 상한가에 매수 주문을 내도 물량 없으면 미체결 (상한가 따라잡기의 어려움)

### 미국과의 비교

미국에는 개별 종목 상하한가 없음 (서킷브레이커만 존재).  
한국의 ±30%는 역사적으로 1995년 ±6%에서 단계적으로 확대되어 2015년부터 ±30%.

## 21.4 권리락 (Ex-dividend) / 배당락

### 배당락 (Ex-dividend Date)

배당을 받으려면 **배당락일 하루 전**까지 주식을 보유해야 합니다.

```
한국 배당금 지급 구조 (대부분의 상장사):
  결산일: 12월 31일
  배당락일: 12월 31일 (이 날 이후 매수하면 배당 못 받음)
  배당 지급: 다음 해 4월경
```

배당락일에는 배당금만큼 주가가 하락하는 경향 (배당락 효과).

### 권리락

유상증자, 무상증자 등 주주에게 특정 권리가 부여되는 날.  
권리락일 이후 매수하면 해당 권리가 없음.

## 21.5 공시 (Disclosure) — DART

**DART(Data Analysis, Retrieval and Transfer System)**: 금융감독원이 운영하는 전자공시시스템.  
[dart.fss.or.kr](https://dart.fss.or.kr)

### 주요 의무 공시

| 공시 종류 | 내용 |
|----------|------|
| **사업보고서** | 연간 재무제표 (3월 말) |
| **반기/분기보고서** | 6개월/3개월 실적 |
| **실적 공시** | 잠정 실적 (어닝 서프라이즈/쇼크) |
| **대규모 계약 체결** | 매출의 10% 이상 계약 |
| **최대주주 변경** | 경영권 이동 |
| **유상증자/무상증자** | 주식 발행 변경 |
| **자사주 취득/처분** | 자기 주식 매매 |

### 공시가 주가에 미치는 영향

```
호재성 공시: 실적 개선, 대형 계약, 자사주 취득 → 주가 상승
악재성 공시: 실적 부진, 소송 패소, 최대주주 매도 → 주가 하락
```

> monticker는 DART OpenAPI를 통해 공시를 실시간으로 수집하고  
> `StockEvent`로 변환해 사용자에게 알림을 제공합니다.

## 21.6 기관/외국인/개인 수급

한국 주식 시장의 특이점: **수급 공개**.  
거래소는 매일 기관·외국인·개인별 순매수 데이터를 공개합니다.

```
외국인 순매수 +1,000억: 외국인이 오늘 1,000억원어치 더 샀음
기관 순매도 −500억: 기관이 오늘 500억원어치 더 팔았음
```

### 투자자별 특성

| 구분 | 투자 성향 |
|------|---------|
| **외국인** | 장기 기관 투자. KOSPI 대형주 중심. 환율 민감 |
| **기관** | 연기금(국민연금), 자산운용사, 증권사 |
| **개인(개미)** | 단기 매매 많음. 테마 반응 빠름 |

"기관 + 외국인 순매수 + 주가 상승 = 신뢰할 수 있는 상승"이라는 경험칙.

## 요약

```
KOSPI = 대형 우량주 (자동차, 반도체, 금융)
KOSDAQ = 중소·기술주 (바이오, IT)
상하한가 ±30% = 하루 최대 변동 제한
배당락일 = 이날 이전에 사야 배당 수령
DART = 공시 의무 플랫폼 (전자공시시스템)
수급 공개 = 기관/외국인/개인 순매수 매일 공개
```
