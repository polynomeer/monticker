# 23장. 투자 규제와 자문

> **핵심 한 줄**: 투자 정보와 투자 조언은 법적으로 다르다. monticker가 "이 서비스는 투자 조언이 아닙니다"라고 고지하는 이유가 여기 있다.

---

## 23.1 투자자문업 vs 유사투자자문업

### 투자자문업 (금융위원회 인가 필요)

금융투자업 중 하나. **개인화된 투자 권유 및 조언**을 유료로 제공.

- 금융위원회 인가 필수 (자본금 2억+ 등)
- 각 고객의 재정 상태, 투자 목적, 위험 성향 파악 의무
- 적합성 원칙, 설명 의무, 손해배상 책임

### 유사투자자문업

투자자문업보다 규제가 낮음.

- 금융당국에 **신고**만 하면 됨 (인가 불필요)
- **불특정 다수**에게 동일한 정보 제공 가능
- 개인화된 조언 불가 → 일반적 정보만 제공

### monticker의 위치

monticker는 투자자문업자도, 유사투자자문업자도 아닙니다.  
**정보 제공 플랫폼(핀테크 서비스)** 으로, 투자 교육 및 학습 도구를 제공합니다.

```
서비스 범위:
✓ 주식 데이터 조회 및 시각화
✓ 기술적 지표 계산 및 표시
✓ 모의투자(페이퍼 트레이딩)
✓ 퀀트 전략 백테스트 (교육 목적)
✗ "A 주식을 사세요"와 같은 개인화된 매수/매도 권유
✗ 특정 수익률 보장
```

---

## 23.2 투자일임업

고객 자산을 **고객의 개별 승인 없이** 직접 운용하는 업무.

- 금융위원회 인가 (인가 요건 더 높음)
- 펀드운용사, 헤지펀드 등이 해당
- 운용 결과에 대한 책임

monticker는 실제 자산을 운용하지 않으므로 투자일임업 해당 없음.

---

## 23.3 투자권유 규제 — "이 서비스는 투자 조언이 아닙니다"의 이유

모든 금융서비스는 투자 권유 시 **적합성 원칙**을 지켜야 합니다.

### 적합성 원칙 (Suitability Rule)

```
고객의 투자 목적, 재정 상태, 투자 경험, 위험 성향을 파악 →
그에 맞는 상품만 권유
```

초보 투자자에게 고위험 파생상품을 권유하는 것은 위법.

### 설명 의무

금융상품 판매 시 주요 내용, 위험 등을 충분히 설명해야 함.

### monticker의 면책 고지

```
이 서비스에서 제공하는 정보와 시뮬레이션 결과는 
교육 및 참고 목적이며, 투자 조언이 아닙니다.
과거 수익률이 미래 수익률을 보장하지 않습니다.
투자 결정은 투자자 본인의 판단과 책임하에 이루어져야 합니다.
```

## 23.4 금융소비자보호법 (금소법)

2021년 시행. 금융 소비자를 보호하기 위한 포괄 법률.

### 핵심 6대 의무

| 의무 | 내용 |
|------|------|
| 적합성 원칙 | 소비자 특성에 맞는 상품 권유 |
| 적정성 원칙 | 권유 없이도 부적합 상품 계약 시 고지 의무 |
| 설명 의무 | 핵심 내용 설명 + 이해 확인 |
| 불공정영업행위 금지 | 부당 권유, 압박 금지 |
| 부당권유행위 금지 | 허위/과장/오해 유발 표시 금지 |
| 광고 규제 | 금융상품 광고 요건 준수 |

### 투자자에게 중요한 권리

- **청약 철회권**: 일정 기간 내 계약 취소 가능 (투자성 상품 제외 경우 多)
- **위법계약 해지권**: 위법 행위 시 5년 내 계약 해지 요청 가능

## 23.5 실명제와 계좌 개설

- 한국은 **금융실명제** 의무 — 주민등록번호 기반 본인 확인
- 주식 계좌 개설: 본인 명의로만 가능
- 타인 명의 계좌 이용 = 불법 (차명 계좌)

---

## 23.6 공매도 (Short Selling) 규제

**공매도**: 갖고 있지 않은 주식을 빌려서 팔고, 이후 가격이 내리면 사서 갚는 투자 방법.

한국에서:
- 기관·외국인 → 허용 (대주거래, 주식 대차)
- **개인 투자자 → 원칙적으로 제한**
- 2023~2024년 한시적 전면 금지 시행

공매도 허용 시에도 업틱룰(직전 체결가 이상에서만 공매도 가능) 적용.

---

## 요약

```
투자자문업 = 개인 맞춤 조언 (인가 필요)
유사투자자문업 = 불특정 다수 정보 제공 (신고)
monticker = 정보·교육 플랫폼 (투자 조언 아님)
금소법 = 금융 소비자 보호의 기본 법률
적합성 원칙 = 투자자 특성에 맞는 상품만 권유
공매도 = 한국에서 개인 투자자 접근 제한
```
