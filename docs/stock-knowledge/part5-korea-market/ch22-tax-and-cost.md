# 22장. 세금과 비용

> **핵심 한 줄**: 세금과 수수료는 반드시 수익에서 차감되는 "보이지 않는 비용"이다. 백테스트에서도 반드시 반영해야 한다.

---

## 22.1 증권거래세 + 농특세

주식을 **매도**할 때마다 부과되는 세금. **매수 시에는 없음**.

```
KOSPI: 증권거래세 0.03% + 농어촌특별세 0.15% = 합계 0.18%
KOSDAQ: 증권거래세 0.15% + 농특세 없음 = 합계 0.15%
KONEX: 0.10%
```

> 2023년 이후 세율 조정이 있었고, 계속 변경되고 있으니 최신 세율 확인 필요.

### 세금 계산 예시

```
KOSPI 삼성전자 100주 @ 75,000원 매도:
  매도 금액: 7,500,000원
  증권거래세(0.03%): 2,250원
  농특세(0.15%): 11,250원
  합계 세금: 13,500원 (0.18%)
```

매도할 때마다 자동으로 원천징수되므로 투자자가 신경 쓸 필요는 없지만,  
**빈번한 매매는 세금 누적으로 수익을 깎아먹습니다.**

```
연간 회전율 500%의 전략 → 매도 금액 = 자본의 5배
세금 비용 = 자본 × 5 × 0.18% = 자본의 0.9%/년
```

## 22.2 양도소득세 — 대주주 기준

### 2024년 현재 (매우 중요: 세율은 자주 바뀝니다)

주식 양도소득세는 **대주주**에게만 부과됩니다.

| 구분 | 기준 |
|------|------|
| **대주주 기준** | 종목별 보유 금액 10억원 이상 (직전 연도 말 기준) |
| 세율 | 20% (과세표준 3억 이하) / 25% (초과) |

일반 소액 투자자: 국내 상장 주식 양도소득세 **없음**.

> **금융투자소득세(금투세)**: 원래 2025년부터 도입 예정이었으나 폐지 결정.  
> 상황이 자주 바뀌니 최신 세법을 항상 확인하세요.

## 22.3 배당소득세

배당금에는 **15.4% (지방세 포함)** 세율로 원천징수됩니다.

```
배당금 1,000원 → 세금 154원 → 실수령 846원
```

- 금융소득 연간 **2,000만원 초과** 시 종합소득세 신고 대상
- 2,000만원 이하: 분리과세(15.4%)로 종결

## 22.4 증권사 수수료 구조

주문 체결 시 증권사가 징수하는 수수료.

| 증권사 유형 | 수수료율 (매매 편도) |
|-----------|-------------------|
| 대형 증권사 (MTS 기준) | 0.01% ~ 0.015% |
| 온라인 전용 증권사 | 0.003% ~ 0.01% |
| 일부 이벤트 수수료 | 0% (기간 한정) |

```
수수료 왕복(매수+매도) = 수수료율 × 2
+ 증권거래세 (매도만)
= 총 거래 비용
```

예시 (수수료 0.015%, KOSPI 매도):
```
편도 수수료: 0.015%
매도 시 세금: 0.18%
왕복 수수료: 0.03%
총 비용(왕복): 약 0.21%
```

100만원으로 매매하면 약 2,100원 비용 발생.

## 22.5 실질 거래 비용과 수익률 영향

### 슬리피지 포함 총 비용

```
총 거래 비용 = 수수료(왕복) + 세금(매도) + 슬리피지
             ≈ 0.03% + 0.18% + 0.1~0.3%
             ≈ 0.3% ~ 0.5% 왕복
```

### 빈번 매매의 비용

| 월 매매 횟수 | 연간 거래 비용 (자본 대비) |
|------------|------------------------|
| 1회/월 | 약 0.04 ~ 0.06%/년 |
| 10회/월 | 약 0.4 ~ 0.6%/년 |
| 50회/월 | 약 2 ~ 3%/년 |

**연 수익률이 5%인데 거래 비용이 3%면 실질 수익은 2%.**

---

## 22.6 비용을 반영한 백테스트

monticker 백테스트에서 비용 파라미터:

```json
{
  "commission": 0.00015,     ← 0.015% (편도)
  "taxRate": 0.0018,         ← 0.18% (KOSPI 매도세)
  "slippageBps": 10          ← 10 basis points = 0.1%
}
```

비용 미반영 vs 반영 결과 비교:

```
전략 A (비용 미반영): 연 수익률 15%, Sharpe 1.5
전략 A (비용 반영):  연 수익률 11%, Sharpe 1.1
→ 거래 빈도가 높을수록 차이 심각
```

## 요약

```
증권거래세 = 매도 시 0.15~0.18% (자동 징수)
양도소득세 = 대주주만 해당 (일반 투자자 면제)
배당소득세 = 15.4% 원천징수
증권사 수수료 = 0.003~0.015% (편도)
총 왕복 거래 비용 ≈ 0.3~0.5%
빈번한 매매는 비용 누적으로 수익률 잠식
```
